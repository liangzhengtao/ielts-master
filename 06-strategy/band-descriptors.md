## 1. 总分等级描述 / Overall Band Descriptors

### 1.1 各 Band 等级含义 / Band Score Meanings

| Band | 英文描述 / English | 中文描述 / Chinese |
|---|---|---|
| **9** | Expert User | 精通使用者：完全掌握英语，运用自如、准确 |
| **8** | Very Good User | 优秀使用者：偶尔出现不恰当或不准确，能处理复杂详细论证 |
| **7** | Good User | 良好使用者：能运用复杂语言，偶尔有不准确，通常能处理好 |
| **6** | Competent User | 合格使用者：能有效运用英语，虽有不准确和误解，能在熟悉语境下使用复杂语言 |
| **5** | Modest User | 适度使用者：能部分运用英语，多数情况下能应付总体意思，但可能犯很多错误 |
| **4** | Limited User | 有限使用者：能力限于熟悉情境，频繁出现理解和表达问题 |
| **3** | Extremely Limited User | 极有限使用者：仅能在非常熟悉的情境下传达和理解大致意思 |
| **2** | Intermittent User | 间歇使用者：在理解英语和用英语表达方面有极大困难 |
| **1** | Non-User | 非使用者：仅能使用几个孤立的单词 |
| **0** | Did Not Attempt | 未参加考试 |

### 1.2 各分数段考生画像 / Score Range Profiles

#### Band 9 — 精通 / Expert
```
特征 / Characteristics:
├── 用语准确、流利，完全自如 / Accurate, fluent, completely natural
├── 理解力全面 / Comprehensive understanding
├── 能处理任何复杂话题 / Handles any complex topic
└── 极少出现错误 / Very rare errors

实际表现 / In Practice:
- 听力：几乎全对 / Listening: nearly all correct
- 阅读：几乎全对 / Reading: nearly all correct
- 写作：论证严密，语言地道 / Writing: tight arguments, native-like language
- 口语：接近母语者水平 / Speaking: near-native level
```

#### Band 7 — 良好 / Good
```
特征 / Characteristics:
├── 能使用复杂语言 / Can use complex language
├── 偶有错误但不影响理解 / Occasional errors that don't impede understanding
├── 对复杂话题有一定掌握 / Some command of complex topics
└── 总体上能有效沟通 / Generally effective communication

实际表现 / In Practice:
- 听力：30-32 题正确 / Listening: 30-32 correct
- 阅读：30-32 题正确 / Reading: 30-32 correct
- 写作：结构清晰，论证有一定深度 / Writing: clear structure, some depth
- 口语：流利表达，能展开论述 / Speaking: fluent, can elaborate
```

#### Band 6 — 合格 / Competent
```
特征 / Characteristics:
├── 能有效运用英语 / Can use English effectively
├── 有不准确和误解 / Some inaccuracies and misunderstandings
├── 能使用复杂语言（熟悉话题）/ Can use complex language (familiar topics)
└── 总体意思能传达 / Overall meaning comes through

实际表现 / In Practice:
- 听力：23-26 题正确 / Listening: 23-26 correct
- 阅读：23-26 题正确 / Reading: 23-26 correct
- 写作：能回应题目，但深度不足 / Writing: addresses task but lacks depth
- 口语：能表达，但有时停顿或重复 / Speaking: can express but with pauses/repetitions
```

#### Band 5 — 适度 / Modest
```
特征 / Characteristics:
├── 部分运用英语 / Partial command of English
├── 能应付大致意思 / Copes with overall meaning
├── 犯很多错误 / Makes many errors
└── 仅在熟悉领域有效沟通 / Effective only in familiar areas

实际表现 / In Practice:
- 听力：19-22 题正确 / Listening: 19-22 correct
- 阅读：19-22 题正确 / Reading: 19-22 correct
- 写作：回应题目但偏题或论证薄弱 / Writing: responds but off-topic or weak
- 口语：表达有限，频繁停顿 / Speaking: limited expression, frequent pauses
```

## 2. 听力评分标准 / Listening Scoring

### 2.1 评分机制 / Scoring Mechanism

听力为客观评分，共 40 题，每题 1 分。
Listening is objectively scored: 40 questions, 1 point each.

**关键注意事项 / Key Notes：**
- 拼写错误不给分 / Spelling errors get no credit
- 大小写不影响得分 / Capitalization doesn't affect score
- 单复数错误不给分 / Singular/plural errors get no credit
- 超出字数限制的答案不给分 / Answers exceeding word limit get no credit
- 缩写需为公认缩写 / Abbreviations must be accepted ones

### 2.2 分数换算表 / Score Conversion Table

| 正确题数 / Correct | Band Score | 正确题数 / Correct | Band Score |
|---|---|---|---|
| 39-40 | 9.0 | 19-22 | 5.5 |
| 37-38 | 8.5 | 15-18 | 5.0 |
| 35-36 | 8.0 | 13-14 | 4.5 |
| 33-34 | 7.5 | 10-12 | 4.0 |
| 30-32 | 7.0 | 6-9 | 3.5 |
| 27-29 | 6.5 | 4-5 | 3.0 |
| 23-26 | 6.0 | 2-3 | 2.5 |

### 2.3 提分策略 / Score Improvement Strategies

**从 5.0 到 6.0：**
- 重点训练 Section 1-2（简单题不丢分）/ Focus on Section 1-2 (don't lose easy points)
- 练习拼写（高频词汇听写）/ Practice spelling (dictation of high-frequency words)
- 学会预读题目 / Learn to pre-read questions

**从 6.0 到 7.0：**
- 提升 Section 3-4 正确率 / Improve Section 3-4 accuracy
- 掌握同义替换 / Master paraphrasing
- 练习速记能力 / Practice shorthand note-taking

**从 7.0 到 8.0+：**
- 精听训练（逐句听写）/ Intensive listening (sentence-by-sentence dictation)
- 熟悉各种口音 / Familiarize with various accents (British, Australian, American)
- 提升注意力集中度 / Improve concentration span

## 3. 阅读评分标准 / Reading Scoring

### 3.1 评分机制 / Scoring Mechanism

阅读同样为客观评分，共 40 题。
Reading is also objectively scored: 40 questions.

**A类与G类换算不同 / Different Conversion for A vs G:**

#### Academic 阅读 / Academic Reading

| 正确题数 / Correct | Band | 正确题数 / Correct | Band |
|---|---|---|---|
| 39-40 | 9.0 | 19-22 | 5.5 |
| 37-38 | 8.5 | 15-18 | 5.0 |
| 35-36 | 8.0 | 13-14 | 4.5 |
| 33-34 | 7.5 | 10-12 | 4.0 |
| 30-32 | 7.0 | 6-9 | 3.5 |
| 27-29 | 6.5 | 4-5 | 3.0 |
| 23-26 | 6.0 | 2-3 | 2.5 |

#### General Training 阅读 / General Training Reading

| 正确题数 / Correct | Band | 正确题数 / Correct | Band |
|---|---|---|---|
| 40 | 9.0 | 23-29 | 5.5 |
| 39 | 8.5 | 19-22 | 5.0 |
| 37-38 | 8.0 | 15-18 | 4.5 |
| 36 | 7.5 | 12-14 | 4.0 |
| 34-35 | 7.0 | 9-11 | 3.5 |
| 32-33 | 6.5 | 6-8 | 3.0 |
| 30-31 | 6.0 | 4-5 | 2.5 |

> ⚠️ G类阅读需要答对更多题才能获得相同分数
> G-Training requires more correct answers for the same band

### 3.2 提分策略 / Score Improvement Strategies

**从 5.0 到 6.0：**
- 学会快速定位答案 / Learn quick answer location
- 优先做填空题和判断题 / Prioritize fill-in-the-blank and T/F/NG
- 提升阅读速度至 250 wpm / Improve reading speed to 250 wpm

**从 6.0 到 7.0：**
- 掌握所有题型技巧 / Master all question type strategies
- 提升同义替换识别能力 / Improve paraphrase recognition
- 做题时间分配优化（Passage 3 多给时间）/ Optimize time allocation

**从 7.0 到 8.0+：**
- 快速理解长难句 / Quick comprehension of complex sentences
- 提升推理判断能力 / Improve inference skills
- 精读学术文章 / Close read academic articles

## 4. 写作评分标准 / Writing Scoring

### 4.1 四大评分维度 / Four Assessment Criteria

写作由考官从四个维度打分，每个维度权重相等。
Writing is scored by examiners on four equally weighted criteria.

#### Task 1 & Task 2 共用维度 / Shared Criteria for Both Tasks

| 维度 / Criterion | 权重 / Weight | 描述 / Description |
|---|---|---|
| **Task Achievement (TA)** / 任务完成度 | 25% | 是否充分回应题目要求 |
| **Coherence & Cohesion (CC)** / 连贯与衔接 | 25% | 逻辑是否清晰，衔接是否自然 |
| **Lexical Resource (LR)** / 词汇丰富度 | 25% | 词汇是否多样、准确 |
| **Grammatical Range & Accuracy (GRA)** / 语法多样性与准确性 | 25% | 语法结构是否多样、正确 |

### 4.2 各维度 Band 7 详解 / Band 7 Descriptors in Detail

#### Task Achievement — Band 7 (Task 2)
```
考官视角 / Examiner sees:
✅ 充足地回应了所有部分 / Addresses all parts of the task
✅ 立场清晰 / Presents a clear position throughout
✅ 主要观点有扩展，但可能有时不够充分
   Main ideas are extended and supported, but may lack balance
```

**考生实操要点 / Practical Tips：**
- 每个主体段都有明确的主题句 / Each body paragraph has a clear topic sentence
- 观点有解释+例子+结果 / Ideas have explanation + example + result
- 回应题目所有部分 / Address ALL parts of the question
- 结论与全文立场一致 / Conclusion consistent with overall position

#### Coherence & Cohesion — Band 7
```
考官视角 / Examiner sees:
✅ 有逻辑地组织信息 / Logically organizes information
✅ 恰当使用衔接手段 / Uses a range of cohesive devices appropriately
✅ 每段有清晰的中心 / Each paragraph has a clear central topic
```

**高分衔接手段 / High-Score Cohesive Devices：**

| 类型 / Type | 例子 / Examples |
|---|---|
| 递进 / Addition | furthermore, moreover, in addition, besides |
| 转折 / Contrast | however, nevertheless, on the other hand, conversely |
| 因果 / Cause & Effect | consequently, as a result, therefore, hence |
| 举例 / Example | for instance, for example, such as, to illustrate |
| 让步 / Concession | admittedly, granted, although, while |
| 总结 / Summary | in conclusion, to sum up, overall, ultimately |

> ⚠️ 常见错误：过度使用 firstly, secondly, thirdly
> Common mistake: overusing firstly, secondly, thirdly — use varied linking devices

#### Lexical Resource — Band 7
```
考官视角 / Examiner sees:
✅ 使用足够的词汇来灵活讨论话题 / Uses sufficient vocabulary for flexible discussion
✅ 能使用不太常见的词汇 / Uses less common vocabulary
✅ 有意识语风格搭配的意识 / Shows awareness of style and collocation
✅ 偶有拼写或词形错误 / Occasional errors in word formation/spelling
```

**词汇提升方法 / Vocabulary Enhancement：**

| 普通表达 / Basic | 高分表达 / Band 7+ |
|---|---|
| important | crucial, vital, paramount, essential |
| think | contend, assert, maintain, argue |
| many people | a significant proportion of individuals |
| good | beneficial, advantageous, favorable |
| bad | detrimental, adverse, unfavorable |
| more and more | an increasing number of, a growing trend of |
| very big | substantial, considerable, enormous |
| because | owing to, due to, on account of |

#### Grammatical Range & Accuracy — Band 7
```
考官视角 / Examiner sees:
✅ 使用多种复杂结构 / Uses a variety of complex structures
✅ 大多数句子无错误 / Majority of sentences are error-free
✅ 有一些语法错误但不影响理解
   Some errors but they don't impede communication
```

**必须掌握的复杂句式 / Must-Know Complex Structures：**

1. **定语从句 / Relative Clauses**
   ```
   ❌ The government should invest in education. It helps economic growth.
   ✅ The government should invest in education, which contributes to economic growth.
   ```

2. **条件句 / Conditional Sentences**
   ```
   ❌ If people recycle, the environment will be better.
   ✅ If governments were to implement stricter regulations, environmental degradation could be significantly reduced.
   ```

3. **让步状语从句 / Concessive Clauses**
   ```
   ❌ Technology has problems. But it is still useful.
   ✅ While technology poses certain challenges, its benefits in facilitating communication are undeniable.
   ```

4. **被动语态 / Passive Voice**
   ```
   ❌ People should consider this issue seriously.
   ✅ This issue should be given serious consideration by policymakers.
   ```

5. **倒装句 / Inversion**
   ```
   ✅ Not only does education enhance individual prospects, but it also strengthens society as a whole.
   ✅ Only by addressing the root causes can we hope to solve this problem.
   ```

### 4.3 写作分数计算 / Writing Score Calculation

```
Task 1 得分 = (TA + CC + LR + GRA) / 4
Task 2 得分 = (TA + CC + LR + GRA) / 4

总写作分 = Task 1 × 1/3 + Task 2 × 2/3
Writing Overall = Task 1 × 1/3 + Task 2 × 2/3

例 / Example:
Task 1: TA=6, CC=6, LR=6, GRA=6 → 6.0
Task 2: TA=7, CC=7, LR=6, GRA=7 → 6.75
Writing = 6.0 × 1/3 + 6.75 × 2/3 = 2.0 + 4.5 = 6.5
```

> 💡 这意味着 Task 2 的分数权重是 Task 1 的两倍
> This means Task 2 counts TWICE as much as Task 1

## 5. 口语评分标准 / Speaking Scoring

### 5.1 四大评分维度 / Four Assessment Criteria

| 维度 / Criterion | 权重 / Weight | 描述 / Description |
|---|---|---|
| **Fluency & Coherence (FC)** / 流利度与连贯性 | 25% | 表达是否流利、有逻辑 |
| **Lexical Resource (LR)** / 词汇丰富度 | 25% | 词汇是否多样、恰当 |
| **Grammatical Range & Accuracy (GRA)** / 语法多样性与准确性 | 25% | 语法是否多样、正确 |
| **Pronunciation (P)** / 发音 | 25% | 发音是否清晰、自然 |

### 5.2 各维度 Band 7 详解 / Band 7 Descriptors

#### Fluency & Coherence — Band 7
```
考官视角 / Examiner sees:
✅ 能流畅地长篇发言 / Speaks at length without noticeable effort
✅ 有适当的停顿 / Uses pauses appropriately
✅ 话题展开有逻辑 / Develops topics coherently
✅ 使用多种衔接手段 / Uses a range of discourse markers
```

**实操要点 / Practical Tips：**
- 回答不要只有一句话 / Don't give one-sentence answers
- 使用 "观点→原因→例子→总结" 结构 / Use "Point→Reason→Example→Summary"
- 适当使用填充词 / Use natural fillers: "well", "I mean", "you know", "let me think"
- 避免长时间沉默 / Avoid long silences

**示范回答 / Sample Answer (Part 1)：**
```
Question: Do you like reading?

❌ Band 5 答案:
"Yes, I like reading. I read books every day."

✅ Band 7 答案:
"Yes, I'm quite a keen reader actually. I tend to read mostly fiction — 
novels and short stories — mainly because I find they help me unwind 
after a long day at work. Having said that, I've recently started 
reading more non-fiction, particularly books about history, which I 
find fascinating."
```

#### Lexical Resource — Band 7
```
考官视角 / Examiner sees:
✅ 灵活使用词汇讨论多种话题 / Flexibly uses vocabulary on various topics
✅ 使用不太常见和地道的表达 / Uses less common and idiomatic expressions
✅ 有效进行同义替换 / Effectively paraphrases
✅ 偶有用词不当 / Occasional inappropriate word choice
```

**口语高分表达替换 / Speaking High-Score Replacements：**

| 普通表达 / Basic | 高分表达 / Band 7+ |
|---|---|
| I like | I'm fond of, I'm keen on, I'm into, I have a passion for |
| I think | I'd say, I reckon, In my view, If you ask me |
| It's good | It's fantastic, It's brilliant, It's remarkable |
| It's bad | It's awful, It's dreadful, It's appalling |
| very + adj | extremely + adj, remarkably + adj, exceptionally + adj |
| a lot of | a great deal of, a wealth of, plenty of, heaps of |
| sometimes | from time to time, on occasion, every now and then |
| I don't know | I'm not entirely sure, I haven't really thought about it, That's a tough one |

#### Grammatical Range & Accuracy — Band 7
```
考官视角 / Examiner sees:
✅ 使用多种复杂结构 / Uses a range of complex structures
✅ 频繁使用无错误的句子 / Frequent error-free sentences
✅ 语法错误基本不影响理解 / Errors rarely impede communication
```

**口语常用复杂句式 / Complex Structures for Speaking：**

1. **过去虚拟 / Past Hypothetical:**
   "If I had more free time, I would probably take up painting."

2. **条件推理 / Conditional Reasoning:**
   "Should the government invest more in public transport, I believe traffic congestion could be significantly alleviated."

3. **被动 + 定语从句 / Passive + Relative Clause:**
   "The book, which was written by a renowned historian, provides a unique perspective."

4. **让步 + 对比 / Concession + Contrast:**
   "While technology has undoubtedly made our lives more convenient, it has also led to some rather concerning social issues."

#### Pronunciation — Band 7
```
考官视角 / Examiner sees:
✅ 表达清晰易懂 / Is easy to understand
✅ 使用多种发音特征 / Uses a range of pronunciation features
✅ 能有效使用重音和语调 / Uses stress and intonation effectively
✅ 偶有发音错误但不影响理解 / Occasional mispronunciations don't impede understanding
```

**发音提升要点 / Pronunciation Improvement Points：**

| 要素 / Element | Band 5-6 | Band 7+ |
|---|---|---|
| **重音** / Stress | 单词重音有时错误 | 正确使用单词和句子重音 |
| **连读** / Linking | 单词之间有明显停顿 | 自然连读，如 "kind of" → "kinda" |
| **语调** / Intonation | 语调平，缺少变化 | 语调自然起伏，表达情感 |
| **弱读** / Weak forms | 每个词都重读 | 功能词弱读，如 "a, the, of, to" |
| **节奏** / Rhythm | 逐词发音 | 英语节奏感（重音计时语言） |

## 6. 如何利用评分标准备考 / How to Use Descriptors for Preparation

### 6.1 自评打分 / Self-Assessment

**写作自评清单 / Writing Self-Assessment Checklist：**

```
Task Achievement (TA):
□ 我回应了题目所有部分吗？/ Did I address ALL parts?
□ 每个主体段有明确观点吗？/ Does each paragraph have a clear point?
□ 观点有充分展开（解释+例子）？/ Are ideas well-developed?
□ 字数达标（Task 1: 150+, Task 2: 250+）？/ Word count met?

Coherence & Cohesion (CC):
□ 文章有清晰的引言-主体-结论？/ Clear intro-body-conclusion?
□ 每段有主题句？/ Topic sentence in each paragraph?
□ 使用了多样衔接词？/ Varied cohesive devices?
□ 段落之间有逻辑过渡？/ Logical transitions between paragraphs?

Lexical Resource (LR):
□ 使用了同义替换（避免重复同一词）？/ Paraphrased effectively?
□ 使用了不太常见的词汇？/ Used less common vocabulary?
□ 搭配正确（collocations correct）？/ Correct collocations?
□ 拼写基本正确？/ Spelling mostly correct?

Grammatical Range & Accuracy (GRA):
□ 使用了至少 3 种复杂句式？/ At least 3 complex structures?
□ 大多数句子无语法错误？/ Most sentences error-free?
□ 主谓一致、时态正确？/ Subject-verb agreement, tense correct?
□ 冠词和介词使用正确？/ Articles and prepositions correct?
```

**口语自评清单 / Speaking Self-Assessment Checklist：**

```
Fluency & Coherence:
□ 回答有扩展（不是一两句结束）？/ Extended answers?
□ 停顿自然（不是因为想词）？/ Natural pauses (not searching for words)?
□ 逻辑清晰？/ Coherent logic?

Lexical Resource:
□ 使用了多样词汇？/ Varied vocabulary?
□ 使用了地道表达？/ Idiomatic expressions?
□ 能有效替换重复词？/ Effective paraphrasing?

Grammatical Range & Accuracy:
□ 使用了多种时态？/ Multiple tenses used?
□ 使用了复杂句？/ Complex sentences used?
□ 语法错误不多？/ Limited grammar errors?

Pronunciation:
□ 考官能轻松听懂？/ Easy for examiner to understand?
□ 有语调变化？/ Intonation variation?
□ 关键词有正确重音？/ Correct stress on key words?
```

### 6.2 对标提分 / Targeted Score Improvement

**从 Band 6 到 Band 7 的关键差距 / Key Gaps from Band 6 to 7：**

| 维度 / Criterion | Band 6 特征 | Band 7 要求 | 提升方法 |
|---|---|---|---|
| TA/FC | 回应了题目但不够充分 | 充足回应所有部分 | 练习全面审题 |
| CC | 有衔接但机械 | 恰当使用多种衔接手段 | 学习高级衔接词 |
| LR | 词汇够用但重复 | 灵活使用不太常见词汇 | 积累同义替换 |
