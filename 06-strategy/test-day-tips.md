## 1. 考前一晚 / The Night Before

### 1.1 必做事项 / Must-Do Checklist

```
□ 准备考试证件 / Prepare ID documents
  ├── 身份证/护照（必须与报名时一致）
  ├── ID/Passport (must match registration)
  └── 确认证件在有效期内 / Confirm validity

□ 准备考试用品 / Prepare test supplies
  ├── 铅笔（至少 2 支，HB 或 2B）
  ├── Pencils (at least 2, HB or 2B)
  ├── 橡皮（好用的，不要花哨的）
  ├── Eraser (effective, not fancy)
  └── 手表（无智能功能的简单手表）
  └── Watch (simple, non-smart)

□ 查看考场地址 / Check test center address
  ├── 确认具体考试地点
  ├── 确认考试时间
  ├── 规划交通路线
  └── 预留充足出行时间

□ 设好闹钟 / Set alarm
  └── 至少提前 1.5 小时起床 / Wake up at least 1.5 hours early
```

### 1.2 不要做 / What NOT to Do

| ❌ 不要 / Don't | 原因 / Why |
|---|---|
| 临时抱佛脚疯狂刷题 / Cram intensely | 增加焦虑，不会有效提分 / Increases anxiety |
| 喝太多咖啡或茶 / Too much coffee/tea | 影响考试时的注意力和手抖 / Affects focus, causes jitteriness |
| 吃不熟悉的食物 / Unfamiliar food | 可能引起肠胃不适 / May cause stomach issues |
| 熬夜到很晚 / Stay up very late | 充足睡眠比多学一小时更重要 / Sleep > 1 extra hour of study |
| 和别人讨论考试内容 / Discuss exam content with others | 增加不必要的焦虑 / Unnecessary anxiety |

### 1.3 建议做 / Recommended Activities

```
晚上 6-7 点：轻松复习高频词汇和公式
6-7 PM: Light review of high-frequency vocabulary

晚上 7-8 点：做一套简短的听力热身（不要对答案）
7-8 PM: Short listening warm-up (don't check answers)

晚上 8-9 点：准备考试物品，确认证件
8-9 PM: Prepare test items, confirm ID

晚上 9-10 点：放松（散步、听轻音乐、看轻松节目）
9-10 PM: Relax (walk, light music, easy show)

晚上 10 点前：上床睡觉 / In bed before 10 PM
```

### 1.4 睡眠管理 / Sleep Management

- **目标睡眠**：7-8 小时 / Target: 7-8 hours
- **如果睡不着**：不要焦虑，闭眼休息也有恢复作用
  If can't sleep: don't stress — resting with eyes closed also helps
- **避免**：手机、平板等蓝光设备（至少睡前1小时）
  Avoid: phones, tablets, blue light (at least 1 hour before bed)
- **助眠方法**：深呼吸 4-7-8 法（吸气4秒、屏气7秒、呼气8秒）
  Sleep aid: 4-7-8 breathing (inhale 4s, hold 7s, exhale 8s)

## 2. 考试当天早晨 / Morning of the Exam

### 2.1 时间线 / Timeline

```
考试前 2.5 小时 / 2.5 hours before:
└── 起床 / Wake up

考试前 2 小时 / 2 hours before:
├── 洗漱、穿舒适衣服 / Wash up, dress comfortably
├── 吃营养早餐 / Eat nutritious breakfast
└── 再次检查证件和用品 / Re-check ID and supplies

考试前 1.5 小时 / 1.5 hours before:
├── 出门 / Leave home
└── 预留交通缓冲时间 / Allow extra travel time

考试前 1 小时 / 1 hour before:
└── 到达考场 / Arrive at test center

考试前 30 分钟 / 30 minutes before:
├── 完成签到 / Complete check-in
├── 去洗手间 / Use restroom
├── 轻度热身（看笔记）/ Light warm-up (review notes)
└── 深呼吸放松 / Deep breathing relaxation

考试前 5 分钟 / 5 minutes before:
└── 进入考场，调整状态 / Enter exam room, settle in
```

### 2.2 早餐建议 / Breakfast Recommendations

| ✅ 推荐 / Recommended | ❌ 避免 / Avoid |
|---|---|
| 全麦面包 + 鸡蛋 / Whole wheat bread + eggs | 油腻食物 / Greasy food |
| 燕麦粥 + 水果 / Oatmeal + fruit | 过甜食物 / Overly sweet food |
| 牛奶/酸奶 + 坚果 / Milk/yogurt + nuts | 碳酸饮料 / Soda |
| 香蕉（补充钾，缓解紧张）/ Banana (potassium, reduces anxiety) | 过量咖啡因 / Excess caffeine |
| 温水 / Warm water | 冰冷饮料 / Ice cold drinks |

### 2.3 心态调整 / Mental Preparation

**积极自我对话 / Positive Self-Talk：**

```
✅ 我已经准备得很充分了
   "I have prepared well for this."

✅ 我只需要正常发挥
   "I just need to perform as I normally do."

✅ 遇到难题是正常的，跳过就好
   "Difficult questions are normal — just skip and move on."

✅ 我的目标是尽力，不是完美
   "My goal is to do my best, not to be perfect."
```

**避免的想法 / Thoughts to Avoid：**

```
❌ "我应该再多学一个月的"
   "I should have studied for one more month."

❌ "别人都比我准备得好"
   "Everyone else is more prepared."

❌ "如果考不到 X 分就完了"
   "If I don't get X score, everything is ruined."
```

## 3. 到达考场 / Arriving at the Test Center

### 3.1 签到流程 / Check-in Process

1. **找到考场** — 提前确认考场地址，不要迟到
   Find the center — confirm address in advance, don't be late

2. **存放个人物品** — 手机必须关机放在指定位置
   Store belongings — phones must be OFF in designated area

3. **身份验证** — 出示身份证/护照，核对信息
   ID verification — present ID, verify information

4. **拍照/按指纹** — 部分考场需要生物识别
   Photo/fingerprint — some centers require biometrics

5. **入座** — 按照座位号就座
   Seating — sit at assigned seat number

### 3.2 考场规则 / Test Center Rules

| 规则 / Rule | 详情 / Details |
|---|---|
| **不能带入考场** / Not allowed in exam room | 手机、手表（智能）、食物、饮料、纸张 |
| **可以带入** / Allowed | 证件、铅笔、橡皮、水（透明瓶，无标签） |
| **洗手间** / Restroom | 听力考试期间不能去 / Cannot go during Listening |
| **提前交卷** / Early submission | 不允许 / Not allowed |
| **举手示意** / Raise hand | 如有问题或需要帮助 / For questions or assistance |

### 3.3 考前热身 / Pre-Exam Warm-up

**到达考场后的 10 分钟热身 / 10-Minute Warm-up After Arrival：**

```
第 1-3 分钟：快速浏览高频词汇
1-3 min: Quick scan of high-frequency vocabulary

第 4-6 分钟：默读几个口语话题的回答思路
4-6 min: Mentally review speaking topic ideas

第 7-8 分钟：深呼吸 5 次（4秒吸，4秒呼）
7-8 min: Deep breathe 5 times (4s in, 4s out)

第 9-10 分钟：积极自我暗示
9-10 min: Positive self-affirmation
```

## 4. 听力考试 / Listening Test

> 时间：约 30 分钟听音 + 10 分钟誊写答案
> Duration: ~30 min listening + 10 min transfer

### 4.1 考试流程 / Test Flow

```
Section 1 → Section 2 → Section 3 → Section 4 → 蘸写答案
(日常对话)   (独白)     (学术讨论)   (学术讲座)   (10 min transfer)
```

### 4.2 时间管理策略 / Time Management

| 阶段 / Phase | 策略 / Strategy |
|---|---|
| **读题时间** / Reading time | 拿到试卷后立刻看 Section 1 题目 |
| **Section 间歇** / Between sections | 利用间隙预读下一 Section 的题目 |
| **听音时** / During listening | 边听边写答案（简写/缩写） |
| **检查时间** / Check time | Section 4 结束后有时间检查所有答案 |
| **誊写时间** / Transfer time | 10 分钟足够，不要慌 |

### 4.3 关键技巧 / Key Techniques

**读题技巧 / Question Reading：**
```
1. 圈出关键词（人名、数字、地点）
   Circle keywords (names, numbers, places)

2. 预测答案类型（数字？拼写？选项？）
   Predict answer type (number? spelling? choice?)

3. 注意字数限制（NO MORE THAN TWO WORDS）
   Watch word limit (NO MORE THAN TWO WORDS)
```

**听音技巧 / Listening Techniques：**
```
1. 注意信号词（however, but, in fact, actually）
   Watch for signal words

2. 同义替换：听到的词 ≠ 题目中的词
   Paraphrasing: heard words ≠ written words

3. 改口陷阱：说话者可能先说一个答案然后纠正
   Correction trap: speaker may correct themselves

4. 不要纠结已错过的题，跟上节奏
   Don't dwell on missed questions — keep up
```

**常见陷阱 / Common Traps：**
```
⚠️ 陷阱1：干扰项 — 第一个出现的不一定是答案
   Trap 1: Distractor — first mentioned isn't always the answer

⚠️ 陷阱2：改口 — "I thought it was Tuesday... oh wait, it's Wednesday"
   Trap 2: Correction — speaker changes their answer

⚠️ 陷阱3：相似发音 — sixteen vs sixty
   Trap 3: Similar sounds — sixteen vs sixty

⚠️ 陷阱4：复数 — 答案要求复数但你写了单数
   Trap 4: Plural — answer requires plural but you wrote singular
```

### 4.4 蘸写注意事项 / Transfer Tips

- 蘸写时再次检查拼写 / Double-check spelling when transferring
- 确保答案写在正确题号旁边 / Ensure answers are next to correct numbers
- 不确定的题也要猜一个答案 / Guess if unsure (no penalty for wrong answers)
- 注意大小写（专有名词首字母大写）/ Capitalize proper nouns
- 检查字数限制 / Verify word count limits

## 5. 阅读考试 / Reading Test

> 时间：60 分钟（无额外誊写时间）
> Duration: 60 minutes (no extra transfer time)

### 5.1 时间分配 / Time Allocation

```
推荐时间分配 / Recommended Time Allocation:
├── Passage 1：17-18 分钟（最简单）
├── Passage 2：20 分钟
├── Passage 3：22-23 分钟（最难）
└── 检查答案：剩余时间

⚠️ 绝对不要在一篇文章上花超过 25 分钟
⚠️ NEVER spend more than 25 minutes on one passage
```

### 5.2 做题顺序策略 / Question Order Strategy

**策略一：按顺序做（推荐基础较弱的考生）**
Strategy 1: In order (recommended for weaker students)
```
Passage 1 → Passage 2 → Passage 3
先做最简单的，确保拿到基础分
Start with easiest to secure base score
```

**策略二：先做简单题型（推荐有一定基础的考生）**
Strategy 2: Easy question types first (for intermediate students)
```
每篇文章先做填空题和判断题，再做选择和配对题
Fill-in-the-blank and T/F/NG first, then multiple choice and matching
```

### 5.3 各题型做题技巧 / Per-Question-Type Tips

#### 填空题 / Fill in the Blanks
```
1. 看清字数限制 / Check word limit
2. 定位关键词在文中的位置 / Locate keywords in passage
3. 答案通常是原文原词（不需改写）/ Usually exact words from passage
4. 检查语法是否通顺 / Check grammar makes sense
```

#### TRUE / FALSE / NOT GIVEN
```
TRUE：    题目信息与文章一致 / Statement matches passage
FALSE：   题目信息与文章矛盾 / Statement contradicts passage
NOT GIVEN：文章没有提到这个信息 / Information not in passage

⚠️ 最难判断的是 FALSE vs NOT GIVEN
   FALSE = 文章说了相反的内容
   NOT GIVEN = 文章根本没提
```

#### 选择题 / Multiple Choice
```
1. 先读题目（不读选项）/ Read question first (not options)
2. 在文中定位相关内容 / Locate relevant content
3. 对照选项，排除法 / Compare options, use elimination
4. 警惕"几乎正确"的干扰选项 / Watch for "almost correct" distractors
```

#### 标题匹配 / Heading Matching
```
1. 先读所有标题选项 / Read all heading options first
2. 读每段首尾句 / Read first and last sentences of each paragraph
3. 找到主旨，而非细节 / Find main idea, not details
4. 先做最明显的段落，最后做不确定的
   Do obvious matches first, save uncertain ones for last
```

### 5.4 紧急情况 / Emergency Scenarios

| 情况 / Scenario | 应对 / Action |
|---|---|
| 时间不够 / Running out of time | 剩余题目全部猜同一个选项 / Guess same letter for all remaining |
| 文章太难看不懂 / Passage too hard | 跳到下一题型，先做能定位的题 / Skip to next question type |
| 纠结于某题 / Stuck on a question | 给自己 30 秒，不行就跳过 / Give 30 seconds, then skip |
| 答案不确定 / Uncertain answer | 先写上，最后有时间再改 / Write something, review later |

## 6. 写作考试 / Writing Test

> 时间：60 分钟（2 篇作文）
> Duration: 60 minutes (2 tasks)

### 6.1 时间分配 / Time Allocation

```
⏰ 严格时间分配 / Strict Time Allocation:

Task 1：20 分钟 / 20 minutes
├── 审题+构思：3 分钟 / Analyze + plan: 3 min
├── 写作：14 分钟 / Write: 14 min
└── 检查：3 分钟 / Proofread: 3 min

Task 2：40 分钟 / 40 minutes
├── 审题+构思：5 分钟 / Analyze + plan: 5 min
├── 写作：30 分钟 / Write: 30 min
└── 检查：5 分钟 / Proofread: 5 min

⚠️ 先写 Task 2（分数权重更高）
⚠️ Write Task 2 FIRST (higher weight)
```

### 6.2 Task 1 快速攻略 / Task 1 Quick Strategy

**图表题 / Chart/Graph：**
```
第一段：改写题目（1-2 句）
Para 1: Paraphrase the question (1-2 sentences)

第二段：概述主要趋势（Overall 2-3 句）
Para 2: Overview — main trends (2-3 sentences)

第三段：详细描述数据组 1
Para 3: Detailed description - data group 1

第四段：详细描述数据组 2
Para 4: Detailed description - data group 2
```

**常用开头句型 / Useful Opening Sentences：**
```
The chart/graph/table illustrates/shows/depicts...
According to the chart/graph/table...
As is shown/illustrated in the...
It is evident/noticeable from the... that...
```

### 6.3 Task 2 快速攻略 / Task 2 Quick Strategy

**标准结构 / Standard Structure：**
```
Introduction (2-3 句):
├── 背景引入 / Background
├── 改写题目 / Paraphrase the question
└── 表明立场 / State your position

Body Paragraph 1 (5-7 句):
├── 主题句 / Topic sentence
├── 解释 / Explanation
├── 举例 / Example
└── 小结 / Mini-conclusion

Body Paragraph 2 (5-7 句):
├── 主题句 / Topic sentence
├── 解释 / Explanation
├── 举例 / Example
└── 小结 / Mini-conclusion

Conclusion (2-3 句):
├── 总结观点 / Summarize main points
└── 重申立场 / Restate position
```

### 6.4 检查清单 / Proofreading Checklist

```
Task 1 检查 / Task 1 Check:
□ 字数 ≥ 150 词 / Word count ≥ 150
□ 有 Overview 段 / Has Overview paragraph
□ 数据描述准确 / Data description accurate
□ 时态一致 / Tense consistency

Task 2 检查 / Task 2 Check:
□ 字数 ≥ 250 词 / Word count ≥ 250
□ 回应了题目所有部分 / Addressed all parts
□ 每段有主题句 / Topic sentence in each paragraph
□ 论证有逻辑 / Arguments are logical
□ 结论清晰 / Clear conclusion

通用检查 / General Check:
□ 拼写 / Spelling
□ 标点符号 / Punctuation
□ 主谓一致 / Subject-verb agreement
□ 冠词使用 / Article usage
□ 时态一致性 / Tense consistency
□ 大小写 / Capitalization
```

## 7. 口语考试 / Speaking Test

> 时间：11-14 分钟
> Duration: 11-14 minutes
> 可能在笔试当天或前后一天进行
> May be on test day or a day before/after

### 7.1 考试结构 / Test Structure

| 部分 / Part | 时间 / Duration | 内容 / Content |
|---|---|---|
| **Part 1** | 4-5 分钟 | 日常话题问答 / Everyday topics Q&A |
| **Part 2** | 3-4 分钟 | 话题卡独白 / Cue card monologue |
| **Part 3** | 4-5 分钟 | 深入讨论 / Abstract discussion |

### 7.2 Part 1 攻略 / Part 1 Strategy

**常见话题 / Common Topics：**
- 你的家乡 / Hometown
- 工作或学习 / Work or study
- 兴趣爱好 / Hobbies
- 食物 / Food
- 天气 / Weather
- 交通 / Transport
- 节假日 / Holidays
- 阅读 / Reading
- 运动 / Sports

**回答框架 / Answer Framework：**
```
直接回答 + 原因/细节 + 补充说明
Direct answer + reason/detail + additional info

示例 / Example:
Q: Do you like cooking?
A: "Yes, I do actually. [直接回答] I find it really relaxing after 
a long day at work — it's almost like a form of meditation for me. 
[原因] I mainly enjoy making Chinese dishes, especially stir-fries, 
because they're quick and you can be quite creative with the 
ingredients. [补充]"
```

**答题时间 / Answer Length：**
- 2-4 句话即可 / 2-4 sentences is enough
- 不要只说 "Yes" 或 "No" / Don't just say "Yes" or "No"
- 也不要滔滔不绝说一分钟 / Don't ramble for a full minute

### 7.3 Part 2 攻略 / Part 2 Strategy

**话题卡结构 / Cue Card Structure：**
```
Describe a place you visited that you liked.
You should say:
- where it is
- when you went there
- what you did there
and explain why you liked it.
```

**1 分钟准备策略 / 1-Minute Preparation：**
```
0-20 秒：审题，确定核心主题
0-20s: Read card, identify core theme

20-40 秒：为每个提示点想 1-2 个关键词
20-40s: Think of 1-2 keywords per bullet point

40-60 秒：组织开头句，想一个好例子
40-60s: Organize opening sentence, think of a good example
```

**2 分钟发言模板 / 2-Minute Speaking Template：**
```
开头 (15 秒)：引入话题
Opening (15s): Introduce the topic
"I'd like to talk about..."

要点 1 (30 秒)：第一个提示点
Point 1 (30s): First bullet point

要点 2 (30 秒)：第二个提示点
Point 2 (30s): Second bullet point

要点 3 (30 秒)：第三个提示点
Point 3 (30s): Third bullet point

总结 (15 秒)：解释为什么重要/印象深刻
Conclusion (15s): Explain why it's important/impressive
```

### 7.4 Part 3 攻略 / Part 3 Strategy

**回答框架 / Answer Framework：**
```
观点 + 原因 + 举例 + 对比/让步
Opinion + Reason + Example + Contrast/Concession

示例 / Example:
Q: How has technology changed education?

A: "Well, I think technology has fundamentally transformed 
education in many ways. [观点] For one thing, it has made 
information much more accessible — students can now access 
courses from top universities around the world through 
platforms like Coursera. [原因+举例] However, I should point 
out that this doesn't necessarily mean the quality of education 
has improved, because there's a lot of unreliable information 
online as well. [让步]"
```

### 7.5 口语考试注意事项 / Speaking Test Dos and Don'ts

| ✅ 做 / Do | ❌ 不做 / Don't |
|---|---|
| 保持眼神交流 / Maintain eye contact | 盯着天花板或地板 / Stare at ceiling or floor |
| 微笑，放松 / Smile, be relaxed | 面无表情，僵硬 / Poker face, stiff |
| 没听清可以请求重复 / Ask to repeat if missed | 假装听懂然后答非所问 / Fake understanding |
| 适当用手势辅助表达 / Use gestures naturally | 全程一动不动 / Be completely still |
| 承认不知道然后尝试回答 / Admit + try anyway | 说"I don't know"然后沉默 / Say nothing |
| 展示词汇多样性 / Show vocabulary range | 反复用同一个词 / Repeat same word |
| 使用连接词组织回答 / Use discourse markers | 答案杂乱无章 / Ramble without structure |

### 7.6 进入考场时的礼仪 / Entry Etiquette

```

   "Good morning/afternoon."
```

## 8. 考后事项 / After the Exam

### 8.1 成绩查询 / Score Inquiry

| 类型 / Type | 出分时间 / Score Release | 查询方式 / How to Check |
|---|---|---|
| 机考 / Computer-delivered | 3-5 个工作日 / 3-5 business days | IELTS 官网 / Official website |
| 纸笔考试 / Paper-based | 13 个日历日 / 13 calendar days | IELTS 官网 / Official website |

### 8.2 成绩复议 / Score Review (Enquiry on Results)

```
如果对成绩不满意 / If unsatisfied with scores:

1. 申请时间：考试日期后 6 周内
   Apply within 6 weeks of test date

2. 费用：约 1400 元人民币（2024 年标准）
   Fee: ~1400 RMB (2024 standard)

3. 可以复议单科或多科
   Can request review for one or more sections

4. 处理时间：2-21 天
   Processing: 2-21 days

5. 结果：
   - 分数提高 → 退还复议费 + 新成绩单
   - 分数不变 → 不退费，成绩不变
   - 分数降低 → 极少发生，以新分数为准
```

**什么情况建议复议 / When to Consider Re-mark：**
- 写作或口语分数明显低于预期 / Writing or Speaking significantly lower than expected
- 其他科分数正常，只有 1 科异常低 / Other sections normal, one abnormally low
- 差 0.5 分达到目标 / 0.5 band away from target
- 有明确理由相信评分有误 / Clear reason to believe scoring error

### 8.3 如何看待成绩 / How to View Your Score

```
✅ 健康的心态 / Healthy mindset:

成绩理想 → 继续保持，为下一阶段做准备
Good score → Maintain, prepare for next stage

成绩不理想 → 分析原因，制定改进计划，再战
Below target → Analyze reasons, plan improvement, retake

差 0.5 分 → 考虑复议，同时准备重考
0.5 short → Consider re-mark, prepare retake simultaneously

差 1 分以上 → 明确弱项，针对性提升后重考
1+ bands short → Identify weaknesses, targeted improvement, retake
```

## 9. 紧急情况处理 / Emergency Handling

### 9.1 常见紧急情况 / Common Emergencies

| 紧急情况 / Emergency | 处理方案 / Solution |
|---|---|
| **忘带身份证** / Forgot ID | 立即联系考场，看是否有替代证件方案 |
| **迟到** / Running late | 赶紧去！口语考试迟到 15 分钟不能入场 |
| **身体不适** / Feeling unwell | 告知监考人员，他们会提供帮助 |
| **听力设备故障** / Equipment failure | 立即举手示意监考人员 |
| **铅笔断了** / Pencil breaks | 举手向监考人员要备用铅笔 |
| **看不清试卷** / Can't see clearly | 举手要求换座位或调亮灯光 |
| **紧张到手抖** / Anxiety/nervousness | 深呼吸 3 次，喝口水，告诉自己"我能行" |

### 9.2 突发焦虑应对 / Sudden Anxiety Management

**3-3-3 法则 / 3-3-3 Rule：**
```
看 3 样东西：观察你周围的 3 样物体
Look at 3 things: observe 3 objects around you

动 3 个部位：活动手指、脚趾、肩膀
Move 3 body parts: wiggle fingers, toes, shoulders

听 3 种声音：注意你能听到的 3 种声音
Listen to 3 sounds: notice 3 sounds you can hear
```

**快速正念呼吸 / Quick Mindful Breathing：**
```
闭眼 / Close eyes
吸气 4 秒 / Inhale 4 seconds
屏气 4 秒 / Hold 4 seconds
呼气 6 秒 / Exhale 6 seconds
重复 3 次 / Repeat 3 times
睁眼，继续考试 / Open eyes, continue
```
