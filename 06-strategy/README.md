## 一、IELTS 考试概览 / IELTS Exam Overview

### 1.1 考试类型 / Exam Types

| 类型 / Type | 用途 / Purpose | 考试内容 / Content |
|---|---|---|
| **Academic (A类)** | 留学申请 / University admission | 学术类阅读和写作 / Academic Reading & Writing |
| **General Training (G类)** | 移民、工作 / Immigration, work | 培训类阅读和写作 / General Reading & Writing |
| **IELTS for UKVI** | 英国签证 / UK visa | 同上，额外安全措施 / Same, extra security |
| **IELTS Life Skills** | 英国签证口语/听力 / UK visa speaking/listening | 仅口语和听力 / Speaking & Listening only |

### 1.2 四科分值与时间 / Sections, Scoring & Timing

| 科目 / Section | 时间 / Duration | 题目数 / Questions | 分数范围 / Score Range |
|---|---|---|---|
| **Listening 听力** | 30分钟 + 10分钟誊写 / 30 min + 10 min transfer | 40题 / 40 questions | 0-9 分 / Band 0-9 |
| **Reading 阅读** | 60分钟 / 60 minutes | 40题 / 40 questions | 0-9 分 / Band 0-9 |
| **Writing 写作** | 60分钟 / 60 minutes | 2篇 / 2 tasks | 0-9 分 / Band 0-9 |
| **Speaking 口语** | 11-14分钟 / 11-14 minutes | 3部分 / 3 parts | 0-9 分 / Band 0-9 |

**总分计算 / Overall Score Calculation：**
总分 = 四科平均分，四舍五入到最近的 0.5 分
Overall = average of four sections, rounded to nearest 0.5

```
例 / Example:
Listening 7.0 + Reading 6.5 + Writing 6.0 + Speaking 7.0 = 26.5
26.5 / 4 = 6.625 → 四舍五入 → Overall 6.5
```

## 二、备考策略框架 / Preparation Strategy Framework

### 2.1 四阶段备考法 / Four-Phase Approach

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  Phase 1    │    │  Phase 2    │    │  Phase 3    │    │  Phase 4    │
│  诊断评估    │ →  │  基础夯实    │ →  │  强化训练    │ →  │  冲刺模考    │
│  Diagnostic  │    │  Foundation  │    │  Intensive   │    │  Mock & Final│
│  (1-2 周)    │    │  (4-8 周)    │    │  (4-8 周)    │    │  (2-4 周)    │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

#### Phase 1：诊断评估 / Diagnostic Assessment (1-2 weeks)

**目标 / Goals：**
- 做一套完整真题，了解当前水平 / Take a full practice test to assess current level
- 识别各科强弱项 / Identify strengths and weaknesses per section
- 确定目标分数 / Set target band score

**行动 / Actions：**
1. 剑桥真题做一套完整模考 / Complete one Cambridge practice test under timed conditions
2. 对照评分标准打分 / Score using official conversion tables
3. 记录各科分数和错题类型 / Record scores and error types
4. 制定个性化学习计划 / Create personalized study plan

#### Phase 2：基础夯实 / Foundation Building (4-8 weeks)

**目标 / Goals：**
- 扩充词汇量至 6000-8000 词 / Build vocabulary to 6000-8000 words
- 掌握核心语法结构 / Master core grammar structures
- 熟悉各题型解题方法 / Learn question-type strategies

**每日任务 / Daily Tasks：**
- 词汇：每天 30-50 个新词 + 复习 / Vocabulary: 30-50 new words + review
- 听力：精听 1 个 Section / Listening: intensive listen 1 section
- 阅读：精读 1 篇文章 / Reading: close read 1 passage
- 写作：学习 1 个写作技巧 / Writing: learn 1 writing technique
- 口语：练习 1 个话题 / Speaking: practice 1 topic

#### Phase 3：强化训练 / Intensive Training (4-8 weeks)

**目标 / Goals：**
- 大量刷题，提升速度和准确率 / Extensive practice for speed and accuracy
- 掌握各题型高频技巧 / Master high-frequency strategies per question type
- 建立错题本，分析错误模式 / Build error log, analyze patterns

**每日任务 / Daily Tasks：**
- 听力：完成 1 套完整听力 / Listening: complete 1 full test
- 阅读：完成 1 套完整阅读 / Reading: complete 1 full test
- 写作：Task 1 + Task 2 各写 1 篇 / Writing: write 1 Task 1 + 1 Task 2
- 口语：Part 1-3 完整练习 / Speaking: practice all 3 parts

#### Phase 4：冲刺模考 / Mock & Final Review (2-4 weeks)

**目标 / Goals：**
- 全真模拟考试环境 / Simulate real test conditions
- 稳定发挥，调整心态 / Stabilize performance, manage anxiety
- 查漏补缺 / Fill remaining gaps

**每日任务 / Daily Tasks：**
- 每 2 天做 1 套完整模考 / Full mock test every 2 days
- 分析模考错题 / Analyze mock test errors
- 复习高频词汇和模板 / Review high-frequency vocabulary and templates
- 口语模拟面试 / Mock speaking interviews

### 2.2 各科核心策略 / Core Strategies per Section

#### 听力 Listening

```
🎯 核心原则 / Core Principles:
├── 预读题目是关键 / Pre-reading questions is KEY
├── 同义替换是考点 / Paraphrasing is the test point
├── 注意信号词 / Listen for signal words
└── 蘸写时检查拼写 / Check spelling when transferring
```

**高频信号词 / High-frequency Signal Words：**
- 转折 / Contrast: however, but, although, on the other hand
- 强调 / Emphasis: in fact, actually, especially, particularly
- 列举 / Listing: firstly, secondly, moreover, furthermore
- 总结 / Summary: in conclusion, to sum up, overall
- 否定 / Negation: not, never, hardly, rarely, seldom

#### 阅读 Reading

```
🎯 核心原则 / Core Principles:
├── 先看题目再看文章 / Read questions BEFORE the passage
├── 定位词找答案 / Use keywords to locate answers
├── 同义替换识别 / Recognize paraphrasing
└── 时间分配：20分钟/篇 / Time allocation: 20 min/passage
```

**题型难度排序 / Question Type Difficulty Ranking：**
1. 填空题 Fill in the blanks (最容易 / easiest)
2. 判断题 TRUE/FALSE/NOT GIVEN
3. 选择题 Multiple choice
4. 配对题 Matching
5. 标题配对 Heading matching (最难 / hardest)

#### 写作 Writing

```
🎯 核心原则 / Core Principles:
├── Task 2 权重是 Task 1 的两倍 / Task 2 worth double Task 1
├── 结构清晰比词汇华丽更重要 / Structure > fancy vocabulary
├── 字数要求必须满足 / Meet minimum word count
└── 留 5 分钟检查 / Reserve 5 min for proofreading
```

**时间分配 / Time Allocation：**
- Task 1：20 分钟 / 20 minutes (150+ words)
- Task 2：40 分钟 / 40 minutes (250+ words)
- 检查：5 分钟 / 5 minutes (预留，不计入上述时间)

#### 口语 Speaking

```
🎯 核心原则 / Core Principles:
├── 流利度 > 准确度 > 词汇 > 发音
│   Fluency > Accuracy > Vocabulary > Pronunciation
├── 不要背模板，会被扣分 / Don't memorize — penalized
├── 展示语言能力 / Showcase language range
└── 保持眼神交流 / Maintain eye contact
```

## 四、心态管理 / Mental Health & Mindset

### 4.1 备考压力管理 / Stress Management During Preparation

| 压力来源 / Stress Source | 应对策略 / Coping Strategy |
|---|---|
| 分数瓶颈 / Score plateau | 调整方法，不要盲目刷题 / Change method, stop blind drilling |
| 时间不够 / Not enough time | 优先弱项，合理分配 / Prioritize weak areas |
| 模考分数低 / Low mock scores | 模考是学习机会，不是最终结果 / Mocks are learning, not final |
| 和别人比较 / Comparing with others | 只和自己的昨天比 / Compare only with your past self |

### 4.2 考前焦虑缓解 / Pre-Exam Anxiety Relief

- ✅ 充分准备是最好的抗焦虑药 / Preparation is the best anxiety medicine
- ✅ 考前一周保证睡眠 / Ensure sleep the week before
- ✅ 考试当天做简单热身 / Light warm-up on test day
- ✅ 深呼吸，正念冥想 / Deep breathing, mindfulness
- ❌ 不要考前临时抱佛脚 / Don't cram the night before
- ❌ 不要过度关注他人 / Don't over-focus on others
