## 1. 模考的重要性 / Why Mock Tests Matter

### 1.1 模考 vs 普通练习 / Mock Tests vs Regular Practice

| 维度 / Dimension | 普通练习 / Regular Practice | 模拟考试 / Mock Test |
|---|---|---|
| **时间限制** / Time limit | 可以慢慢做 / Can take time | 严格计时 / Strictly timed |
| **环境** / Environment | 随意 / Casual | 模拟考场 / Simulates test center |
| **心态** / Mindset | 放松 / Relaxed | 紧张（接近真实）/ Tense (realistic) |
| **连续性** / Continuity | 可以分开做 / Can split | 一次性完成 / Complete in one sitting |
| **反馈价值** / Feedback value | 单科反馈 / Single section | 全面模拟 / Full simulation |
| **暴露问题** / Issues revealed | 技能问题 / Skill issues | 技能+体力+心态问题 / Skill+stamina+mindset |

### 1.2 模考的核心价值 / Core Value of Mock Tests

```
价值 1：发现真实水平 / Discover True Level
├── 平时做得好 ≠ 考试做得好
│   Good in practice ≠ good in exam
├── 模考是检验真实水平的唯一方法
│   Mocks are the only way to verify true level
└── 压力下的表现才是真实表现
    Performance under pressure is true performance

价值 2：暴露薄弱环节 / Expose Weak Points
├── 哪种题型容易错？/ Which question types are error-prone?
├── 时间分配是否合理？/ Is time allocation reasonable?
├── 哪个 Section 最弱？/ Which section is weakest?
└── 紧张时哪些错误会犯？/ What errors occur when nervous?

价值 3：锻炼考试耐力 / Build Exam Stamina
├── 2.5 小时连续考试需要体力和注意力
│   2.5 hours of continuous testing requires stamina
├── 后面的 Section 往往因为疲劳而丢分
│   Later sections often lose points due to fatigue
└── 模考帮助你适应长时间考试
    Mocks help adapt to long testing sessions

价值 4：优化时间管理 / Optimize Time Management
├── 每个 Section 该花多少时间？
│   How much time per section?
├── 哪些题需要快速跳过？
│   Which questions to skip quickly?
└── 检查时间够不够？
    Is there enough check time?
```

## 2. 模考前准备 / Pre-Mock Preparation

### 2.1 材料准备 / Material Preparation

```
必备材料 / Essential Materials：
□ 剑桥雅思真题（1 本）/ Cambridge IELTS test (1 book)
□ 答题纸（可打印空白答题卡）/ Answer sheet (printable blank)
□ 铅笔 2 支 + 橡皮 1 个 / 2 pencils + 1 eraser
□ 计时器/手表 / Timer/watch
□ 安静的房间 / Quiet room
□ 水 + 少量零食 / Water + light snack

可选材料 / Optional：
□ 耳机（播放听力用）/ Headphones (for listening)
□ 耳塞（隔音用）/ Earplugs (noise isolation)
□ 答案纸（提前打印好）/ Printed answer sheets
```

### 2.2 环境模拟 / Environment Simulation

```
最佳模考环境 / Ideal Mock Environment：

✅ 推荐 / Recommended：
├── 安静的书房或图书馆
│   Quiet study room or library
├── 桌面只有考试用品
│   Only test materials on desk
├── 手机关机或放在另一个房间
│   Phone off or in another room
├── 告诉家人/室友不要打扰
│   Tell family/roommates not to disturb
└── 有自然光或稳定的灯光
    Natural light or stable lighting

❌ 避免 / Avoid：
├── 咖啡厅（太吵）
│   Coffee shops (too noisy)
├── 躺在床上做（太放松）
│   In bed (too relaxed)
├── 边做边吃东西（分散注意力）
│   While eating (distracting)
└── 有 WiFi 的地方（容易分心）
    Places with WiFi (too tempting)
```

### 2.3 心态准备 / Mental Preparation

```
模考前心态调整 / Pre-Mock Mindset：

✅ 正确心态 / Correct Mindset：
├── "这是一次学习机会，不是最终考试"
│   "This is a learning opportunity, not the final exam"
├── "分数低了没关系，重要的是发现问题"
│   "Low score is OK — finding problems matters"
├── "我要模拟真实考试环境，认真对待"
│   "I'll simulate real conditions and take it seriously"
└── "模考分数波动是正常的"
    "Score fluctuations in mocks are normal"

❌ 错误心态 / Wrong Mindset：
├── "我一定要拿最高分"
│   "I must get the highest score"
├── "这次考不好就完蛋了"
│   "If I don't do well, I'm done"
└── "随便做做就好了"
    "I'll just do it casually"
```

## 3. 模考执行 / Mock Test Execution

### 3.1 完整模考流程 / Full Mock Test Flow

```
时间线 / Timeline (总约 3 小时 / ~3 hours total)：

00:00 - 00:10  准备阶段
               Preparation phase
               ├── 摆好材料 / Arrange materials
               ├── 设置计时器 / Set timer
               ├── 深呼吸 3 次 / Deep breathe 3 times
               └── 写下今日目标分数 / Write today's target

00:10 - 00:40  听力考试（30 分钟听音 + 10 分钟检查）
               Listening test (30 min + 10 min check)
               ├── 严格按照考试流程
               │   Follow test procedure strictly
               ├── 不能暂停或重听
               │   No pausing or replaying
               └── 10 分钟用于检查和蘸写
                   10 minutes for checking and transfer

00:40 - 01:40  阅读考试（60 分钟）
               Reading test (60 minutes)
               ├── 严格计时
               │   Strict timing
               ├── 不能查词典
               │   No dictionary
               └── 答案直接写在答题卡上
                   Write answers directly on answer sheet

01:40 - 01:50  休息（10 分钟）
               Break (10 minutes)
               ├── 上洗手间 / Restroom
               ├── 喝水 / Drink water
               ├── 简单活动身体 / Light stretching
               └── 不要玩手机！/ Don't check phone!

01:50 - 02:50  写作考试（60 分钟）
               Writing test (60 minutes)
               ├── Task 1 先写或 Task 2 先写（看你习惯）
               │   Task 1 first or Task 2 first (your preference)
               ├── 严格计时
               │   Strict timing
               └── 留 5 分钟检查
                   Reserve 5 minutes for proofreading

02:50 - 03:00  收尾
               Wrap up
               ├── 停笔 / Stop writing
               ├── 整理答题卡 / Organize answer sheets
               └── 准备对答案 / Prepare to check answers
```

### 3.2 时间管理监控 / Time Management Monitoring

**阅读时间检查点 / Reading Time Checkpoints：**
```
开始后 17 分钟 → Passage 1 应完成
At 17 min → Passage 1 should be done

开始后 37 分钟 → Passage 2 应完成
At 37 min → Passage 2 should be done

开始后 55 分钟 → Passage 3 应完成（留 5 分钟检查）
At 55 min → Passage 3 done (5 min for checking)
```

**写作时间检查点 / Writing Time Checkpoints：**
```
如果先写 Task 1 (20 min)：
00:00-00:03  审题 + 构思 / Analyze + plan
00:03-00:17  写作 / Write
00:17-00:20  检查 / Proofread

然后 Task 2 (40 min)：
00:20-00:25  审题 + 构思 / Analyze + plan
00:25-00:55  写作 / Write
00:55-01:00  检查 / Proofread
```

### 3.3 考试纪律 / Test Discipline

```
严格遵守 / Strictly Follow：
✅ 不能中途暂停（除非紧急情况）
   No pausing (except emergencies)
✅ 不能查字典或手机
   No dictionary or phone
✅ 不能看答案
   Don't peek at answers
✅ 不能重新听听力
   Can't replay listening
✅ 严格遵守每个 Section 的时间
   Strictly follow section timing

违反纪律的后果：
Discipline violations consequences:
→ 模考分数不真实 → 无法准确评估水平
→ Mock score inaccurate → can't assess true level
→ 自欺欺人 → 最终考试暴露真实水平
→ Self-deception → real exam exposes true level
```

## 4. 模考后分析 / Post-Mock Analysis

> ⚠️ **这是模考最重要的部分！分析比做题更重要！**
> This is the MOST important part of mock testing! Analysis > doing the test!

### 4.1 评分流程 / Scoring Process

```
步骤 1：对答案 / Step 1: Check answers (30 min)
├── 听力：逐题对照，标记对错
│   Listening: check each, mark right/wrong
├── 阅读：逐题对照，标记对错
│   Reading: check each, mark right/wrong
├── 写作：对照评分标准自评
│   Writing: self-assess using band descriptors
└── 口语：录音回听 + 自评（如有录音）
    Speaking: listen back + self-assess (if recorded)

步骤 2：计算分数 / Step 2: Calculate scores (10 min)
├── 听力：正确题数 → 查换算表 → Band Score
│   Listening: correct count → conversion table → Band
├── 阅读：正确题数 → 查换算表 → Band Score
│   Reading: correct count → conversion table → Band
├── 写作：(TA + CC + LR + GRA) / 4 → Task 1×1/3 + Task 2×2/3
│   Writing: (TA + CC + LR + GRA) / 4 → weighted average
└── 口语：(FC + LR + GRA + P) / 4
    Speaking: (FC + LR + GRA + P) / 4
```

### 4.3 错误类型分类 / Error Type Classification

```
听力错误类型 / Listening Error Types：

类型 A：词汇问题 / Vocabulary Issue
├── 表现：听到但拼写错误，或不认识该词
├── 表现：Heard but misspelled, or didn't know word
├── 解决：加强词汇听写练习
└── 解决：More dictation practice

类型 B：节奏问题 / Pacing Issue
├── 表现：没听到答案，因为正在看上一题
├── 表现：Missed answer because reading previous question
├── 解决：练习预读和快速反应
└── 解决：Practice pre-reading and quick response

类型 C：理解问题 / Comprehension Issue
├── 表现：听到了但不理解意思
├── 表现：Heard but didn't understand meaning
├── 解决：精听训练 + 词汇扩展
└── 解决：Intensive listening + vocabulary

类型 D：注意力问题 / Attention Issue
├── 表现：走神，错过了几个题
├── 表现：Lost focus, missed several questions
├── 解决：注意力训练 + 冥想
└── 解决：Focus training + meditation
```

```
阅读错误类型 / Reading Error Types：

类型 A：定位问题 / Location Issue
├── 表现：答案在文中但没找到
├── 表现：Answer in passage but couldn't find it
├── 解决：练习关键词定位 + 同义替换识别
└── 解决：Keyword location + paraphrase recognition

类型 B：理解问题 / Comprehension Issue
├── 表现：找到了答案区域但理解错误
├── 表现：Found area but misunderstood
├── 解决：长难句分析 + 词汇扩展
└── 解决：Complex sentence analysis + vocabulary

类型 C：判断问题 / Judgment Issue
├── 表现：T/F/NG 判断错误
├── 表现：Wrong T/F/NG judgment
├── 解决：专项练习 T/F/NG 题型
└── 解决：Focused T/F/NG practice

类型 D：时间问题 / Time Issue
├── 表现：后面几题没时间做
├── 表现：Last questions unfinished
├── 解决：优化时间分配 + 提速训练
└── 解决：Optimize time allocation + speed training
```

## 5. 模考频率和节奏 / Mock Test Frequency & Pacing

### 5.1 按备考阶段的模考频率 / Frequency by Phase

| 阶段 / Phase | 频率 / Frequency | 目的 / Purpose |
|---|---|---|
| **基础期** (Month 1-2) | 每 2 周 1 次 / 1 per 2 weeks | 了解水平，熟悉题型 |
| **强化期** (Month 3-4) | 每周 1 次 / 1 per week | 监控进步，调整策略 |
| **冲刺期** (Month 5) | 每周 2 次 / 2 per week | 提升稳定性和耐力 |
| **最后 2 周** | 每 2 天 1 次 / 1 per 2 days | 保持状态，建立信心 |
| **考前 3 天** | 1 次（最后模考）/ 1 (final mock) | 确认状态，不再关注分数 |

### 5.2 模考 vs 精练的时间比例 / Mock vs Focused Practice Ratio

```
基础期 / Foundation Phase:
├── 模考：20%（每 2 周一次完整模考）
├── 精练：60%（各科专项训练）
└── 分析：20%（错题分析 + 方法学习）

强化期 / Intensive Phase:
├── 模考：30%（每周一次完整模考）
├── 精练：50%（各科强化训练）
└── 分析：20%（错题分析 + 策略调整）

冲刺期 / Sprint Phase:
├── 模考：50%（每周 2 次完整模考）
├── 精练：30%（弱项集中突破）
└── 分析：20%（深度分析 + 最后调整）
```

### 5.3 单科模考 vs 全科模考 / Section vs Full Mock

```
单科模考 / Section Mock (30-60 分钟)：
├── 适合：只有一科弱，需要集中训练
│   For: Only one weak section, focused training
├── 优点：时间短，可以每天做
│   Pros: Short, can do daily
├── 缺点：不能训练考试耐力
│   Cons: Can't train exam stamina
└── 推荐：周一到周五各科单独练
    Recommendation: Mon-Fri individual sections

全科模考 / Full Mock (3+ 小时)：
├── 适合：需要检验整体水平
│   For: Testing overall level
├── 优点：完全模拟真实考试
│   Pros: Fully simulates real exam
├── 缺点：时间长，需要集中精力
│   Cons: Long, requires focus
└── 推荐：周末做完整模考
    Recommendation: Weekend full mocks
```

## 6. 各科模考技巧 / Section-Specific Mock Tips

### 6.1 听力模考技巧 / Listening Mock Tips

```
考前 / Before：
├── 确保耳机/音响正常工作
│   Ensure headphones/speakers work properly
├── 调好音量（不要太响也不要太轻）
│   Set volume (not too loud or soft)
└── 提前预读 Section 1 题目
    Pre-read Section 1 questions

考中 / During：
├── 边听边写答案（不要等到最后）
│   Write answers while listening (don't wait)
├── 没听到的题立刻猜一个，标记后跳过
│   Guess if missed, mark and skip
├── 利用 Section 间隙预读下一 Section
│   Use gaps to pre-read next section
└── 不要纠结已错过的题
    Don't dwell on missed questions

考后 / After：
├── 统计每个 Section 的正确率
│   Count accuracy per section
├── 分析 Section 3-4 的错题类型
│   Analyze Section 3-4 error types
└── 记录没听到的原因
    Record reasons for missed answers
```

### 6.2 阅读模考技巧 / Reading Mock Tips

```
考前 / Before：
├── 准备好计时器
│   Prepare timer
└── 准备好空白答题卡
    Prepare blank answer sheet

考中 / During：
├── 每 17-20 分钟检查时间
│   Check time every 17-20 minutes
├── 某题超过 2 分钟 → 猜一个跳过
│   Question >2 min → guess and skip
├── 答案直接写在答题卡上（节省时间）
│   Write directly on answer sheet (save time)
└── 最后 5 分钟检查所有答案
    Check all answers in last 5 minutes

考后 / After：
├── 统计每种题型的正确率
│   Count accuracy per question type
├── 分析时间分配是否合理
│   Analyze time allocation
└── 找出最耗时的题型
    Find most time-consuming question type
```

### 6.3 写作模考技巧 / Writing Mock Tips

```
考前 / Before：
├── 确认计时器已设置
│   Confirm timer set
└── 准备好答题纸（或白纸）
    Prepare answer paper

考中 / During：
├── 先审题，花 3-5 分钟构思
│   Analyze question, spend 3-5 min planning
├── Task 1 严格 20 分钟，Task 2 严格 40 分钟
│   Task 1 strict 20 min, Task 2 strict 40 min
├── 写完后用剩余时间检查
│   Use remaining time to proofread
```

## 7. 模考常见问题 / Common Mock Test Issues

### 7.1 分数相关问题 / Score-Related Issues

**Q：模考分数忽高忽低怎么办？/ Score fluctuates — what to do?**
```
原因分析 / Cause Analysis：
├── 不同套题难度不同
│   Different tests have different difficulty
├── 状态不同（疲劳、情绪）
│   Different states (fatigue, mood)
├── 做过的题可能分数偏高
│   Previously done tests may inflate scores
└── 正常波动范围：±0.5 分
    Normal fluctuation: ±0.5 band

解决方法 / Solution：
├── 用 3 次以上模考的平均分评估水平
│   Use average of 3+ mocks to assess level
├── 关注趋势而非单次分数
│   Focus on trend, not single score
├── 记录每次模考的状态
│   Record state for each mock
└── 分数波动超过 1 分 → 可能是方法问题
    Fluctuation >1 band → likely method issue
```

**Q：模考分数比预期低很多？/ Mock score much lower than expected?**
```
可能原因 / Possible Causes：
├── 平时练习不限时，考试时间不够
│   Untimed practice, not enough time in test
├── 平时做过的题，分数虚高
│   Previously done tests inflate scores
├── 考试紧张影响发挥
│   Anxiety affects performance
└── 某一科拖了后腿
    One section drags overall

解决方法 / Solution：
├── 严格限时做新题
│   Strictly time new tests only
├── 分析具体哪科最弱
│   Identify weakest section
├── 针对性训练
│   Targeted training
└── 心态调整训练
    Mindset training
```

### 7.2 执行相关问题 / Execution Issues

**Q：做着做着就分心了？/ Losing focus during mock?**
```
解决方法 / Solutions：
├── 缩短模考时间（先做单科模考）
│   Shorten mock time (start with section mocks)
├── 冥想练习（每天 5 分钟，提升专注力）
│   Meditation (5 min daily, improve focus)
├── 保证充足睡眠
│   Ensure adequate sleep
├── 模考前不要做高强度脑力活动
│   Avoid intense mental activity before mock
└── 使用番茄钟训练专注力
    Use Pomodoro to train focus
```

**Q：时间总是不够？/ Always running out of time?**
```
解决方法 / Solutions：
├── 严格练习"跳过"能力
│   Practice "skipping" skills
├── 简单题快速做，难题先跳过
│   Quick on easy, skip hard ones first
├── 阅读每题最多 2 分钟
│   Max 2 minutes per reading question
├── 写作先列提纲再写
│   Outline before writing
└── 练习快速决策能力
    Practice quick decision-making
```

**Q：模考后不知道怎么分析？/ Don't know how to analyze after mock?**
```
分析步骤 / Analysis Steps：
1. 对答案，计算分数（10 分钟）
   Check answers, calculate score (10 min)
2. 标记所有错题，分类错误类型（15 分钟）
   Mark all errors, categorize types (15 min)
3. 找出错误模式（哪类错误最多？）（10 分钟）
   Find patterns (which error type most?) (10 min)
4. 制定下周改进计划（10 分钟）
   Make next week improvement plan (10 min)
5. 记录在模考日志中
   Record in mock test journal
```
