## 1. Band 5 → Band 6 提升方案

> 核心任务：基础补漏 + 建立考试感觉
> Core task: Fill foundation gaps + build test awareness

### 1.1 能力差距分析 / Capability Gap Analysis

| 维度 / Dimension | Band 5 水平 | Band 6 要求 | 差距 / Gap |
|---|---|---|---|
| **词汇量** / Vocabulary | ~4000 词 | ~6000 词 | 需增 2000 词 |
| **语法** / Grammar | 基础时态，简单句为主 | 能使用复合句，偶有错误 | 学习从句和特殊句式 |
| **听力** / Listening | Section 1-2 尚可，3-4 困难 | 各 Section 基本能跟上 | Section 3-4 专练 |
| **阅读** / Reading | 速度慢，理解不全面 | 60 分钟内完成 40 题 | 提速 + 定位训练 |
| **写作** / Writing | 结构混乱，论证不足 | 结构清晰，有基本论证 | 学习标准结构 |
| **口语** / Speaking | 停顿多，表达有限 | 能流利表达日常话题 | 流利度训练 |

### 1.2 各科提分策略 / Section-by-Section Strategy

#### 听力：从 5.0 到 6.0 (正确 23-26 题)

```
当前问题 / Current Issues:
├── Section 1-2 丢分多（基础题没抓住）
├── Section 3-4 基本听不懂
└── 拼写错误导致白白丢分

训练方案 / Training Plan:

阶段 1（第 1-2 周）：夯实基础
Phase 1 (Week 1-2): Solidify foundation
├── 每天听写 Section 1 原文 15 分钟
│   Dictate Section 1 transcript 15 min daily
├── 整理高频场景词汇（租房、旅游、图书馆等）
│   Compile high-frequency scenario vocabulary
├── 练习数字、日期、地址、电话号码的听写
│   Practice dictating numbers, dates, addresses, phone numbers
└── 确保 Section 1-2 正确率 ≥ 80%
    Ensure Section 1-2 accuracy ≥ 80%

阶段 2（第 3-4 周）：攻克 Section 3
Phase 2 (Week 3-4): Crack Section 3
├── 学习学术讨论场景词汇
│   Learn academic discussion vocabulary
├── 练习选择题和配对题
│   Practice multiple choice and matching
├── 听力精听：逐句听 → 理解 → 对照
│   Intensive listening: sentence by sentence → understand → check
└── 目标：Section 3 正确率 ≥ 50%
    Target: Section 3 accuracy ≥ 50%

阶段 3（第 5-6 周）：接触 Section 4
Phase 3 (Week 5-6): Tackle Section 4
├── 先从简单的 Section 4 开始（科学类话题）
│   Start with easier Section 4 (science topics)
├── 学术讲座词汇积累
│   Academic lecture vocabulary building
├── 练习长段落填空题
│   Practice long gap-fill questions
└── 目标：Section 4 正确 3-4 题即可
    Target: Section 4 correct 3-4 questions is enough
```

**每日任务 / Daily Tasks (1 小时)：**
```
07:00-07:15  场景词汇背诵 + 复习 / Scenario vocabulary + review
07:15-07:35  听力精听训练（1个 Section）/ Intensive listening (1 section)
07:35-07:55  套题练习（1个 Section）/ Practice test (1 section)
07:55-08:00  错题分析 + 记录 / Error analysis + logging
```

#### 阅读：从 5.0 到 6.0 (正确 23-26 题)

```
当前问题 / Current Issues:
├── 阅读速度太慢 / Reading speed too slow
├── 不知道怎么定位答案 / Don't know how to locate answers
├── 同义替换识别不了 / Can't recognize paraphrasing
└── 判断题 T/F/NG 混淆 / Confused by T/F/NG

训练方案 / Training Plan:

阶段 1（第 1-2 周）：提升阅读速度
Phase 1 (Week 1-2): Improve reading speed
├── 每天泛读 1 篇 500-800 词英文文章
│   Extensive reading: 1 article (500-800 words) daily
├── 学会跳过不认识的词（根据上下文猜意思）
│   Skip unknown words (guess from context)
├── 训练快速找到段落主旨句（通常在段首）
│   Find topic sentences quickly (usually first sentence)
└── 目标：阅读速度达到 200 wpm
    Target: reading speed 200 wpm

阶段 2（第 3-4 周）：学习做题技巧
Phase 2 (Week 3-4): Learn question strategies
├── 填空题：先看题再定位，答案通常是原词
│   Fill-in: read question first, answer usually exact words
├── 判断题：区分 FALSE（矛盾）和 NOT GIVEN（未提及）
│   T/F/NG: distinguish FALSE (contradicts) from NOT GIVEN (not mentioned)
├── 选择题：排除法 + 定位关键句
│   Multiple choice: elimination + locate key sentences
└── 每天限时做 1 篇 / 1 timed passage daily

阶段 3（第 5-6 周）：套题训练
Phase 3 (Week 5-6): Full test training
├── 每周做 2 套完整阅读（严格 60 分钟）
│   2 full reading tests per week (strict 60 min)
├── 分析错题：定位错误 vs 理解错误 vs 陷阱
│   Analyze errors: locating vs comprehension vs trap
└── 目标：整套正确率 23-26 题
    Target: 23-26 correct per test
```

#### 写作：从 5.0 到 6.0

```
当前问题 / Current Issues:
├── 文章结构混乱 / Disorganized structure
├── 观点没有展开 / Ideas not developed
├── 语法错误较多 / Many grammar errors
└── 词汇单一 / Limited vocabulary

训练方案 / Training Plan:

Task 1 (5 分钟/天)：
├── 学习图表描述的标准结构（4 段式）
│   Learn standard chart description structure (4 paragraphs)
├── 积累描述趋势的动词和副词
│   Accumulate trend verbs and adverbs
├── 学习描述数据对比的句型
│   Learn comparison sentence patterns
└── 每周写 2 篇 Task 1 / Write 2 Task 1 per week

Task 2 (15 分钟/天)：
├── 学习议论文标准结构（4-5 段式）
│   Learn essay standard structure (4-5 paragraphs)
├── 每段要有：主题句 + 解释 + 例子
│   Each paragraph: topic sentence + explanation + example
├── 学习常用连接词和过渡句
│   Learn common linking words and transitions
├── 积累 20 个万能例子（教育、科技、环境等）
│   Accumulate 20 versatile examples (education, tech, environment)
└── 每周写 2 篇 Task 2 / Write 2 Task 2 per week

语法专项 (10 分钟/天)：
├── 周一：时态练习 / Tense practice
├── 周二：定语从句 / Relative clauses
├── 周三：状语从句 / Adverbial clauses
├── 周四：被动语态 / Passive voice
├── 周五：常见语法错误纠正 / Common grammar error correction
└── 周末：复习 + 综合练习 / Review + comprehensive practice
```

#### 口语：从 5.0 到 6.0

```
当前问题 / Current Issues:
├── 回答太短（Yes/No 结束）/ Answers too short
├── 停顿太多，不流利 / Too many pauses
├── 词汇单一，反复用 same words / Limited vocabulary
└── 紧张导致大脑空白 / Nervousness causes mental blanks

训练方案 / Training Plan：

每日练习 (30 分钟) / Daily practice (30 min)：

第 1 周：Part 1 基础 / Part 1 basics
├── 收集 Part 1 高频话题 20 个
│   Collect 20 high-frequency Part 1 topics
├── 每个话题准备 3-4 句的回答思路
│   Prepare 3-4 sentence ideas for each topic
├── 练习"直接回答 + 原因 + 补充"的结构
│   Practice "direct answer + reason + supplement"
└── 每天录音 5 个话题，回听纠错
    Record 5 topics daily, listen back and correct

第 2 周：Part 2 独白 / Part 2 monologue
├── 收集 10 个高频话题卡
│   Collect 10 high-frequency cue cards
├── 练习 1 分钟快速准备能力
│   Practice 1-minute quick preparation
├── 练习说满 2 分钟的能力
│   Practice speaking for full 2 minutes
└── 使用"时间线法"或"五感法"扩展内容
    Use "timeline method" or "five senses method" to expand

第 3-4 周：Part 3 讨论 / Part 3 discussion
├── 学习抽象问题的答题框架
│   Learn answer frameworks for abstract questions
├── 练习给出观点 + 举例论证
│   Practice giving opinions + supporting with examples
├── 学习表达不同意见的礼貌方式
│   Learn polite ways to express disagreement
└── 每天找人模拟 10 分钟 / Find partner for 10 min daily mock
```

## 2. Band 6 → Band 7 提升方案

> 核心任务：从"及格"到"良好"，需要质的飞跃
> Core task: From "passing" to "good" — requires qualitative leap

### 2.1 能力差距分析 / Capability Gap Analysis

| 维度 / Dimension | Band 6 水平 | Band 7 要求 | 差距 / Gap |
|---|---|---|---|
| **词汇量** / Vocabulary | ~6000 词 | ~8000 词 | +2000 词，尤其是学术词汇和同义替换 |
| **语法** / Grammar | 能用复合句但错误较多 | 复杂句使用频繁且大部分正确 | 提高准确率 |
| **听力** / Listening | 正确 23-26 题 | 正确 30-32 题 | +4-9 题 |
| **阅读** / Reading | 正确 23-26 题 | 正确 30-32 题 | +4-9 题 |
| **写作** / Writing | 结构清晰但深度不够 | 论证深入，语言多样 | 论证深度 + 语言质量 |
| **口语** / Speaking | 能表达但不够灵活 | 流利、准确、多样 | 流利度 + 词汇多样性 |

### 2.2 关键突破点 / Key Breakthroughs

#### 听力突破：30-32 题正确 / Listening Breakthrough

```
瓶颈原因 / Bottleneck Causes:
├── Section 4 学术讲座听不懂细节
├── 同义替换反应不够快
└── 注意力不能持续 30 分钟

突破方案 / Breakthrough Plan:

1. 同义替换专项训练（核心中的核心！）
   Paraphrase training (THE core skill!)
   ├── 建立 300 组同义替换词汇表
   │   Build 300 paraphrase pairs
   ├── 每天听写时标注原文和题目中的替换
   │   Mark paraphrases during dictation
   └── 反复练习直到"秒反应"
       Practice until instant recognition

2. Section 4 精听突破
   Section 4 intensive listening
   ├── 选择剑桥真题 Section 4
   │   Use Cambridge test Section 4
   ├── 第一遍：正常做题 / First: normal test
   ├── 第二遍：精听，标注听不懂的地方
   │   Second: intensive, mark unclear parts
   ├── 第三遍：看原文，理解为什么听不懂
   │   Third: check transcript, understand why
   └── 第四遍：跟读模仿 / Fourth: shadow reading

3. 注意力训练
   Concentration training
   ├── 每周至少做 2 次完整 30 分钟听力
   │   At least 2 full 30-min listening per week
   ├── 练习在噪音环境下听（咖啡厅等）
   │   Practice in noisy environments
   └── 冥想练习（提升专注力）
       Meditation (improve focus)
```

#### 阅读突破：30-32 题正确 / Reading Breakthrough

```
瓶颈原因 / Bottleneck Causes:
├── Passage 3 复杂文章理解不透
├── 推理题和作者观点题做不对
├── 时间不够（最后一篇草草了事）
└── 标题匹配题正确率低

突破方案 / Breakthrough Plan:

1. 长难句攻克
   Complex sentence mastery
   ├── 每天分析 5 个长难句
   │   Analyze 5 complex sentences daily
   ├── 学会快速找到主语、谓语、宾语
   │   Learn to quickly find S, V, O
   ├── 熟悉各种从句嵌套
   │   Familiarize with clause nesting
   └── 限时 30 秒理解一个长难句
       30-second limit for comprehension

2. 推理和判断能力
   Inference and judgment
   ├── 区分"文中说了什么" vs "可以推断什么"
   │   Distinguish "stated" vs "inferred"
   ├── 练习识别作者态度和观点
   │   Practice identifying author's attitude
   └── 学习排除"看似正确但实际错误"的选项
       Learn to eliminate "seems correct but wrong" options

3. 速度优化
   Speed optimization
   ├── Passage 1 控制在 15 分钟
   │   Passage 1: 15 minutes max
   ├── Passage 2 控制在 18 分钟
   │   Passage 2: 18 minutes max
   └── 留 27 分钟给 Passage 3
       Save 27 minutes for Passage 3
```

#### 写作突破：达到 7.0 / Writing Breakthrough

```
瓶颈原因 / Bottleneck Causes:
├── 论证停留在表面（what 没有 why 和 how）
├── 词汇不够高级（反复用 important, think）
├── 语法错误集中在复杂句
└── Task 1 数据描述不够全面

突破方案 / Breakthrough Plan:

1. 论证深度提升
   Argument depth
   ├── 学习"为什么"链：观点→原因→深层原因→例子→影响
   │   Learn "why chain": point → reason → deep reason → example → impact
   ├── 每个观点至少写 3-4 句展开
   │   Expand each point in 3-4 sentences
   ├── 学习反驳和让步段落
   │   Learn counter-argument and concession paragraphs
   └── 阅读高分范文，标注论证方式
       Read high-score essays, mark argumentation methods

2. 语言质量提升
   Language quality
   ├── 掌握 50 组高级同义替换
   │   Master 50 advanced paraphrase groups
   ├── 学习学术化表达
   │   Learn academic expressions
   ├── 每周背诵 5 个好句子（从范文中提取）
   │   Memorize 5 good sentences weekly (from model essays)
   └── 练习复杂句的准确性
       Practice accuracy of complex structures

3. Task 1 全面提升
   Task 1 comprehensive improvement
   ├── 掌握所有图表类型（线图、柱图、饼图、表格、流程图、地图）
   │   Master all chart types
   ├── 学习数据对比和分组描述
   │   Learn data comparison and grouping
   ├── Overview 段要概括 2 个主要特征
   │   Overview: summarize 2 main features
   └── 每种类型至少练习 3 篇
       Practice at least 3 per type
```

#### 口语突破：达到 7.0 / Speaking Breakthrough

```
瓶颈原因 / Bottleneck Causes:
├── 回答模式化（不是真正交流）
├── Part 3 深度不够（只能说 1-2 句）
├── 发音有明显问题影响理解
└── 词汇不够灵活（不会地道表达）

突破方案 / Breakthrough Plan：

1. 从"回答问题"到"自然交流"
   From "answering" to "natural conversation"
   ├── 把口语练习当成和朋友聊天
   │   Treat practice like chatting with friends
   ├── 加入个人经历和感受
   │   Include personal stories and feelings
   ├── 使用自然的连接词（well, I mean, you know）
   │   Use natural discourse markers
   └── 不要追求完美，追求自然
       Don't aim for perfect, aim for natural

2. Part 3 深度讨论
   Part 3 deep discussion
   ├── 学习分类讨论法（按年龄/性别/地区分）
   │   Learn categorization (by age/gender/region)
   ├── 学习假设论证（如果...那么...）
   │   Learn hypothetical reasoning (if...then...)
   ├── 学习用具体数据和例子支持观点
   │   Support with data and examples
   └── 练习 30-45 秒的完整回答
       Practice 30-45 second complete answers

3. 发音提升
   Pronunciation improvement
   ├── 录音回听，标注发音问题
   │   Record and mark pronunciation issues
   ├── 重点攻克 th/v/w/l/r 等难音
   │   Focus on th/v/w/l/r difficult sounds
   ├── 练习句子重音和语调
   │   Practice sentence stress and intonation
   └── 跟读 BBC/VOA 模仿语调
       Shadow BBC/VOA for intonation
```

## 3. Band 7 → Band 8 提升方案

> 核心任务：从"良好"到"优秀"，需要精细化打磨
> Core task: From "good" to "excellent" — requires fine-tuning

### 3.1 能力差距分析 / Capability Gap Analysis

| 维度 / Dimension | Band 7 水平 | Band 8 要求 | 差距 / Gap |
|---|---|---|---|
| **词汇量** / Vocabulary | ~8000 词 | ~10000+ 词 | 学术精准用词 + 地道搭配 |
| **语法** / Grammar | 复杂句大部分正确 | 几乎无语法错误 | 消除残余错误 |
| **听力** / Listening | 正确 30-32 题 | 正确 35-36 题 | +3-6 题 |
| **阅读** / Reading | 正确 30-32 题 | 正确 35-36 题 | +3-6 题 |
| **写作** / Writing | 论证充分，语言多样 | 论证精准，语言自然优雅 | 自然度 + 精准度 |
| **口语** / Speaking | 流利表达，能深入讨论 | 接近母语者水平 | 自然度 + 发音细节 |

### 3.2 各科突破策略 / Section Breakthrough Strategies

#### 听力：正确 35-36 题 / Listening: 35-36 Correct

```
从 7 到 8，每一道题都不能丢。
From 7 to 8, you can't afford to lose any question.

训练重点 / Training Focus：

1. 零失误 Section 1-2
   Zero errors in Section 1-2
   ├── 这是"保分区"，必须全对
   │   This is your "safety zone" — must get all correct
   ├── 重点练习：数字、拼写、地址
   │   Focus: numbers, spelling, addresses
   └── 每周至少做 3 套 Section 1-2
       At least 3 Section 1-2 sets per week

2. Section 3-4 精确理解
   Section 3-4 precise comprehension
   ├── 精听剑桥真题所有 Section 3-4
   │   Intensive listen to ALL Cambridge Section 3-4
   ├── 学习识别学术讲座的结构（引言→主体→结论）
   │   Learn academic lecture structure
   ├── 注意"细节陷阱"（数字、日期、专有名词）
   │   Watch for "detail traps"
   └── 练习 1.25 倍速听力（考试时原速会觉得慢）
       Practice at 1.25x speed

3. 全真环境训练
   Realistic practice
   ├── 只用剑桥真题，不用模拟题
   │   Use only Cambridge tests, not simulations
   ├── 一次性完成 4 个 Section（不暂停）
   │   Complete all 4 sections without pause
   └── 模拟嘈杂环境（训练抗干扰能力）
       Practice in noisy environment
```

#### 阅读：正确 35-36 题 / Reading: 35-36 Correct

```
训练重点 / Training Focus：

1. 极速阅读能力
   Speed reading
   ├── 阅读速度达到 300+ wpm
   │   Reading speed 300+ wpm
```

## 6. 提分瓶颈突破 / Breaking Through Plateaus

### 6.1 识别瓶颈 / Identifying Plateaus

```
什么是瓶颈？/ What is a plateau?
连续 3-4 次模考，分数在同一个 Band 波动（±0.5 以内）
3-4 consecutive mocks with scores fluctuating within the same band (±0.5)

例 / Example:
模考 1：6.5  模考 2：6.0  模考 3：6.5  模考 4：6.5
→ 你遇到了 6.0-6.5 的瓶颈 / You've hit a 6.0-6.5 plateau
```

### 6.2 瓶颈原因分析 / Plateau Cause Analysis

| 可能原因 / Possible Cause | 表现 / Symptoms | 解决方案 / Solution |
|---|---|---|
| **方法不对** / Wrong method | 努力但没效果 / Working hard but no results | 换学习策略 / Change strategy |
| **基础不牢** / Weak foundation | 简单题也错 / Making easy mistakes | 回去补基础 / Go back to basics |
| **心理因素** / Psychological | 模考紧张，发挥失常 / Anxiety in mocks | 心态训练 / Mental training |
| **单项瓶颈** / One section bottleneck | 其他科在涨，某科不动 / Others improving, one stagnant | 集中突破该科 / Focus on that section |
| **练得不够** / Not enough practice | 知道方法但不熟练 / Know methods but not proficient | 增加练习量 / Increase volume |
| **方向偏离** / Off track | 练习材料或方法不适合 / Materials/methods don't fit | 评估调整 / Reassess and adjust |

### 6.3 瓶颈突破实用方法 / Practical Plateau-Breaking Methods

```
方法 1：换一种学习方式 / Change Learning Mode
├── 一直看视频课？→ 换成做题实战
├── 一直刷题？→ 换成精读范文
├── 一直自学？→ 找老师或学习小组
└── 一直用同一套教材？→ 换一本

方法 2：聚焦最小单位 / Focus on Smallest Unit
├── 不要泛泛地"提高听力"
│   Don't broadly "improve listening"
├── 而是"提高 Section 4 地理话题填空题的正确率"
│   Instead: "improve Section 4 geography topic fill-in accuracy"
└── 越具体，越容易突破
    The more specific, the easier to break through

方法 3：寻求外部反馈 / Get External Feedback
├── 找老师批改写作（自己看不出自己的问题）
│   Get teacher feedback (can't see own problems)
├── 找口语搭档（对方能指出你的问题）
│   Find speaking partner
└── 加入学习社群（交流经验和方法）
    Join study community

方法 4：战略性休息 / Strategic Rest
├── 连续高强度学习 4 周后，休息 3-5 天
│   After 4 weeks intensive study, rest 3-5 days
├── 休息期间可以轻度接触英语（看美剧、听歌）
│   Light English exposure during rest (shows, music)
└── 回来后往往有突破
    Often break through after rest
```
