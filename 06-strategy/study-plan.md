## 适用人群判断 / Which Plan Is Right for You?

| 计划 / Plan | 适合人群 / Best For | 前提条件 / Prerequisites |
|---|---|---|
| **1个月** / 1 Month | 考前冲刺、已有 6.0 基础 / Pre-exam sprint, 6.0+ base | 英语基础扎实，只需熟悉题型 / Solid English, just need test familiarity |
| **3个月** / 3 Months | 大多数考生 / Most test-takers | 英语中等水平 (5.0-5.5)，目标 6.5-7.0 / Intermediate level |
| **6个月** / 6 Months | 基础薄弱或目标高分 / Weak base or high target | 英语基础较弱 (4.0-4.5) 或目标 7.5+ / Lower base or 7.5+ target |

## 2. 三个月标准计划 / 3-Month Standard Plan

> 适合：当前 5.0-5.5，目标 6.5-7.0
> For: Current 5.0-5.5, targeting 6.5-7.0

### 每日学习时间：3-5 小时 / Daily study: 3-5 hours

### Month 1：基础夯实期 / Foundation Building (Weeks 1-4)

#### 词汇目标 / Vocabulary Goals
- 第 1-2 周：核心词汇 1500 词 / Core vocabulary: 1500 words
- 第 3-4 周：学术词汇 1000 词 / Academic vocabulary: 1000 words
- 每日新词 40 个 + 复习 60 个 / 40 new + 60 review daily

#### 周计划模板 / Weekly Plan Template

**每周一到周五 / Monday to Friday：**

```
07:00-07:30  词汇晨练 / Vocabulary morning drill (新词 + 复习)
07:30-08:30  听力训练 / Listening practice
             - 第1周：Section 1-2 基础训练
             - 第2周：Section 3 进阶训练
             - 第3周：Section 4 挑战训练
             - 第4周：完整套题训练
08:30-09:30  阅读训练 / Reading practice
             - 第1周：扫读技巧 + 填空题
             - 第2周：判断题 + 选择题
             - 第3周：配对题 + 标题匹配
             - 第4周：完整套题训练
09:30-10:00  休息 / Break
10:00-10:45  语法专项 / Grammar focus
             - 第1周：时态复习
             - 第2周：从句（定语从句、状语从句）
             - 第3周：虚拟语气 + 倒装句
             - 第4周：复杂句式综合运用
10:45-11:30  写作基础 / Writing basics
             - 第1周：Task 1 图表类型识别
             - 第2周：Task 1 描述数据的句型
             - 第3周：Task 2 文章结构
             - 第4周：Task 2 论证方法
晚上 30 分钟：口语练习 + 词汇复习
Evening 30 min: Speaking practice + vocabulary review
```

**每周六 / Saturday：**
- 上午：模拟测试（听力 + 阅读）/ Mock test (Listening + Reading)
- 下午：错题分析 + 薄弱环节补强 / Error analysis + weak area reinforcement

**每周日 / Sunday：**
- 上午：口语话题练习（3-5 个话题）/ Speaking topics (3-5 topics)
- 下午：写作练习（Task 1 或 Task 2）/ Writing practice
- 晚上：周总结 + 下周计划 / Weekly review + next week plan

| 周次 / Week | 听力目标 / Listening | 阅读目标 / Reading | 写作目标 / Writing | 口语目标 / Speaking |

| Week 1 | 熟悉 Section 1-2 | 掌握填空题技巧 | 了解 Task 1 题型 | Part 1 流利回答 |
| Week 2 | Section 3 正确率 60%+ | 掌握判断题技巧 | 学会描述趋势 | Part 2 说满 2 分钟 |

## 3. 六个月长线计划 / 6-Month Comprehensive Plan

> 适合：当前 4.0-4.5，目标 7.0+；或时间充裕想冲高分
> For: Current 4.0-4.5 targeting 7.0+, or those with ample time aiming high

### 每日学习时间：2-4 小时 / Daily study: 2-4 hours

### 总体时间线 / Overall Timeline

```
Month 1-2          Month 3-4          Month 5          Month 6
┌──────────┐      ┌──────────┐      ┌──────────┐      ┌──────────┐
│ 基础期    │  →   │ 强化期    │  →   │ 提升期    │  →   │ 冲刺期    │
│Foundation │      │Intensive │      │ Advanced  │      │ Sprint    │
│ 词汇+语法 │      │ 题型+技巧 │      │ 突破+精练 │      │ 模考+调整 │
│ 4000 词汇 │      │ 6000 词汇 │      │ 8000 词汇 │      │ 巩固词汇  │
└──────────┘      └──────────┘      └──────────┘      └──────────┘
```

### Month 1-2：基础期 / Foundation Phase

**核心任务 / Core Tasks：**

1. **词汇建设 / Vocabulary Building**
   - 每天 50 个新词 + 复习 / 50 new words + review daily
   - 使用艾宾浩斯遗忘曲线复习 / Use spaced repetition (Ebbinghaus)
   - 重点：高中词汇 + 四级核心词 / Focus: high school + CET-4 core
   - 目标：两个月累计掌握 4000 词 / Target: 4000 words in 2 months

2. **语法系统学习 / Systematic Grammar**
   - 第 1-2 周：五大基本句型 / Five basic sentence patterns
   - 第 3-4 周：时态系统（16 种时态重点 8 种）/ Tense system (focus on 8 of 16)
   - 第 5-6 周：从句系统（定语/状语/名词性从句）/ Clause system
   - 第 7-8 周：特殊句式（倒装/强调/虚拟语气）/ Special structures

3. **听力基础 / Listening Foundation**
   - 每天精听 30 分钟 / 30 min intensive listening daily
   - 材料：BBC Learning English, VOA Special English
   - 方法：听写 → 对照 → 纠错 → 重听 / Dictation → check → correct → re-listen
   - 逐步过渡到剑桥真题 Section 1-2 / Transition to Cambridge Section 1-2

4. **阅读基础 / Reading Foundation**
   - 每天泛读 1 篇英文文章 / 1 English article daily (extensive reading)
   - 材料：New Scientist, National Geographic, BBC News
   - 学会划分句子成分 / Learn to parse sentence structures
   - 积累学术词汇 / Accumulate academic vocabulary

5. **写作入门 / Writing Introduction**
   - 学习范文结构 / Study model essay structures
   - 积累常用表达 / Collect common expressions
   - 每周仿写 1 篇 / 1 imitation essay per week

6. **口语基础 / Speaking Foundation**
   - 每天朗读 15 分钟 / 15 min reading aloud daily
   - 跟读练习（影子跟读法）/ Shadow reading practice
   - Part 1 基础话题练习 / Part 1 basic topic practice

**月度里程碑 / Monthly Milestones：**

| 月份 / Month | 词汇量 / Vocabulary | 语法 / Grammar | 听力 / Listening | 阅读 / Reading |
|---|---|---|---|---|
| Month 1 | 2500 词 | 基本句型 + 时态 | Section 1-2 正确率 70% | 填空+判断正确率 60% |
| Month 2 | 4000 词 | 从句 + 特殊句式 | Section 1-3 正确率 65% | 各题型正确率 60% |

---

### Month 3-4：强化期 / Intensive Phase

**核心任务 / Core Tasks：**

1. **词汇进阶 / Advanced Vocabulary**
   - 每天 40 个新词 + 复习 / 40 new + review daily
   - 重点：雅思高频词 + 同义替换 / IELTS high-frequency + paraphrases
   - 学科词汇：自然科学、社会科学、人文艺术
   - 目标：累计 6000 词 / Target: 6000 words total

2. **题型技巧 / Question Type Strategies**
   - 听力：每种题型专项训练 / Listening: drills per question type
   - 阅读：快速定位 + 同义替换识别 / Reading: keyword location + paraphrase recognition
   - 写作：Task 1 各图表类型 + Task 2 各文章类型
   - 口语：Part 1-3 各类型应答策略

3. **限时训练 / Timed Practice**
   - 逐步加入时间限制 / Gradually introduce time limits
   - 听力：跟原速播放 / Listening: original speed only
   - 阅读：每篇 20 分钟 / Reading: 20 min per passage
   - 写作：Task 1 (20min) + Task 2 (40min)
   - 口语：Part 2 严格 2 分钟 / Speaking Part 2: strict 2 min

4. **错题系统 / Error Tracking System**
   - 建立错题本 / Build error log
   - 分类记录错误类型 / Categorize error types
   - 每周分析错误模式 / Analyze patterns weekly
   - 针对性训练 / Targeted practice

**月度里程碑 / Monthly Milestones：**

| 月份 / Month | 模考分数 / Mock Score | 重点突破 / Key Breakthrough |
|---|---|---|
| Month 3 | Overall 5.5-6.0 | 各题型熟练度 / Question type familiarity |
| Month 4 | Overall 6.0-6.5 | 速度+准确率 / Speed + accuracy |

---

### Month 5：提升期 / Advanced Phase

**核心任务 / Core Tasks：**

1. **高分技巧 / High-Score Techniques**
   - 听力：Section 4 学术讲座精听 / Section 4 academic lecture intensive
   - 阅读：长难句快速理解 / Long complex sentence quick comprehension
   - 写作：高级词汇和句式运用 / Advanced vocabulary and structures
   - 口语：地道表达 + 逻辑展开 / Natural expressions + logical development

2. **弱项集中突破 / Intensive Weak Area Work**
   - 分析模考数据，找到最大提分空间 / Analyze mock data for biggest gains
   - 集中 2 周专攻最弱的 1-2 科 / 2 weeks focused on 1-2 weakest sections
   - 寻求老师或高手反馈 / Get feedback from teachers or experts

3. **写作深度提升 / Deep Writing Improvement**
   - 每周写 3-4 篇 + 精批改 / 3-4 essays per week + detailed feedback
   - 学习高分范文的论证逻辑 / Study high-score essay argumentation
   - Task 1：复杂图表综合描述 / Complex chart comprehensive description
   - Task 2：深层论证 + 反驳段 / Deep argumentation + counter-argument

4. **口语突破 / Speaking Breakthrough**
   - 每天录音 + 回听 + 改进 / Daily record + listen back + improve
   - 学习地道连接词和填充词 / Learn natural linkers and fillers
   - 练习即兴回答能力 / Practice impromptu responses
   - 模拟考官追问 / Simulate examiner follow-up questions

**月度目标 / Monthly Target：**
- 模考稳定在 Overall 6.5-7.0 / Stable mock score 6.5-7.0

---

### Month 6：冲刺期 / Sprint Phase

**核心任务 / Core Tasks：**

1. **全真模考 / Full Mock Tests**
   - 每周 2-3 套完整模考 / 2-3 full mock tests per week
   - 严格模拟考试环境 / Strictly simulate test conditions
   - 无手机、无字典、严格计时 / No phone, no dictionary, strict timing

2. **考试策略优化 / Test Strategy Optimization**
   - 确定各科时间分配策略 / Finalize time allocation per section
   - 练习快速决策（跳过/猜测）/ Practice quick decisions (skip/guess)
   - 蘸写检查流程 / Transfer and check routine

3. **心态管理 / Mental Preparation**
   - 考前两周开始调整作息 / Adjust sleep schedule 2 weeks before
   - 练习深呼吸和正念 / Practice deep breathing and mindfulness
   - 建立自信清单（记录进步）/ Build confidence list (track progress)

4. **最终复习 / Final Review**

## 5. 计划调整指南 / Plan Adjustment Guide

### 5.1 什么情况下需要调整 / When to Adjust

| 情况 / Situation | 调整方案 / Adjustment |
|---|---|
| 连续两周模考分数无提升 / No improvement for 2 weeks | 换学习方法，不要只加量 / Change method, not just volume |
| 某一科远低于其他科 / One section far below others | 增加该科时间比例至 40% / Allocate 40% to that section |
| 学习时间不足 / Insufficient study time | 切换到更紧凑的计划 / Switch to more intensive plan |
| 感到倦怠 / Feeling burned out | 安排 1-2 天休息，减少强度 / Rest 1-2 days, reduce intensity |
| 提前达到目标 / Target reached early | 冲击更高分数 / Aim higher |

### 5.3 计划执行小贴士 / Plan Execution Tips

1. **灵活性** / Flexibility — 计划是指南，不是枷锁 / The plan is a guide, not a chain
2. **一致性** / Consistency — 每天学一点比周末突击好 / Daily study > weekend cramming
3. **反馈循环** / Feedback loop — 每周评估进展，及时调整 / Evaluate weekly, adjust promptly

5. **学习环境** / Study environment — 固定学习场所，减少干扰 / Fixed study spot, minimize distractions
