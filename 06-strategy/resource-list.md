### 6.3 写作学习方法 / Writing Study Methods

```
方法 1：范文精读法 / Model Essay Deep Study
├── 选一篇高分范文
├── 第一遍：阅读理解
├── 第二遍：标注好词好句
├── 第三遍：分析论证结构
├── 第四遍：仿写类似话题
└── 对比自己的和范文的差距

方法 2：互批法 / Peer Review
├── 找一个水平相近的备考伙伴
├── 互相写作文
├── 互相批改（对照评分标准）
└── 讨论改进方案

方法 3：间隔练习法 / Spaced Practice
├── 写完一篇作文后不立刻修改
├── 隔天再看，以"读者"视角审视
├── 发现更多问题，修改更有效
└── 过一周再看同一篇，可能又有新发现
```

### 8.2 词汇学习方法 / Vocabulary Learning Methods

```
方法 1：主题分类法 / Topic Classification
├── 按考试常见主题分类记忆
│   Learn by common exam topics
├── 教育类、科技类、环境类、社会类...
│   Education, Technology, Environment, Society...
└── 每个主题 50-100 个核心词
    50-100 core words per topic

方法 2：同义替换法 / Paraphrase Method
├── 学一个词时，同时学它的 3-5 个同义词
│   When learning a word, also learn 3-5 synonyms
├── 这对听力和阅读的同义替换识别特别有帮助
│   Especially helpful for listening/reading paraphrasing
└── 例：important → crucial, vital, significant, essential
    Example: important → crucial, vital, significant, essential

方法 3：搭配记忆法 / Collocation Method
├── 不要只记单词，要记搭配
│   Don't just learn words — learn collocations
├── 例：不是记 "important"，而是记 "play a crucial role"
│   Don't just learn "important" — learn "play a crucial role"
└── 搭配在写作和口语中更自然
    Collocations sound more natural in writing and speaking

方法 4：间隔重复法 / Spaced Repetition
├── 使用 Anki 或墨墨背单词
│   Use Anki or 墨墨背单词
├── 科学安排复习间隔
│   Scientific review intervals
└── 新词学后：1天→3天→7天→14天→30天 复习
    Review schedule: 1d → 3d → 7d → 14d → 30d
```

## 附录：备考资源使用时间表 / Appendix: Resource Usage Schedule

### 基础期（第 1-2 个月）/ Foundation Phase (Month 1-2)

```
每日 / Daily:
├── 词汇：墨墨背单词 APP (30 min)
├── 听力：BBC 6 Minute English (20 min)
├── 阅读：BBC News 泛读 (20 min)
├── 语法：Cambridge Grammar for IELTS (20 min)
└── 口语：ELSA Speak 发音练习 (15 min)

每周 / Weekly:
├── 剑桥真题 1 套（听力+阅读）/ 1 Cambridge test (L+R)
├── 写作范文精读 2 篇 / 2 model essay studies
└── 口语录音练习 3 次 / 3 speaking recordings
```

### 强化期（第 3-4 个月）/ Intensive Phase (Month 3-4)

```
每日 / Daily:
├── 词汇：同义替换专项 (20 min)
├── 听力：精听训练 + 套题 (60 min)
├── 阅读：限时套题 (60 min)
├── 写作：Task 1 或 Task 2 练习 (45 min)
└── 口语：话题练习 + 录音 (30 min)

每周 / Weekly:
├── 全真模考 1-2 次 / 1-2 full mock tests
├── 写作批改 1-2 篇 / 1-2 writing corrections
└── 口语模拟 1 次 / 1 speaking mock
```

### 冲刺期（第 5-6 个月）/ Sprint Phase (Month 5-6)

```
每日 / Daily:
├── 词汇：快速复习高频词 (15 min)
├── 全真模考或单科冲刺 (2-3 hours)
├── 错题分析 + 弱项突破 (60 min)
└── 口语话题快速过 (20 min)

每周 / Weekly:
├── 全真模考 2-3 次 / 2-3 full mock tests
├── 写作批改 2 篇 / 2 writing corrections
└── 口语模拟 2 次 / 2 speaking mocks
```
