# IELTS Listening Practice Tests / 雅思听力练习

> 🎧 **Instructions / 说明**: Each test contains 10 questions. Read the questions first, then imagine the audio scenario. Write your answers, then check with the answer key at the bottom.
> 每套测试包含 10 道题。先阅读题目，然后想象听力场景。写下答案，最后对照底部的答案核对。

---

## Test 1: University Enrollment / 测试一：大学注册

### Part 1: Conversation between student and registrar / 第一部分：学生与注册员的对话

**Questions 1–5: Complete the form / 填写表格**

Write **NO MORE THAN TWO WORDS AND/OR A NUMBER** for each answer.
每个答案不超过**两个单词和/或一个数字**。

**Student Enrollment Form / 学生注册表**

| Field / 项目 | Answer / 答案 |
|---|---|
| 1. Student ID number / 学号 | __________ |
| 2. Course / 课程 | __________ |
| 3. Start date / 开始日期 | __________ |
| 4. Emergency contact / 紧急联系人 | __________ |
| 5. Accommodation type / 住宿类型 | __________ |

**Questions 6–8: Multiple choice / 选择题**

**6.** The student chose this university mainly because:
学生选择这所大学主要因为：

- A) It has a good reputation / 学校声誉好
- B) It offers a scholarship / 提供奖学金
- C) It is close to home / 离家近

**7.** The registration fee needs to be paid by:
注册费需要在何时支付：

- A) Credit card / 信用卡
- B) Bank transfer / 银行转账
- C) Cash / 现金

**8.** The orientation session is on:
迎新会的日期是：

- A) Monday / 周一
- B) Wednesday / 周三
- C) Friday / 周五

**Questions 9–10: Sentence completion / 句子填空**

Write **NO MORE THAN TWO WORDS** for each answer.
每个答案不超过**两个单词**。

**9.** The library is open until ________ on weekdays.
工作日图书馆开放至 ________。

**10.** Students can borrow up to ________ books at a time.
学生一次最多可借 ________ 本书。

---

### 💡 Tips for Test 1 / 测试一技巧

- **Q1**: Listen carefully for numbers and letters. Listen for spelling of names/IDs.
  注意听数字和字母，尤其注意拼写。
- **Q2**: Course names often include specific terminology. Be ready to write quickly.
  课程名称常包含专业术语，做好快速书写的准备。
- **Q3**: Dates can be said in different formats. Note the format required.
  日期可能有不同的表达方式，注意题目要求的格式。
- **Q4**: Names are spelled out in the audio. Write exactly what you hear.
  名字会在音频中拼写出来，照写你听到的。
- **Q5**: Housing/accommodation vocabulary: dormitory, homestay, shared flat, studio.
  住宿类词汇：宿舍、寄宿家庭、合租公寓、单间公寓。
- **Q6**: The speaker will mention multiple reasons but emphasize one as the main reason.
  说话者会提到多个原因，但会强调一个主要原因。
- **Q7**: Payment methods are often discussed with specific details. Listen for the exact method.
  支付方式通常会有具体细节说明，注意听准确的方式。
- **Q8**: Days of the week are easy to confuse. Focus and write immediately.
  星期几容易混淆，集中注意力并立即写下。
- **Q9**: Pay attention to time expressions: until, by, from...to.
  注意时间表达：until、by、from...to。
- **Q10**: Numbers are frequently tested. Practice recognizing numbers quickly.
  数字是常见考点，练习快速识别数字。

## Test 2: Hotel Reservation / 测试二：酒店预订

### Part 1: Phone conversation about booking a room / 第一部分：电话预订房间

**Questions 1–5: Note completion / 笔记填空**

Write **NO MORE THAN TWO WORDS AND/OR A NUMBER** for each answer.
每个答案不超过**两个单词和/或一个数字**。

**Hotel Booking Details / 酒店预订详情**

| Item / 项目 | Details / 详情 |
|---|---|
| Hotel name / 酒店名称 | The Grand ________ (1) |
| Check-in date / 入住日期 | ________ (2) |
| Check-out date / 退房日期 | ________ (3) |
| Room type / 房间类型 | ________ (4) |
| Price per night / 每晚价格 | £________ (5) |

**Questions 6–8: Multiple choice / 选择题**

**6.** The hotel provides breakfast:
酒店提供早餐：

- A) Included in the price / 包含在价格中
- B) For an extra £10 / 额外 10 英镑
- C) No breakfast service / 不提供早餐

**7.** The guest wants a room with a view of:
客人想要可以看到什么景色的房间：

- A) The garden / 花园
- B) The sea / 大海
- C) The city center / 市中心

**8.** Cancellation must be made at least:
取消预订必须至少提前：

- A) 24 hours / 24 小时
- B) 48 hours / 48 小时
- C) 72 hours / 72 小时

**Questions 9–10: Short answer / 简短回答**

Write **NO MORE THAN THREE WORDS** for each answer.
每个答案不超过**三个单词**。

**9.** What facility does the guest specifically ask about?
客人具体询问了什么设施？

**10.** How will the confirmation be sent?
确认信息将通过什么方式发送？

---

### 💡 Tips for Test 2 / 测试二技巧

- **Q1**: Hotel names often have "The" + adjective + noun format.
  酒店名称通常是"The" + 形容词 + 名词的格式。
- **Q2–3**: Listen for date formats carefully. Note whether it's day-month or month-day.
  仔细听日期格式，注意是日-月还是月-日。
- **Q4**: Room types: single, double, twin, suite, deluxe.
  房间类型：单人间、大床房、双床间、套房、豪华间。
- **Q5**: Listen for the price and note the currency symbol required.
  注意听价格，记下所需的货币符号。
- **Q6**: "Included" vs "additional charge" — these phrases signal different answers.
  "包含"和"额外收费"——这些短语指向不同的答案。
- **Q7**: Views: garden, sea, mountain, pool, courtyard, city skyline.
  景观：花园、大海、山景、泳池、庭院、城市天际线。
- **Q8**: Cancellation policies are a common listening topic. Note the time period.
  取消政策是常见听力主题，注意时间段。
- **Q9**: Facilities: gym, pool, spa, parking, WiFi, laundry.
  设施：健身房、泳池、水疗、停车场、WiFi、洗衣服务。
- **Q10**: Confirmation methods: email, text/SMS, phone call, post.
  确认方式：邮件、短信、电话、邮寄。

## Test 3: Science Lecture / 测试三：科学讲座

### Part 3: University lecture on marine biology / 第三部分：海洋生物学大学讲座

**Questions 1–5: Matching / 配对题**

Match each marine creature (1–5) with the correct characteristic (A–F).
将每种海洋生物 (1–5) 与正确特征 (A–F) 配对。

**Marine Creatures / 海洋生物**

1. Blue whale / 蓝鲸
2. Seahorse / 海马
3. Octopus / 章鱼
4. Coral / 珊瑚
5. Dolphin / 海豚

**Characteristics / 特征**

- A) Can change color for camouflage / 能变色伪装
- B) The largest animal ever / 有史以来最大的动物
- C) Uses echolocation to navigate / 使用回声定位导航
- D) Male carries the eggs / 雄性携带卵
- E) Actually a colony of tiny organisms / 实际上是微小生物的群体
- F) Has three hearts / 有三个心脏

**Questions 6–8: Multiple choice / 选择题**

**6.** According to the lecture, ocean temperatures have risen by:
根据讲座，海洋温度上升了：

- A) 0.5°C in 50 years / 50年内 0.5°C
- B) 1.0°C in 100 years / 100年内 1.0°C
- C) 1.5°C in 50 years / 50年内 1.5°C

**7.** The biggest threat to coral reefs is:
珊瑚礁面临的最大威胁是：

- A) Overfishing / 过度捕捞
- B) Ocean acidification / 海洋酸化
- C) Plastic pollution / 塑料污染

**8.** The speaker's main recommendation is:
演讲者的主要建议是：

- A) Create more marine reserves / 建立更多海洋保护区
- B) Reduce carbon emissions / 减少碳排放
- C) Ban single-use plastics / 禁止一次性塑料

**Questions 9–10: Summary completion / 摘要填空**

Write **NO MORE THAN TWO WORDS** for each answer.
每个答案不超过**两个单词**。

Marine ecosystems are under increasing pressure from human activities. The lecturer emphasized that ________ (9) is essential for protecting endangered species. She also noted that ________ (10) can play a key role in monitoring ocean health.

海洋生态系统正面临越来越大的人类活动压力。讲师强调 ________(9) 对保护濒危物种至关重要。她还指出 ________(10) 可以在监测海洋健康方面发挥关键作用。

---

### 💡 Tips for Test 3 / 测试三技巧

- **Q1–5**: For matching questions, eliminate options as you listen. Don't try to match all at once.
  配对题边听边排除选项，不要试图一次性完成所有配对。
- **Q1**: Blue whale facts: up to 30m long, heart size of a small car.
  蓝鲸知识：长达30米，心脏有一辆小汽车那么大。
- **Q2**: Seahorse unique fact: the male carries and gives birth to young.
  海马独特之处：雄性海马负责携带和生育幼崽。
- **Q3**: Octopus: 3 hearts, blue blood, highly intelligent.
  章鱼：3个心脏、蓝色血液、高度智能。
- **Q4**: Coral is often misunderstood — it's an animal, not a plant.
  珊瑚常被误解——它是动物，不是植物。
- **Q5**: Dolphins use clicks and whistles for echolocation.
  海豚使用咔嗒声和口哨声进行回声定位。
- **Q6**: Temperature changes are usually given with specific numbers. Listen for the exact figure.
  温度变化通常会给出具体数字，注意听准确数据。
- **Q7**: The speaker may discuss multiple threats but emphasize one as the biggest.
  演讲者可能讨论多个威胁，但会强调一个最大的。
- **Q8**: Recommendations often come near the end of a lecture.
  建议通常出现在讲座末尾。
- **Q9–10**: Summary questions test your understanding of the lecture's key message.
  摘要题测试你对讲座核心信息的理解。
