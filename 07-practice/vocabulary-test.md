## 📖 Vocabulary Study Tips / 词汇学习技巧

### How to Build Your Vocabulary / 如何扩充词汇量

1. **Read extensively / 广泛阅读**
   - Read academic articles, newspapers, and English novels
   - 阅读学术文章、报纸和英文小说

2. **Keep a vocabulary notebook / 保持词汇笔记本**
   - Write new words with definitions, example sentences, and synonyms
   - 记录新单词的定义、例句和同义词

3. **Learn words in context / 在语境中学习单词**
   - Don't just memorize word lists — see how words are used in sentences
   - 不要只背单词表——看单词在句子中如何使用

4. **Use spaced repetition / 使用间隔重复**
   - Review vocabulary at increasing intervals
   - 以递增的间隔复习词汇

5. **Practice word formation / 练习词形变化**
   - Learn common prefixes and suffixes (un-, re-, -tion, -ment, -ly)
   - 学习常见前缀和后缀（un-、re-、-tion、-ment、-ly）

## 🔑 Essential Word Pairs / 必备同义词对

这些词对在雅思中经常作为同义替换出现，学会识别它们：

| Word | Synonym / 同义词 |
|---|---|
| increase | rise, grow, surge, climb |
| decrease | decline, fall, drop, diminish |
| important | significant, crucial, vital, essential |
| difficult | challenging, demanding, arduous |
| show | demonstrate, illustrate, indicate, reveal |
| think | believe, consider, reckon, deem |
| change | transform, modify, alter, shift |
| help | assist, facilitate, aid, support |
| problem | issue, challenge, difficulty, obstacle |
| result | outcome, consequence, effect, impact |
