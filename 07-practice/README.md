## 🗺️ How to Use / 使用指南

### For Self-Study Learners / 自学考生

1. **Start with diagnostics / 先做诊断测试**
   - Try one practice test from each section to identify your weak areas.
   - 尝试每个科目的一套练习，找出薄弱环节。

2. **Follow the weekly plan / 按周计划学习**
   - **Week 1–2**: Focus on Listening & Reading (input skills) / 重点练习听力和阅读（输入技能）
   - **Week 3–4**: Focus on Writing & Speaking (output skills) / 重点练习写作和口语（输出技能）
   - **Week 5–6**: Mixed practice + Vocabulary review / 混合练习 + 词汇复习

3. **Review mistakes systematically / 系统性地复习错题**
   - Keep an error log / 记录错题本
   - Revisit vocabulary-test.md weekly / 每周重做词汇测试

### For Teachers / 教师使用指南

- Each listening test can be used as a 30-minute classroom activity.
- 每套听力练习可作为 30 分钟的课堂活动。
- Writing prompts can be assigned as homework with peer review.
- 写作题目可布置为家庭作业，配合同伴互评。
- Speaking topics work well for pair or group discussion sessions.
- 口语话题适合用于双人或小组讨论。

## 💡 General Tips / 通用技巧

### Before the Exam / 考前

- ✅ Practice under timed conditions / 在限时条件下练习
- ✅ Use official answer sheets / 使用官方答题卡
- ✅ Simulate real exam environment / 模拟真实考试环境
- ✅ Review answers carefully before submitting / 提交前仔细检查答案

### During the Exam / 考试中

- ✅ Read instructions carefully / 仔细阅读题目要求
- ✅ Manage your time / 合理分配时间
- ✅ Don't spend too long on one question / 不要在一道题上花太长时间
- ✅ Transfer answers accurately / 准确誊写答案
