## 这是什么？

一个免费、开源的雅思备考资料库，涵盖听力、阅读、写作、口语四大模块。外加词汇、策略和练习材料。

**适合谁？**
- 自学备考雅思的人
- 寻找教学资料的老师
- 任何想提高英语水平的人

**有什么不同？**
- 100% 免费，没有付费墙
- 中英双语解释
- 真实例子和范文
- 实用策略，不只是理论
- 持续更新

## 🎯 快速开始

### 初学者（5-6 分）

1. 阅读 [学习计划](06-strategy/study-plan.md) — 选择你的时间线
2. 从 [听力 Section 1](01-listening/section1-conversations.md) 开始 — 最简单的部分
3. 学习 [基础词汇](05-vocabulary/academic-vocabulary.md) — 最常用的单词
4. 练习 [Task 1 写作](03-writing/task1-overview.md) — 描述简单图表

### 中级（6-7 分）

1. 专注 [题型解析](02-reading/question-types.md) — 掌握每种题型
2. 练习 [Task 2 作文](03-writing/task2-overview.md) — 所有作文类型
3. 练习 [口语 Part 2](04-speaking/part2-cue-card.md) — 长段独白
4. 学习 [搭配词](05-vocabulary/collocations.md) — 自然的词语组合

### 高级（7-8+ 分）

1. 掌握 [速读技巧](02-reading/skimming-scanning.md) — 读得更快
2. 写 [8 分范文](03-writing/sample-essays.md) — 模仿高分作文
3. 完善 [口语 Part 3](04-speaking/part3-discussion.md) — 复杂讨论
4. 学习 [学术词汇](05-vocabulary/vocabulary-for-writing.md) — 正式用语

## 📊 雅思分数说明

| 分数 | 水平 | 描述 |
|------|------|------|
| 9 | 专家级 | 完全掌握英语 |
| 8 | 优秀 | 偶尔有不准确的地方 |
| 7 | 良好 | 总体能有效运用英语 |
| 6 | 合格 | 总体能有效沟通，但有不准确 |
| 5 | 一般 | 部分掌握，能理解大意 |
| 4 | 有限 | 基本能力，仅限熟悉场景 |

## 📖 使用方法

### 自学

```
第 1-2 周：阅读策略指南，做一次模拟测试
第 3-4 周：专注最弱的部分
第 5-6 周：用样题练习
第 7-8 周：做完整模拟测试
```

### 教师使用

- 在课堂上使用 [写作模板](templates/)
- 布置 [阅读练习](07-practice/) 作为作业
- 用 [口语话题](04-speaking/common-topics.md) 做讨论练习
