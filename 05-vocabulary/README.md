# IELTS 词汇模块 / IELTS Vocabulary Module

## 模块概述 / Module Overview

本模块提供全面的雅思词汇学习资源，涵盖学术词汇、话题词汇、搭配、习语等核心内容，帮助考生系统提升词汇量和运用能力。

This module provides comprehensive IELTS vocabulary learning resources, covering academic vocabulary, topic vocabulary, collocations, idioms, and other core content to help candidates systematically improve their vocabulary and usage skills.

---

## 学习目标 / Learning Objectives

1. 掌握 500+ 学术词汇及其用法 / Master 500+ academic words and their usage
2. 熟悉常见话题的核心词汇 / Familiarize with core vocabulary for common topics
3. 学会地道的词汇搭配 / Learn authentic collocations
4. 理解词根词缀，扩大词汇量 / Understand word formation to expand vocabulary
5. 区分同义词和反义词的细微差别 / Distinguish nuances between synonyms and antonyms
6. 掌握写作和口语中的高频表达 / Master high-frequency expressions for writing and speaking

## 学习建议 / Study Tips

### 第一阶段：基础积累 (1-2 周) / Phase 1: Foundation (1-2 weeks)
- 每天学习 30-50 个学术词汇 / Learn 30-50 academic words daily
- 重点记忆词性和搭配 / Focus on word forms and collocations
- 做词汇笔记，记录例句 / Take vocabulary notes with examples

### 第二阶段：话题专项 (2-3 周) / Phase 2: Topic Focus (2-3 weeks)
- 按话题分类学习 / Study by topic categories
- 结合听力和阅读材料巩固 / Consolidate with listening and reading materials
- 练习用新词造句 / Practice making sentences with new words

### 第三阶段：深化运用 (持续) / Phase 3: Deep Application (Ongoing)
- 学习同义替换，避免重复 / Learn synonyms to avoid repetition
- 掌握词根词缀，举一反三 / Master word formation for extrapolation
- 在写作和口语中主动运用 / Actively use in writing and speaking

## 使用说明 / How to Use This Module

1. **系统学习**: 按顺序从学术词汇开始，逐步扩展到话题词汇 / Study systematically from academic vocabulary to topic vocabulary
2. **重点突破**: 根据自身薄弱环节，针对性学习特定模块 / Focus on weak areas and study specific modules
3. **反复复习**: 使用间隔重复法巩固记忆 / Use spaced repetition to consolidate memory
4. **学以致用**: 在真题练习中主动运用所学词汇 / Actively use learned vocabulary in practice tests
5. **持续积累**: 每天坚持学习新词，复习旧词 / Persist in daily learning of new words and reviewing old ones
