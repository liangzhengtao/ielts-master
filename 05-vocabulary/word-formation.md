# 词汇构成 / Word Formation

## 概述 / Overview

本文档介绍英语词汇构成的基本规则，包括前缀、后缀和词根，帮助考生通过构词法扩大词汇量，提高词汇推断能力。

This document introduces basic English word formation rules, including prefixes, suffixes, and roots, to help candidates expand vocabulary through word formation and improve word inference ability.

---

## 1. 常见前缀 / Common Prefixes

### 1.1 表示否定 / Expressing Negation

| 前缀 | 含义 | 例词 | 词义 |
|:---|:---|:---|:---|
| **un-** | 不；无 | unhappy, unable, uncertain | 不快乐的，不能的，不确定的 |
| **in-** | 不；无 | inaccurate, inappropriate, independent | 不准确的，不恰当的，独立的 |
| **im-** | 不；无 (b/m/p前) | impossible, immature, impatient | 不可能的，不成熟的，不耐烦的 |
| **il-** | 不；无 (l前) | illegal, illiterate, illegible | 非法的，文盲的，难辨认的 |
| **ir-** | 不；无 (r前) | irrelevant, irresponsible, irregular | 不相关的，不负责任的，不规则的 |
| **dis-** | 不；相反 | disagree, disappear, disadvantage | 不同意，消失，劣势 |
| **non-** | 非；不 | nonsense, non-profit, non-fiction | 胡说，非营利的，非小说类 |
| **mis-** | 错误 | misunderstand, mislead, misjudge | 误解，误导，误判 |
| **anti-** | 反对 | antibiotic, antisocial, anti-war | 抗生素，反社会的，反战的 |
| **counter-** | 反；对抗 | counterpart, counterargument, counteract | 对应物，反驳论，抵消 |

**构词规则 / Formation Rules:**

- `un- + adjective → negative adjective`
  - happy → unhappy (不快乐的)
  - fair → unfair (不公平的)
  - necessary → unnecessary (不必要的)

- `un- + verb → reverse action`
  - do → undo (撤销)
  - lock → unlock (开锁)
  - cover → uncover (揭开)

- `in- + adjective → negative adjective`
  - complete → incomplete (不完整的)
  - correct → incorrect (不正确的)
  - sufficient → insufficient (不足的)

- `dis- + verb → negative/reverse action`
  - agree → disagree (不同意)
  - appear → disappear (消失)
  - approve → disapprove (不赞成)

### 1.2 表示程度和大小 / Expressing Degree and Size

| 前缀 | 含义 | 例词 | 词义 |
|:---|:---|:---|:---|
| **super-** | 超级 | superstar, supernatural, supervisor | 超级明星，超自然的，主管 |

| **hyper-** | 过度 | hyperactive, hypersensitive, hyperlink | 过度活跃的，过敏的，超链接 |
| **micro-** | 微小 | microscope, microorganism, microchip | 显微镜，微生物，微芯片 |
| **macro-** | 宏大 | macroeconomics, macro-level | 宏观经济学，宏观层面 |

**构词示例 / Examples:**

- **over-**: over + load = overload (超载)
- **under-**: under + estimate = underestimate (低估)
- **out-**: out + grow = outgrow (长得太大)

### 1.3 表示时间和顺序 / Expressing Time and Order

| 前缀 | 含义 | 例词 | 词义 |
|:---|:---|:---|:---|
| **pre-** | 之前 | preview, predict, precaution | 预览，预测，预防措施 |
| **post-** | 之后 | postgraduate, postwar, postpone | 研究生，战后的，推迟 |
| **fore-** | 预先 | forecast, foresee, forehead | 预测，预见，额头 |
| **re-** | 再次 | review, rebuild, recycle | 复习，重建，回收 |
| **ex-** | 前任 | ex-president, ex-wife, export | 前总统，前妻，出口 |
| **neo-** | 新 | neoclassical, neonatal | 新古典的，新生儿的 |

**构词规则 / Formation Rules:**

- `pre- + verb/noun → before`
  - view → preview (预览)
  - history → prehistory (史前)
  - determine → predetermine (预先决定)

- `post- + noun/adjective → after`
  - war → postwar (战后的)
  - graduate → postgraduate (研究生)
  - modern → postmodern (后现代的)

- `re- + verb → again`
  - build → rebuild (重建)
  - write → rewrite (重写)
  - think → rethink (重新考虑)

## 2. 常见后缀 / Common Suffixes

### 2.1 名词后缀 / Noun Suffixes

#### 表示状态和性质 / Expressing State and Quality

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-ness** | 形容词→名词 | happiness, darkness, awareness | 幸福，黑暗，意识 |
| **-ity/-ty** | 形容词→名词 | ability, diversity, complexity | 能力，多样性，复杂性 |
| **-ence/-ance** | 形容词→名词 | importance, existence, independence | 重要性，存在，独立 |
| **-dom** | 名词→名词 | freedom, kingdom, wisdom | 自由，王国，智慧 |
| **-ship** | 名词→名词 | friendship, leadership, membership | 友谊，领导力，会员资格 |
| **-ism** | 名词/形容词→名词 | capitalism, racism, optimism | 资本主义，种族主义，乐观主义 |
| **-hood** | 名词→名词 | childhood, neighborhood, likelihood | 童年，社区，可能性 |

**构词规则 / Formation Rules:**

- `adjective + -ness → noun (state/quality)`
  - aware → awareness (意识)
  - careless → carelessness (粗心)
  - effective → effectiveness (有效性)

- `adjective + -ity → noun (state/quality)`
  - diverse → diversity (多样性)
  - equal → equality (平等)
  - productive → productivity (生产力)

- `verb + -ence/-ance → noun (state/action)`
  - exist → existence (存在)
  - occur → occurrence (发生)
  - resist → resistance (抵抗)

#### 表示人和职业 / Expressing Person and Profession

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-er** | 动作执行者 | teacher, worker, researcher | 教师，工人，研究者 |
| **-or** | 动作执行者 | actor, director, operator | 演员，导演，操作员 |
| **-ist** | 专业人员 | scientist, economist, journalist | 科学家，经济学家，记者 |
| **-ant/-ent** | 执行者 | assistant, participant, resident | 助手，参与者，居民 |
| **-ee** | 动作接受者 | employee, trainee, refugee | 雇员，实习生，难民 |
| **-ian/-an** | 专业人员 | musician, historian, politician | 音乐家，历史学家，政治家 |
| **-eer** | 专业人员 | engineer, volunteer, pioneer | 工程师，志愿者，先驱 |

#### 表示行为和过程 / Expressing Action and Process

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-tion/-sion** | 动词→名词 | education, decision, conclusion | 教育，决定，结论 |
| **-ment** | 动词→名词 | development, achievement, environment | 发展，成就，环境 |
| **-al** | 动词→名词 | arrival, approval, removal | 到达，批准，移除 |
| **-ing** | 动词→名词 | learning, building, understanding | 学习，建筑，理解 |
| **-ure** | 动词→名词 | failure, pressure, procedure | 失败，压力，程序 |

**构词规则 / Formation Rules:**

- `verb + -tion → noun (process/result)`
  - educate → education (教育)
  - innovate → innovation (创新)
  - communicate → communication (交流)

- `verb + -ment → noun (result/state)`
  - achieve → achievement (成就)
  - develop → development (发展)
  - govern → government (政府)

### 2.2 形容词后缀 / Adjective Suffixes

#### 表示性质和特征 / Expressing Quality and Characteristic

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-ful** | 名词→形容词 | helpful, beautiful, successful | 有帮助的，美丽的，成功的 |
| **-less** | 名词→形容词 | helpless, careless, useless | 无助的，粗心的，无用的 |
| **-ous/-ious** | 名词→形容词 | dangerous, various, serious | 危险的，各种的，严肃的 |
| **-ive** | 名词/动词→形容词 | creative, attractive, effective | 创造性的，有吸引力的，有效的 |
| **-al** | 名词→形容词 | natural, traditional, environmental | 自然的，传统的，环境的 |
| **-able/-ible** | 动词→形容词 | available, possible, flexible | 可用的，可能的，灵活的 |
| **-ic** | 名词→形容词 | economic, scientific, historic | 经济的，科学的，历史的 |
| **-ical** | 名词→形容词 | political, technological, practical | 政治的，技术的，实际的 |

**构词规则 / Formation Rules:**

- `noun + -ful → adjective (having)`
  - help → helpful (有帮助的)
  - care → careful (仔细的)
  - success → successful (成功的)

- `noun + -less → adjective (without)`
  - help → helpless (无助的)
  - care → careless (粗心的)
  - use → useless (无用的)

- `verb + -able → adjective (can be)`
  - accept → acceptable (可接受的)
  - achieve → achievable (可实现的)
  - avoid → avoidable (可避免的)

#### 表示关系和来源 / Expressing Relationship and Origin

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-ian** | 国家/地区 | American, Asian, Canadian | 美国的，亚洲的，加拿大的 |
| **-ese** | 国家/地区 | Chinese, Japanese, Portuguese | 中国的，日本的，葡萄牙的 |
| **-ish** | 国家/风格 | British, Spanish, childish | 英国的，西班牙的，幼稚的 |
| **-ern** | 方向 | eastern, western, northern | 东方的，西方的，北方的 |

### 2.3 动词后缀 / Verb Suffixes

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-ize/-ise** | 名词/形容词→动词 | realize, organize, modernize | 意识到，组织，使现代化 |
| **-ify** | 名词/形容词→动词 | identify, simplify, classify | 识别，简化，分类 |
| **-en** | 形容词→动词 | widen, strengthen, broaden | 加宽，加强，扩大 |
| **-ate** | 名词/形容词→动词 | create, separate, communicate | 创造，分离，交流 |

**构词规则 / Formation Rules:**

- `noun/adjective + -ize → verb (make/become)`
  - modern → modernize (使现代化)
  - special → specialize (专攻)
  - summary → summarize (总结)

- `adjective + -ify → verb (make/become)`
  - simple → simplify (简化)
  - pure → purify (净化)
  - intense → intensify (加强)

- `adjective + -en → verb (make/become)`
  - wide → widen (加宽)
  - strength → strengthen (加强)
  - broad → broaden (扩大)

### 2.4 副词后缀 / Adverb Suffixes

| 后缀 | 用途 | 例词 | 词义 |
|:---|:---|:---|:---|
| **-ly** | 形容词→副词 | quickly, easily, significantly | 快速地，容易地，显著地 |
| **-ward(s)** | 方向 | forward, backward, towards | 向前，向后，朝向 |
| **-wise** | 方面 | otherwise, likewise, clockwise | 否则，同样地，顺时针地 |

**构词规则 / Formation Rules:**

- `adjective + -ly → adverb`
  - quick → quickly (快速地)
  - careful → carefully (仔细地)
  - significant → significantly (显著地)

- 特殊情况 / Special Cases:
  - happy → happily (快乐地) - y变i
  - true → truly (真正地) - 去e
  - whole → wholly (完全地) - 去e

## 3. 常见词根 / Common Roots

### 3.1 拉丁词根 / Latin Roots

| 词根 | 含义 | 例词 | 词义 |
|:---|:---|:---|:---|
| **dict** | 说 | predict, dictionary, contradict | 预测，字典，矛盾 |
| **duct** | 引导 | conduct, introduce, produce | 引导，介绍，生产 |
| **port** | 搬运 | transport, import, export | 运输，进口，出口 |
| **spect** | 看 | inspect, perspective, respect | 检查，观点，尊重 |
| **struct** | 建造 | construct, structure, instruct | 建造，结构，指导 |
| **ject** | 投掷 | project, reject, inject | 项目，拒绝，注射 |
| **scrib/script** | 写 | describe, prescription, manuscript | 描述，处方，手稿 |
| **mit/mis** | 发送 | transmit, permit, submit | 传输，允许，提交 |
| **cede/cess** | 走 | proceed, access, exceed | 进行，访问，超过 |
| **fer** | 携带 | transfer, refer, differ | 转移，参考，不同 |
| **vert/vers** | 转 | convert, reverse, diverse | 转换，颠倒，多样的 |
| **pos/pon** | 放置 | position, postpone, compose | 位置，推迟，组成 |
| **tract** | 拉 | attract, extract, contract | 吸引，提取，合同 |
| **cept/ceive** | 拿取 | accept, concept, perceive | 接受，概念，感知 |
| **form** | 形状 | inform, reform, transform | 通知，改革，转变 |

**词根应用示例 / Root Application Examples:**

**dict (说 / to say):**
- predict = pre (前) + dict (说) = 预先说 = 预测
- dictionary = dict (说) + ionary (地方) = 说话的工具 = 字典
- contradict = contra (反) + dict (说) = 反着说 = 矛盾

**spect (看 / to look):**
- inspect = in (内) + spect (看) = 往里看 = 检查
- perspective = per (通过) + spect (看) = 看穿 = 视角
- respect = re (再) + spect (看) = 再看 = 尊重

**port (搬运 / to carry):**
- transport = trans (跨) + port (运) = 跨地运 = 运输
- import = im (进) + port (运) = 运进来 = 进口
- export = ex (出) + port (运) = 运出去 = 出口

   **答案 / Answer**: development

   **答案 / Answer**: successfully

   **答案 / Answer**: environmental

   **答案 / Answer**: Education

   **答案 / Answer**: significantly

   **答案 / Answer**: diversify

   **答案 / Answer**: beneficial

   **答案 / Answer**: arrival

## 6. 学习建议 / Study Recommendations

### 6.1 词汇扩展策略 / Vocabulary Expansion Strategies

1. **词根记忆法**: 掌握常见词根，举一反三
   - 学会 "spect" (看)，可以推断 inspect, respect, perspective, spectator

2. **前缀规律法**: 记住前缀含义，快速推断词义
   - 学会 "un-" (不)，可以理解 unhappy, unable, uncertain

3. **后缀判断法**: 通过后缀判断词性
   - 看到 "-tion" 知道是名词
   - 看到 "-ly" 知道是副词

4. **词族扩展法**: 以一个词为核心，扩展整个词族
   - create → creation → creative → creativity → creator

### 6.2 常见易混前缀 / Common Confusing Prefixes
