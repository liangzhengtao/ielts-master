# 学术词汇 / Academic Vocabulary

## 概述 / Overview

本文档收录雅思考试高频学术词汇（基于 AWL 学术词表精选），包含发音、词性、释义、例句和常用搭配。

This document contains high-frequency IELTS academic vocabulary (selected from AWL Academic Word List), including pronunciation, part of speech, definitions, example sentences, and common collocations.

## 词汇等级划分 / Vocabulary Levels

### 核心高频词 / Core High-Frequency Words (Sublist 1)

#### A 组 / Group A

**1. abandon** /əˈbændən/
- **词性 / Part of Speech**: v. / n.
- **释义 / Definition**: 放弃，抛弃 / to give up completely; to leave behind
- **例句 / Example**: The government decided to **abandon** the policy due to public opposition.
  - 政府决定因公众反对而**放弃**该政策。
- **搭配 / Collocations**: abandon hope, abandon a plan, abandon a project
- **派生词 / Derivatives**: abandonment (n.), abandoned (adj.)

**2. abstract** /ˈæbstrækt/
- **词性 / Part of Speech**: adj. / n. / v.
- **释义 / Definition**: 抽象的；摘要 / existing in thought or as an idea; a summary
- **例句 / Example**: The concept of justice is quite **abstract** and difficult to define.
  - 正义的概念相当**抽象**，难以定义。
- **搭配 / Collocations**: abstract concept, abstract art, abstract thinking
- **派生词 / Derivatives**: abstraction (n.), abstractly (adv.)

**3. access** /ˈækses/
- **词性 / Part of Speech**: n. / v.
- **释义 / Definition**: 进入；访问；使用权 / the right to use or approach something
- **例句 / Example**: Students should have **access** to quality education regardless of their background.
  - 无论背景如何，学生都应该有**机会**获得优质教育。
- **搭配 / Collocations**: access to information, gain access, easy access
- **派生词 / Derivatives**: accessible (adj.), accessibility (n.)

**4. accommodate** /əˈkɒmədeɪt/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 容纳；适应；提供住宿 / to provide space or adapt to
- **例句 / Example**: The hotel can **accommodate** up to 500 guests.
  - 这家酒店可以**容纳**多达 500 位客人。
- **搭配 / Collocations**: accommodate guests, accommodate needs, accommodate changes
- **派生词 / Derivatives**: accommodation (n.)

**5. accumulate** /əˈkjuːmjəleɪt/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 积累，积聚 / to gather or build up over time
- **例句 / Example**: Dust tends to **accumulate** on surfaces if not cleaned regularly.
  - 如果不定期清洁，灰尘容易在表面**积聚**。
- **搭配 / Collocations**: accumulate wealth, accumulate evidence, accumulate knowledge
- **派生词 / Derivatives**: accumulation (n.), accumulative (adj.)

**6. accurate** /ˈækjərət/
- **词性 / Part of Speech**: adj.
- **释义 / Definition**: 准确的，精确的 / correct and precise
- **例句 / Example**: The report provides an **accurate** representation of the situation.
  - 该报告提供了对情况的**准确**描述。
- **搭配 / Collocations**: accurate information, accurate data, accurate description
- **派生词 / Derivatives**: accuracy (n.), accurately (adv.), inaccurate (adj.)

**7. achieve** /əˈtʃiːv/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 实现，达到 / to successfully reach a goal
- **例句 / Example**: She worked hard to **achieve** her academic goals.
  - 她努力学习以**实现**自己的学术目标。
- **搭配 / Collocations**: achieve success, achieve a goal, achieve results
- **派生词 / Derivatives**: achievement (n.), achievable (adj.)

**8. acknowledge** /əkˈnɒlɪdʒ/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 承认；感谢 / to accept or recognize; to express gratitude
- **例句 / Example**: The author **acknowledges** the contributions of her colleagues.
  - 作者**感谢**同事们的贡献。
- **搭配 / Collocations**: acknowledge the fact, acknowledge receipt, acknowledge help
- **派生词 / Derivatives**: acknowledgement (n.)

**9. acquire** /əˈkwaɪə(r)/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 获得，取得 / to gain or obtain something
- **例句 / Example**: Language learners **acquire** vocabulary through exposure and practice.
  - 语言学习者通过接触和练习**获得**词汇。
- **搭配 / Collocations**: acquire knowledge, acquire skills, acquire a habit
- **派生词 / Derivatives**: acquisition (n.)

**10. adapt** /əˈdæpt/
- **词性 / Part of Speech**: v.
- **释义 / Definition**: 适应；改编 / to adjust to new conditions; to modify
- **例句 / Example**: Animals must **adapt** to changing environments to survive.
  - 动物必须**适应**变化的环境才能生存。
- **搭配 / Collocations**: adapt to change, adapt to circumstances, adapt a method
- **派生词 / Derivatives**: adaptation (n.), adaptable (adj.), adaptive (adj.)

## 学习方法建议 / Study Method Recommendations

### 每日学习计划 / Daily Study Plan

**周一至周五 / Monday to Friday**
- 上午：学习 20 个新词 / Morning: Learn 20 new words
- 下午：复习昨天的词汇 / Afternoon: Review yesterday's words
- 晚上：用新词造句练习 / Evening: Practice making sentences

**周末 / Weekends**
- 复习本周所有词汇 / Review all words from the week
- 做词汇测试 / Take vocabulary tests
- 阅读包含这些词汇的文章 / Read articles containing these words

### 记忆技巧 / Memory Techniques

1. **词根记忆法 / Root Method**: 通过词根词缀推断词义
   - 例：`predict` = pre (前) + dict (说) = 预先说 = 预测

2. **联想法 / Association Method**: 将新词与已知事物联系
   - 例：`enormous` → 想象一头巨大的大象 (e-normous)

3. **语境记忆法 / Context Method**: 在句子中记忆单词
   - 例：记住 `The impact of climate change is enormous` 而非孤立记忆 `enormous`

4. **间隔重复法 / Spaced Repetition**: 按照遗忘曲线复习
   - 第 1 天 → 第 3 天 → 第 7 天 → 第 14 天 → 第 30 天
