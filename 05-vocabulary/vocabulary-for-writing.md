# 写作词汇 / Vocabulary for Writing

## 概述 / Overview

本文档整理雅思写作（Task 1 和 Task 2）高频词汇和表达，帮助考生提升学术写作的语言水平和表达多样性。

This document organizes high-frequency IELTS writing vocabulary and expressions (Task 1 and Task 2) to help candidates improve academic writing language level and expression diversity.

## 3. 学术写作风格词汇 / Academic Style Vocabulary

### 3.1 避免口语化表达 / Avoiding Informal Expressions

| 口语化 ❌ | 学术化 ✅ | 例句 |
|:---|:---|:---|
| a lot of | **numerous / a considerable number of** | **Numerous** studies have shown... |
| get better | **improve / enhance** | The results **improved** significantly. |
| get worse | **deteriorate / decline** | The situation **deteriorated** rapidly. |
| big | **significant / substantial** | A **significant** increase was observed. |
| small | **minor / slight** | A **slight** improvement was noted. |
| thing | **factor / aspect / element** | Several **factors** contribute to... |
| really | **significantly / considerably** | The rate **significantly** increased. |
| lots of | **a great deal of / ample** | There is **ample** evidence to suggest... |
| bad | **adverse / detrimental / unfavorable** | The **adverse** effects are well-documented. |
| good | **beneficial / favorable / positive** | The **beneficial** effects are clear. |
| show | **demonstrate / indicate / illustrate** | The data **demonstrates** a clear pattern. |
| think | **argue / contend / maintain** | Scholars **argue** that... |
| about | **approximately / roughly** | **Approximately** 60% of respondents... |

### 3.2 学术写作风格提升 / Academic Style Enhancement

#### 避免绝对化 / Avoiding Absolutes

| 绝对化表达 ❌ | 谨慎表达 ✅ |
|:---|:---|
| always | **often / frequently / generally** |
| never | **rarely / seldom / hardly ever** |
| all | **the majority of / most** |
| none | **few / very few / hardly any** |
| every | **most / many** |
| definitely | **likely / probably / arguably** |
| certainly | **presumably / arguably / it seems** |
| completely | **largely / to a large extent / substantially** |

**使用示例 / Usage Examples:**
- ❌ Technology **always** has positive effects.
- ✅ Technology **generally** has positive effects.

- ❌ This is **definitely** the best solution.
- ✅ This is **arguably** the best solution.

#### 学术表达框架 / Academic Expression Frameworks

**表达观点 / Expressing Views:**
- It could be argued that...
- There is evidence to suggest that...
- Research indicates that...
- It is reasonable to assume that...
- One could contend that...
- The evidence points to...
- It is evident from the data that...

**提出建议 / Making Suggestions:**
- It is recommended that...
- It would be advisable to...
- One possible solution would be...
- The government should consider...
- Policymakers ought to...
- It is imperative that...
- Steps should be taken to...

**承认局限 / Acknowledging Limitations:**
- It should be noted that...
- However, it must be acknowledged that...
- A limitation of this argument is...
- While this may be true,...
- It is important to consider...
- One drawback of this approach is...
- This argument does have its limitations...

## 5. 写作练习模板 / Writing Practice Templates

### 5.1 Task 1 模板 / Task 1 Template

**开头 / Introduction:**
> The [chart type] illustrates/shows/depicts the [data type] of [subject] in [location/time period].

**概述 / Overview:**
> Overall, it can be seen that [main trend 1] and [main trend 2].

**细节 / Details:**
> Looking at the details, [describe first major feature]. In contrast/comparison, [describe second major feature]. Furthermore, [describe additional detail].

### 5.2 Task 2 模板 / Task 2 Template

**开头 / Introduction:**
> [Hook sentence]. This essay will discuss both sides of the argument and present my opinion.

**主体段 1 / Body Paragraph 1:**
> On the one hand, there are several advantages to [topic]. Firstly, [point 1 + explanation]. Furthermore, [point 2 + example].

**主体段 2 / Body Paragraph 2:**
> On the other hand, there are also disadvantages to consider. One major drawback is [point 1 + explanation]. Additionally, [point 2 + example].

**结尾 / Conclusion:**
> In conclusion, while there are both benefits and drawbacks, I believe that [your opinion] because [reason].
