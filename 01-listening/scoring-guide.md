# IELTS Listening Scoring Guide | 雅思听力评分指南

> How scoring works, what counts, and how to maximize your score | 评分机制、计分规则与最大化得分策略

---

## Overview | 概述

Understanding how the IELTS Listening test is scored helps you make smarter decisions during the test and target your preparation effectively.

了解雅思听力考试的评分机制有助于你在考试中做出更明智的决定，并有效地针对你的备考。

---

## The Scoring System | 评分系统

### Raw Score to Band Score | 原始分到雅思分数

The IELTS Listening test has **40 questions**, each worth **1 mark**. Your raw score (number of correct answers) is then converted to an **IELTS band score** from 1 to 9.

雅思听力考试有 **40 道题**，每题 **1 分**。你的原始分（正确答案数）随后被转换为 **1 到 9 的雅思分数**。

| Raw Score 原始分 | Band Score 分数 | Description 描述 |
|-----------------|----------------|-----------------|
| 39–40 | **9.0** | Expert user 精通用户 |
| 37–38 | **8.5** | Very good 非常好 |
| 35–36 | **8.0** | Very good 非常好 |
| 32–34 | **7.5** | Good user 良好用户 |
| 30–31 | **7.0** | Good user 良好用户 |
| 26–29 | **6.5** | Competent user 合格用户 |
| 23–25 | **6.0** | Competent user 合格用户 |
| 18–22 | **5.5** | Modest user 一般用户 |
| 16–17 | **5.0** | Modest user 一般用户 |
| 13–15 | **4.5** | Limited user 有限用户 |
| 11–12 | **4.0** | Limited user 有限用户 |
| 8–10 | **3.5** | Extremely limited 极有限 |
| 6–7 | **3.0** | Extremely limited 极有限 |
| 4–5 | **2.5** | Intermittent 间歇性 |
| 3 | **2.0** | Intermittent 间歇性 |

### What This Means in Practice | 实际意义

| Target Band | Need approximately | Can afford to miss |
|------------|-------------------|-------------------|
| Band 9 | 39–40 correct | 0–1 questions |
| Band 8 | 35–36 correct | 4–5 questions |
| Band 7 | 30–31 correct | 9–10 questions |
| Band 6.5 | 26–29 correct | 11–14 questions |
| Band 6 | 23–25 correct | 15–17 questions |
| Band 5.5 | 18–22 correct | 18–22 questions |

**Key insight:** To go from Band 6 to Band 7, you need about 5–6 more correct answers. That's just one more correct answer per section.

**关键洞察：** 从 6 分提升到 7 分，你需要多答对约 5-6 题。每个部分只多对 1 题。

## What Counts as Correct | 什么算正确

### Rules for Marking Answers | 答案评分规则

| Rule | Example | Correct? |
|------|---------|----------|
| **Spelling must be perfect** | "accomodation" for "accommodation" | Wrong ✗ |
| **Case doesn't matter** | "London" or "london" | Both correct ✓ |
| **Abbreviations usually accepted** | "Feb" for "February" | Usually accepted ✓ |
| **Articles usually optional** | "the library" or "library" (if within word limit) | Usually both correct ✓ |
| **American/British spelling both accepted** | "color" / "colour", "center" / "centre" | Both correct ✓ |
| **Singular/plural must match** | "student" when answer is "students" | Wrong ✗ |
| **Numbers can be digits or words** | "15" or "fifteen" | Both correct ✓ |
| **Hyphenated words count as one word** | "full-time" | One word ✓ |
| **Contractions count as one word** | "don't" | One word ✓ |

### Spelling: The Silent Killer | 拼写：无声杀手

Spelling is the **number one reason** candidates lose marks they should have earned. The IELTS test requires correct spelling for all written answers.

拼写是考生失去本应得到的分数的**头号原因**。雅思考试要求所有书面答案拼写正确。

**Frequently misspelled words in IELTS listening | 雅思听力中经常拼错的词:**

| Correct 正确 | Common Error 常见错误 | Memory Trick 记忆技巧 |
|-------------|---------------------|---------------------|
| accommodation | accomodation | Two c's, two m's: a-c-c-o-m-m-o-d-a-t-i-o-n |
| necessary | neccessary / neccesary | 1 collar (c), 2 sleeves (s): ne-cess-ary |
| beginning | begining | Double n: begi-nn-ing |
| government | goverment | Has "n" in it: gover-n-ment |
| environment | enviroment | Has "n" before "ment": environ-ment |
| separate | seperate | "A rat" in the middle: sep-A-RAT-e |
| definitely | definitly | Has "finite" in it: definite-ly |
| immediately | immediatly | Two m's: i-mm-ediately |
| Wednesday | Wensday | Remember: Wed-nes-day |
| February | Febuary | Has "r" after "b": Feb-r-uary |
| library | libary | Has two "r"s: lib-r-ary |
| restaurant | resturant | Has "au": rest-au-rant |
| beautiful | beatiful | Has "eau": b-eau-tiful |
| category | catagory | Has "e": cat-e-gory |
| independent | independant | Ends in "-ent": independ-ent |
| recommend | reccommend | One c, two m's: re-c-o-mm-end |
| occurrence | occurence | Two c's, two r's: o-cc-u-rr-ence |
| reference | referance | Ends in "-ence": refer-ence |
| temperature | temperture | Has "era": temp-er-a-ture |
| exaggerate | exagerate | Two g's: ex-a-gg-er-ate |

### Plural vs Singular | 单数与复数

The answer must match the grammar of the sentence.

答案必须匹配句子的语法。

**Example:**
> "The course accepts 25 ___ per year."
> Correct: **students** (plural — "25" requires plural)
> Wrong: **student**

> "The main ___ of the study is..."
> Correct: **finding** (singular — "main" suggests one)
> Wrong: **findings**

**How to check:** After writing your answer, read the complete sentence. Does it sound grammatically correct?

**如何检查：** 写完答案后，读一遍完整的句子。语法听起来对吗？

## The 10-Minute Transfer Time (Paper-Based Test) | 10 分钟誊写时间（纸笔考试）

### What Happens | 发生什么

After the 30-minute listening test, paper-based test takers get **10 extra minutes** to transfer their answers from the question paper to the answer sheet.

30 分钟听力测试后，纸笔考试考生获得**额外 10 分钟**将答案从试卷誊写到答题纸上。

### How to Use This Time | 如何利用这段时间

1. **Transfer answers carefully** — check spelling one more time
   仔细誊写答案——再检查一次拼写

2. **Fill in all answers** — even guesses (no negative marking)
   填写所有答案——即使是猜测（不倒扣分）

3. **Check word limits** — make sure no answer exceeds the stated limit
   检查字数限制——确保没有答案超过规定限制

4. **Check grammar** — singular/plural, verb tense
   检查语法——单数/复数、动词时态

5. **Make sure answers are in the correct question number** — a common and costly mistake
   确保答案对应正确的题号——常见且代价高昂的错误

### Common Transfer Mistakes | 常见誊写错误

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| Writing answer for Q5 in Q6 slot | Both Q5 and Q6 are wrong | Check question numbers carefully |
| Illegible handwriting | Examiner can't read it | Write clearly |
| Forgetting to transfer an answer | Blank = 0 marks | Transfer ALL answers |
| Smudging pencil marks | May be unreadable | Use firm pencil strokes |

### Computer-Delivered Test | 机考

In the computer-delivered test, you type your answers directly during the test. There is **no transfer time**. This means:
- You must type while listening
- Use the highlight tool to mark important information
- You can navigate between questions freely
- Review answers at the end (within the 30-minute time limit)

机考中，你在考试期间直接打字输入答案。**没有誊写时间**。这意味着：
- 你必须边听边打字
- 使用高亮工具标记重要信息
- 你可以自由地在题目间导航
- 在最后审查答案（在 30 分钟时间限制内）

## Band Score Descriptions | 分数等级描述

### Band 9: Expert User | 9 分：精通

- Has fully operational command of the language
- Understands virtually everything heard
- 0–1 mistakes out of 40
- 完全掌握语言
- 几乎理解听到的所有内容
- 40 道题中错 0-1 道

**What it takes:** Near-perfect concentration, excellent vocabulary, zero spelling errors

### Band 8: Very Good User | 8 分：非常好

- Has fully operational command with only occasional inaccuracies
- Handles complex detailed argumentation well
- 4–5 mistakes out of 40
- 完全掌握，仅有偶尔不准确
- 能很好地处理复杂的详细论证
- 40 道题中错 4-5 道

**What it takes:** Strong vocabulary, good concentration, minimal spelling errors

### Band 7: Good User | 7 分：良好

- Has operational command though with occasional inaccuracies
- Generally handles complex language well
- 9–10 mistakes out of 40
- 具有实际运用能力，但有偶尔不准确
- 总体上能很好地处理复杂语言
- 40 道题中错 9-10 道

**What it takes:** Good general comprehension, reasonable vocabulary, good spelling

### Band 6.5: Competent (Upper) | 6.5 分：合格（上）

- Between Band 6 and Band 7
- 11–14 mistakes out of 40
- Often the minimum score required for university admission
- 介于 6 分和 7 分之间
- 40 道题中错 11-14 道
- 通常是大学录取的最低分数要求

### Band 6: Competent User | 6 分：合格

- Has generally effective command
- Can understand the main points of clear speech
- 15–17 mistakes out of 40
- 具有总体有效的掌握
- 能理解清晰讲话的主要内容
- 40 道题中错 15-17 道

### Band 5.5: Modest (Upper) | 5.5 分：一般（上）

- Between Band 5 and Band 6
- 18–22 mistakes out of 40
- Can handle most communication in familiar situations
- 介于 5 分和 6 分之间
- 40 道题中错 18-22 道

## Section-by-Section Scoring Strategy | 各部分得分策略

### The "Points Available" Approach | "可用分数"方法

Each section has 10 questions. Not all sections are equally easy or hard.

每个部分有 10 道题。并非所有部分都同样简单或困难。

**Recommended targets by section:**

| Section | Difficulty | Target Score | Strategy |
|---------|-----------|-------------|----------|
| 1 (Easiest) | Easy | **9–10** out of 10 | Secure maximum marks; this is your safety net |
| 2 | Easy–Medium | **8–9** out of 10 | Focus carefully; lose no more than 1–2 |
| 3 | Medium–Hard | **7–8** out of 10 | Accept some loss; focus on what you can get |
| 4 (Hardest) | Hard | **6–8** out of 10 | Don't panic; every mark counts |

### Total from this approach:

- Section 1: 9–10
- Section 2: 8–9
- Section 3: 7–8
- Section 4: 6–8
- **Total: 30–35** → **Band 7.0–8.0**

This approach gives you a realistic, achievable scoring framework.

### The "Insurance" Strategy | "保险"策略

Since there's no negative marking:

由于没有倒扣分：

1. **Never leave an answer blank** — always guess
   永远不要留空——始终猜一个

2. **If you miss a question, mark it and guess at the end**
   如果错过一道题，标记它，最后猜

3. **Use context clues** — even if you didn't hear the answer, the question context may help you guess
   使用上下文线索——即使你没听到答案，题目上下文可能帮助你猜测

**Example of educated guessing:**
> "The course fee is £___"
> If you didn't hear the exact price, think: what's a reasonable course fee in the UK? £200? £500? Use general knowledge.

## How to Analyse Your Score | 如何分析你的分数

### After a Practice Test | 练习测试后

Don't just count your score. Analyse WHY you got each wrong answer.

不要只计算分数。分析你为什么每道题做错了。

### Error Categories | 错误分类

| Category | Description | Solution |
|----------|-------------|----------|
| **Didn't hear it** | Missed the answer completely | Practice more; improve concentration |
| **Heard it but wrong word** | Misunderstood the content | Improve vocabulary; practice paraphrasing |
| **Spelling error** | Knew the answer but spelled it wrong | Study spelling list; practice dictation |
| **Grammar error** | Wrong singular/plural or tense | Study grammar; check answer fits sentence |
| **Too many words** | Exceeded word limit | Count words before writing |
| **Distractor** | Chose wrong option due to distractor | Practice distractor awareness |
| **Lost track** | Lost place in the question set | Practice reading ahead |
| **Transfer error** | Wrote answer in wrong number | Double-check during transfer |

### Creating an Error Log | 创建错误日志

After each practice test, record your errors in a table:

每次练习测试后，在表格中记录你的错误：

```
Date: 2024-01-15
Practice Test: Cambridge IELTS 18, Test 1
Score: 27/40 (Band 6.5)

Error Log:
| Q# | My Answer | Correct Answer | Error Category | Notes |
|----|-----------|---------------|----------------|-------|
| 3  | station   | station       | Spelling       | Wrote "stasion" |
| 7  | A         | C             | Distractor     | Speaker corrected themselves |
| 12 | B         | B             | Correct        | — |
| 15 | —         | library       | Didn't hear    | Was still reading Q14 |
| 18 | three     | thirty        | Number trap    | Couldn't distinguish 13/30 |
| 22 | 3 months  | 6 months      | Misheard       | Confused "three" and "six" |
| ...          | ...           | ...            | ... |

Patterns:
- 3 spelling errors → need to practice spelling
- 2 number errors → need to practice number dictation
- 1 lost track → need to practice reading ahead
```

### Tracking Progress Over Time | 跟踪长期进度

| Test # | Date | Score | Band | Section 1 | Section 2 | Section 3 | Section 4 |
|--------|------|-------|------|-----------|-----------|-----------|-----------|
| 1 | Jan 15 | 27 | 6.5 | 9 | 8 | 6 | 4 |
| 2 | Jan 22 | 29 | 6.5 | 9 | 8 | 7 | 5 |
| 3 | Jan 29 | 31 | 7.0 | 10 | 9 | 7 | 5 |
| 4 | Feb 05 | 33 | 7.5 | 10 | 9 | 8 | 6 |

This helps you see where you're improving and where you still need work.

## Scoring Tips for Different Band Levels | 不同分数段的得分技巧

### Targeting Band 5 → 6 (Need ~23–25 correct) | 目标 5 → 6 分

**Focus on:**
- Section 1: Get 8–9 correct (this is achievable with practice)
- Section 2: Get 6–7 correct
- Section 3–4: Get 4–5 correct each

**Key areas to improve:**
- Spelling of basic vocabulary
- Listening for numbers and dates
- Understanding the main idea of each section

**重点改进：**
- 基础词汇拼写
- 听数字和日期
- 理解每个部分的主旨

### Targeting Band 6 → 7 (Need ~30–31 correct) | 目标 6 → 7 分

**Focus on:**
- Section 1: Get 9–10 correct (aim for perfect)
- Section 2: Get 8–9 correct
- Section 3: Get 7 correct
- Section 4: Get 5–6 correct

**Key areas to improve:**
- Paraphrase recognition
- Multiple choice strategy
- Concentration endurance for Section 4

### Targeting Band 7 → 8 (Need ~35–36 correct) | 目标 7 → 8 分

**Focus on:**
- Section 1: Perfect 10
- Section 2: Get 9 correct
- Section 3: Get 8–9 correct
- Section 4: Get 7–8 correct

**Key areas to improve:**
- Eliminating all spelling errors
- Handling the hardest multiple choice questions
- Maintaining full concentration in Section 4

### Targeting Band 8 → 9 (Need ~39–40 correct) | 目标 8 → 9 分

**Focus on:**
- Perfect scores in Sections 1–2
- Near-perfect in Section 3
- 8+ in Section 4

**Key areas to improve:**
- Zero spelling mistakes
- Instant synonym recognition
- Prediction accuracy
- Flawless concentration

## Frequently Asked Questions About Scoring | 关于评分的常见问题

### Q: Is there negative marking? | 有倒扣分吗？

**A:** No. You are never penalized for a wrong answer. Always guess if you don't know.
没有。答错不扣分。不知道时始终猜。

### Q: Does handwriting affect the score? | 手写会影响分数吗？

**A:** If the examiner cannot read your answer, it will be marked wrong. Write clearly.
如果考官无法辨认你的答案，会被判错。书写清晰。

### Q: Can I use all capital letters? | 可以全部用大写字母吗？

**A:** Yes. Both "LIBRARY" and "library" are acceptable. Using all capitals can help avoid ambiguity.
可以。"LIBRARY" 和 "library" 都可以接受。使用全部大写可以帮助避免歧义。

### Q: What if I write "the library" but the answer is just "library"? | 如果我写了 "the library" 但答案是 "library" 呢？

**A:** If the word limit allows it (e.g., "NO MORE THAN TWO WORDS"), both are usually accepted. If the limit is "ONE WORD ONLY," then "the library" is wrong because "the" is an extra word.
如果字数限制允许（如"不超过两个词"），通常两者都接受。如果限制是"仅限一个词"，那么 "the library" 是错的，因为 "the" 是多余的词。

### Q: Do I need to write full sentences for short answer questions? | 简答题需要写完整句子吗？

**A:** No. Short answer questions require short answers only. Write just the answer word(s).
不需要。简答题只需要简短回答。只写答案词。

### Q: Are half band scores possible? | 会有半分吗？

**A:** Yes. Band scores come in half bands: 6.0, 6.5, 7.0, 7.5, etc.
有。分数以半分形式出现：6.0、6.5、7.0、7.5 等。

### Q: Can I ask for a re-mark? | 可以申请重新评分吗？

**A:** Yes. You can request an Enquiry on Results (EOR) within 6 weeks of the test date. There is a fee, which is refunded if your score changes.
可以。你可以在考试日期后 6 周内申请成绩复议。需要支付费用，如果分数改变会退还。

## Key Takeaways | 核心要点

1. **Each question is worth 1 mark** — there's no question worth more than another
   每题 1 分——没有哪道题比其他题更值钱

2. **Spelling is critical** — it's the easiest way to lose marks you should have earned
   拼写至关重要——这是最容易失去本应得到的分数的方式

3. **Never leave an answer blank** — guess if you don't know (no penalty)
   永远不要留空——不知道就猜（不扣分）

4. **Target 9–10 in Section 1** — it's your easiest section and gives you the most security
   第一部分目标 9-10 分——这是最简单的部分，给你最大的保障

5. **Analyse every mistake** — understanding why you got something wrong is more valuable than doing another practice test
   分析每一道错题——理解你为什么做错比做另一套练习更有价值

6. **Use the 10-minute transfer time wisely** (paper-based) — check spelling, grammar, and word limits
   明智地利用 10 分钟誊写时间（纸笔考试）——检查拼写、语法和字数限制
