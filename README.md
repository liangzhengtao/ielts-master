## What is this?

A free, open-source IELTS preparation library covering all four sections: Listening, Reading, Writing, and Speaking. Plus vocabulary, strategy, and practice materials.

**Who is this for?**
- Self-studying for IELTS
- Teachers looking for teaching materials
- Anyone who wants to improve their English

**What makes it different?**
- 100% free, no paywalls
- Bilingual (English + Chinese) explanations
- Real examples and sample answers
- Practical strategies, not just theory
- Continuously updated

## 🎯 Quick Start

### For Beginners (Band 5-6)

1. Read [Study Plan](06-strategy/study-plan.md) - Choose your timeline
2. Start with [Listening Section 1](01-listening/section1-conversations.md) - Easiest section
3. Learn [Basic Vocabulary](05-vocabulary/academic-vocabulary.md) - Most common words
4. Practice [Task 1 Writing](03-writing/task1-overview.md) - Describe simple charts

### For Intermediate (Band 6-7)

1. Focus on [Question Types](02-reading/question-types.md) - Master each type
2. Practice [Task 2 Essays](03-writing/task2-overview.md) - All essay types
3. Work on [Speaking Part 2](04-speaking/part2-cue-card.md) - Long turn practice
4. Study [Collocations](05-vocabulary/collocations.md) - Natural word combinations

### For Advanced (Band 7-8+)

1. Master [Speed Reading](02-reading/skimming-scanning.md) - Read faster
2. Write [Band 8 Essays](03-writing/sample-essays.md) - Model answers
3. Perfect [Speaking Part 3](04-speaking/part3-discussion.md) - Complex discussions
4. Learn [Academic Vocabulary](05-vocabulary/vocabulary-for-writing.md) - Formal language

## 📊 IELTS Score Guide

| Band | Level | Description |
|------|-------|-------------|
| 9 | Expert | Full operational command |
| 8 | Very Good | Occasional inaccuracies |
| 7 | Good | Generally effective command |
| 6 | Competent | Generally effective despite some inaccuracies |
| 5 | Modest | Partial command, copes with overall meaning |
| 4 | Limited | Basic competence limited to familiar situations |
