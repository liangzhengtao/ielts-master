## 1. 为什么需要速读 | Why Speed Reading

### 时间压力分析 | Time Pressure Analysis

```
IELTS 阅读考试:
- 总时间: 60 分钟
- 总文章: 3 篇
- 总题目: 40 道

每篇文章平均分配:
- 阅读时间: 约 2-3 分钟
- 答题时间: 约 17-18 分钟
- 每题平均: 约 1.5 分钟

问题: 如果逐字逐句阅读，根本不够时间！
Problem: If you read word by word, you'll never have enough time!
```

### 速度对比 | Speed Comparison

| 阅读方式 | 速度 | 理解程度 | 是否适合考试 |
|----------|------|----------|--------------|
| 逐字阅读 | 100-150 wpm | 90-95% | ❌ 太慢 |
| 正常阅读 | 200-250 wpm | 70-80% | ⚠️ 勉强 |
| Skimming | 400-700 wpm | 50-60% | ✅ 快速了解大意 |
| Scanning | 不限速 | 只找特定信息 | ✅ 精确定位 |
| 组合使用 | 变速 | 70-80% | ✅✅ 最佳策略 |

> **关键理念 / Key Concept**: IELTS 阅读不是考你"读完"文章，而是考你"找到"答案。
>
> IELTS Reading doesn't test whether you "read" the passage, but whether you can "find" the answers.

## 2. Skimming 略读技巧

### 什么是 Skimming | What is Skimming

Skimming 是**快速浏览**文章，获取**整体大意**和**文章结构**，而不是理解每一个细节。

Skimming is **quickly glancing** through a passage to get the **general idea** and **structure**, not to understand every detail.

### Skimming 的目标 | Goals of Skimming

```
1. 了解文章主题 (Topic)
   → 文章在讲什么？

2. 了解文章结构 (Structure)
   → 每段在讲什么？

3. 了解作者立场 (Author's position)
   → 作者支持还是反对？

4. 了解段落关系 (Paragraph relationships)
   → 因果？对比？时间顺序？
```

### Skimming 的具体方法 | How to Skim

#### 方法一：读首尾句法 | First & Last Sentence Method

```
对于每个段落，只读:
For each paragraph, only read:

1. 第一句 (Topic sentence) → 了解段落主题
2. 最后一句 (Concluding sentence) → 了解段落结论
3. 中间部分快速扫过 → 看有没有关键词

这通常能获取段落 70-80% 的核心信息
This usually captures 70-80% of the key information
```

**练习示例 / Practice Example**:

```
[第一句] The world's oceans are facing an unprecedented crisis due to 
plastic pollution. Every year, approximately 8 million tonnes of plastic 
waste enters the marine environment, devastating ecosystems from coral 
reefs to deep-sea habitats. [快速扫过中间] ...fish... turtles... 
microplastics... food chain... [最后一句] Without immediate global 
action, scientists warn that by 2050 there could be more plastic than 
fish in the ocean by weight.
```

**你获取的信息 / Information You Get**:
- 主题: 海洋塑料污染
- 问题严重性: 前所未有的危机
- 数据: 每年 800 万吨
- 结论: 2050 年塑料可能比鱼多

#### 方法二：关键词定位法 | Keyword Spotting Method

```
快速扫视每个段落，只关注:
Quickly scan each paragraph, focusing only on:

- 大写字母 (Capital letters): 人名、地名、机构名
- 数字 (Numbers): 年份、百分比、数据
- 引号 (Quotation marks): 直接引用的观点
- 转折词 (Transition words): however, but, yet, despite
- 强调词 (Emphasis words): importantly, significantly, notably
```

**练习示例 / Practice Example**:

```
Dr. Sarah Chen of Stanford University conducted a groundbreaking study 
in 2019 that revealed "the decline of insect populations worldwide has 
reached alarming levels." The research, published in Nature, showed a 
27% decrease in flying insects since 1990. However, some scientists 
argue that the data may not be representative of all regions.
```

**你提取的关键词 / Keywords You Extract**:
- 人名: Dr. Sarah Chen
- 机构: Stanford University
- 年份: 2019
- 期刊: Nature
- 数据: 27% decrease since 1990
- 转折: However (后面有不同观点)
- 引用: "alarming levels"

#### 方法三：结构扫描法 | Structure Scanning Method

```
快速识别文章的组织方式:
Quickly identify the organization of the passage:

时间顺序? → 看到年份、日期
因果关系? → 看到 because, therefore, as a result
对比比较? → 看到 however, while, whereas, in contrast
列举说明? → 看到 firstly, secondly, for example
问题-解决? → 看到 problem, solution, approach
```

### Skimming 速度训练 | Speed Training

#### 阶段一：基础训练（第 1-2 周）

```
练习 1: 3 分钟阅读
- 用计时器设置 3 分钟
- 尽可能多地阅读一篇 800 词的文章
- 记录你读到的位置
- 用 3 句话总结文章大意

目标: 在 3 分钟内读完 800 词的文章
Goal: Read an 800-word passage in 3 minutes
```

#### 阶段二：进阶训练（第 3-4 周）

```
练习 2: 2 分钟阅读
- 将时间缩短到 2 分钟
- 只读每段的首尾句
- 能够说出每段的主题

练习 3: 结构识别
- 用 1 分钟快速浏览文章
- 识别文章结构（因果/对比/时间顺序）
- 列出每段的关键词
```

#### 阶段三：实战训练（第 5 周起）

```
练习 4: 真题 Skimming
- 用 Cambridge IELTS 真题
- 2 分钟内 Skim 一篇完整文章
- 不看题目，先说出:
  a) 文章主题
  b) 文章结构
  c) 每段大意
  d) 作者立场
```

## 3. Scanning 扫读技巧

### 什么是 Scanning | What is Scanning

Scanning 是**快速搜索**文章，寻找**特定信息**（如数字、人名、关键词），而不是理解文章内容。

Scanning is **quickly searching** through a passage for **specific information** (like numbers, names, keywords), not to understand the content.

### Scanning 的目标 | Goals of Scanning

```
1. 定位特定信息 (Locate specific information)
   → 找到题目中关键词在文章中的位置

2. 快速找到答案 (Quickly find answers)
   → 不需要读完整段，找到答案句即可

3. 节省时间 (Save time)
   → 只读需要读的部分
```

### Scanning 的具体方法 | How to Scan

#### 方法一：关键词扫描法 | Keyword Scanning

```
步骤 / Steps:
1. 从题目中提取关键词（名词 > 动词 > 形容词）
   Extract keywords from the question (nouns > verbs > adjectives)

2. 用眼睛快速扫视文章，寻找关键词
   Quickly scan the passage with your eyes for the keyword

3. 找到关键词后，仔细阅读该句及前后句
   Once found, read the sentence and surrounding sentences carefully

4. 提取答案
   Extract the answer
```

**关键词选择原则 / Keyword Selection Rules**:

| 优先级 | 类型 | 原因 | Example |
|--------|------|------|---------|
| ⭐⭐⭐ | 专有名词 | 不会被替换 | Dr. Smith, UNESCO, 2019 |
| ⭐⭐⭐ | 数字 | 不会被替换 | 85%, 2020, three |
| ⭐⭐ | 名词 | 替换可能性低 | pollution, education |
| ⭐ | 动词 | 可能被替换 | increase → rise |
| ⭐ | 形容词 | 很可能被替换 | important → significant |

#### 方法二：Z 形扫描法 | Z-Pattern Scanning

```
不要逐行阅读，而是用 Z 形扫视:

眼 睛 移 动 方 向:
→ → → → → → → → → →
                 ↙
← ← ← ← ← ← ← ← ← ←
                 ↙
→ → → → → → → → → →
                 ↙
← ← ← ← ← ← ← ← ← ←

这样可以覆盖整个页面，同时保持速度
This covers the entire page while maintaining speed
```

#### 方法三：垂直扫描法 | Vertical Scanning

```
对于某些题型（如数字、日期），可以垂直扫视:

只看每行的左侧或右侧
Only look at the left or right side of each line

特别适合找:
- 数字 (Numbers)
- 日期 (Dates)
- 大写词 (Capitalized words)
- 引号内容 (Quoted text)
```

### Scanning 练习 | Scanning Exercises

#### 练习 1：数字扫描 | Number Scanning

**文章 / Passage**:
```
The population of the city grew from 2.3 million in 1990 to 4.1 
million by 2010. The unemployment rate fell to 5.2% in 2015, while 
inflation remained stable at approximately 2.8%. Investment in 
education reached $12.5 billion, a 35% increase from the previous 
year. The government allocated $8.7 million to healthcare reforms.
```

**任务 / Task**: 在 10 秒内找到以下信息
- 2010 年的人口 → 4.1 million
- 2015 年的失业率 → 5.2%
- 教育投资增幅 → 35%

#### 练习 2：人名扫描 | Name Scanning

**文章 / Passage**:
```
Dr. Maria Gonzalez published her findings in the Journal of 
Environmental Science. Her colleague, Professor James Thompson, 
disagreed with her conclusions. However, Dr. Liu Wei from Beijing 
University supported Gonzalez's research, while Professor Sarah 
Chen of MIT remained neutral on the issue.
```

**任务 / Task**: 列出所有提到的人物及其立场
- Dr. Maria Gonzalez → published findings
- Professor James Thompson → disagreed
- Dr. Liu Wei → supported
- Professor Sarah Chen → neutral

## 4. 精读 vs 速读 | Intensive vs Extensive Reading

### 什么时候用什么 | When to Use What

| 场景 | 阅读方式 | 说明 |
|------|----------|------|
| 了解文章大意 | Skimming | 只读首尾句 |
| 定位答案位置 | Scanning | 只找关键词 |
| 理解答案句 | 精读 | 仔细阅读该句 |
| 做 T/F/NG | 精读 | 需要仔细对比 |
| 做 Matching Headings | Skimming | 只需段落大意 |
| 做 Multiple Choice | 精读 | 需要理解细节 |

### 变速阅读法 | Variable Speed Reading

```
IELTS 阅读应该是变速的:
IELTS Reading should use variable speeds:

速度 1: 快速浏览 (Fast - Skimming)
→ 了解大意、定位段落
→ 400-700 wpm

速度 2: 中速扫描 (Medium - Scanning)
→ 寻找关键词、定位信息
→ 300-400 wpm

速度 3: 慢速精读 (Slow - Intensive)
→ 理解答案句、对比选项
→ 100-200 wpm

根据需要在三种速度间灵活切换
Flexibly switch between three speeds as needed
```

## 5. 速读训练方法 | Training Methods

### 每日训练计划 | Daily Training Plan

```
第 1 周: 基础速度提升
├── 5 分钟: 眼球运动训练（上下左右移动眼球）
├── 10 分钟: 快速阅读练习（不求理解，只求速度）
└── 5 分钟: 回忆练习（读完后说出大意）

第 2 周: Skimming 训练
├── 5 分钟: 首尾句练习（只读首尾句）
├── 10 分钟: 结构识别练习
└── 5 分钟: 关键词提取练习

第 3 周: Scanning 训练
├── 5 分钟: 数字/人名扫描练习
├── 10 分钟: 关键词定位练习
└── 5 分钟: 同义替换识别练习

第 4 周: 综合实战
├── 20 分钟: 完整文章限时练习
└── 反思总结
```

### 速读常见问题 | Common Speed Reading Problems

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 读得太慢 | 逐字阅读，嘴唇在动 | 用手指引导，强迫眼睛快速移动 |
| 读了就忘 | 没有主动记忆 | 读完每段后暂停，回忆关键词 |
| 找不到关键词 | 眼睛没有训练 | 做专门的 Scanning 练习 |
| 理解率太低 | 速度太快 | 稍微降速，找到平衡点 |
| 容易走神 | 精力不集中 | 分段阅读，每段设一个小目标 |

### 眼球训练 | Eye Movement Training

```
练习 1: 扩大视野
- 在一行文字中，眼睛只停 3 次（左、中、右）
- 不要一个词一个词地看
- 训练一次看到 3-5 个词

练习 2: 减少回读
- 用手指或笔指着正在读的词
- 手指匀速向前移动
- 强迫自己不回头看

练习 3: 消除默读
- 阅读时不要在心里"念"出每个词
- 可以在心里默数"1, 2, 3"来阻止默读
- 或者嚼口香糖来占据发音器官
```

## 6. 实战应用 | Exam Application

### 不同题型的阅读策略组合 | Strategy Combination by Question Type

#### True/False/Not Given 策略

```
1. 快速浏览题干 (Skim questions)
   → 理解每道题在问什么

2. 扫描定位 (Scan for keywords)
   → 在文章中找到关键词

3. 精读对比 (Intensive read & compare)
   → 仔细对比题目和原文

4. 做出判断 (Make judgment)
   → TRUE / FALSE / NOT GIVEN
```

#### Matching Headings 策略

```
1. 读所有标题 (Read all headings)
   → 2 分钟

2. Skim 每个段落 (Skim each paragraph)
   → 只读首尾句
   → 每段 30 秒

3. 匹配标题 (Match headings)
   → 选择最匹配的标题
```

#### Sentence Completion 策略

```
1. 读题目，划关键词 (Read questions, mark keywords)
   → 1 分钟

2. 按顺序扫描定位 (Scan in order)
   → 因为是顺序出题

3. 精读答案句 (Intensive read answer sentence)
   → 确保答案准确
```

### 实战模拟 | Real Exam Simulation

**场景 / Scenario**: 你有 20 分钟完成一篇文章

```
分钟 0-2: Skimming
├── 快速浏览全文
├── 了解主题和结构
└── 识别每段大意

分钟 2-3: 读题目
├── 快速浏览所有题目
├── 划出关键词
└── 决定答题顺序

分钟 3-17: 答题
├── 用 Scanning 定位
├── 用精读确认答案
└── 每题约 1.5 分钟

分钟 17-20: 检查
├── 检查是否有遗漏
├── 检查拼写和字数
└── 确保所有答案已填写
```

## 7. 高级技巧 | Advanced Techniques

### 技巧一：预测法 | Prediction Method

```
在读文章之前，根据题目预测文章内容:
Before reading, predict the passage content from the questions:

例 / Example:
题目涉及 "climate change", "carbon emissions", "global temperature"
→ 预测文章是关于气候变化的科学文章
→ 预期会看到: 数据、研究、因果关系

这样做可以激活你的背景知识，加快理解
This activates your background knowledge and speeds up comprehension
```

### 技巧二：信号词追踪 | Signal Word Tracking

```
利用信号词快速定位信息类型:

因果关系 → because, therefore, as a result, due to
转折关系 → however, but, yet, nevertheless, despite
举例说明 → for example, such as, including, specifically
对比关系 → while, whereas, in contrast, on the other hand
递进关系 → moreover, furthermore, in addition, additionally
总结关系 → in conclusion, to sum up, overall, in summary
时间顺序 → first, then, subsequently, finally, meanwhile
```

### 技巧三：段落标记法 | Paragraph Marking Method

```
在 Skimming 时，用简单符号标记每段:
When skimming, mark each paragraph with simple symbols:

段落 A: ✓ (有关键词)
段落 B: ? (不确定)
段落 C: ✓✓ (有两个关键词)
段落 D: ✗ (没有相关信息)

这样做可以在回找时快速定位
This helps you quickly locate paragraphs when returning
```

### 技巧四：同义替换预判 | Paraphrase Prediction

```
看到题目中的关键词时，预判它在文章中可能出现的替换形式:

题目: "Scientists believe that..."
文章可能: "Researchers suggest that..."
         "According to experts..."
         "It is widely accepted that..."

题目: "The number increased dramatically"
文章可能: "The figure rose sharply"
         "There was a significant surge"
         "The quantity grew substantially"
```
