## 1. 时间分配基础 | Time Allocation Basics

### 核心数据 | Key Data

```
总时间: 60 分钟
总题数: 40 道
每题平均: 1.5 分钟

但是!
你需要额外的时间:
- Skimming 文章: 2-3 分钟/篇
- 检查答案: 3-5 分钟
- 填写答题卡: 不需要额外时间（直接写在答题卡上）
```

### 理想时间分配模型 | Ideal Time Model

| 环节 | 时间 | 占比 |
|------|------|------|
| **Skimming 全文** | 2-3 分钟/篇 × 3 = 6-9 分钟 | 10-15% |
| **读题 + 定位** | 1 分钟/题 × 40 = 40 分钟 | 67% |
| **精读 + 答题** | 含在上面 | - |
| **检查 + 调整** | 5-10 分钟 | 8-17% |
| **总计** | 60 分钟 | 100% |

### 时间分配的黄金法则 | Golden Rules

```
法则一: 均等分配
→ 每篇文章 20 分钟
→ 适合水平稳定的考生

法则二: 先易后难
→ 简单文章 15 分钟，难题 25 分钟
→ 适合能快速判断难度的考生

法则三: 固定节奏
→ 每 10 分钟检查一次进度
→ 适合容易走神的考生
```

## 2. 三篇文章的时间策略 | Three Passage Strategy

### 策略一：均等分配法 | Equal Distribution

```
第 1 篇: 20 分钟
第 2 篇: 20 分钟
第 3 篇: 20 分钟

优点: 简单易行，不会遗漏
缺点: 可能在难题上时间不够

适合: 初学者、水平 5.5-6.5 的考生
```

### 策略二：递增分配法 | Increasing Distribution

```
第 1 篇 (最简单): 15 分钟
第 2 篇 (中等):    20 分钟
第 3 篇 (最难):    25 分钟

优点: 难文章有更多时间
缺点: 需要快速判断难度

适合: 水平 6.5+ 的考生
```

### 策略三：灵活分配法 | Flexible Distribution

```
第 1 篇: 快速浏览后判断难度
  → 简单: 15 分钟
  → 中等: 18 分钟
  → 困难: 22 分钟

第 2 篇: 根据剩余时间调整
  → 时间充裕: 20 分钟
  → 时间紧张: 18 分钟

第 3 篇: 用剩余所有时间
  → 至少保证 18 分钟

适合: 有经验的考生
```

### 各策略对比 | Strategy Comparison

| 策略 | 第 1 篇 | 第 2 篇 | 第 3 篇 | 适合水平 |
|------|---------|---------|---------|----------|
| 均等法 | 20 min | 20 min | 20 min | 5.5-6.5 |
| 递增法 | 15 min | 20 min | 25 min | 6.5+ |
| 灵活法 | 15-22 min | 18-22 min | 18-25 min | 7.0+ |

### 进度检查点 | Progress Checkpoints

```
检查点 1: 20 分钟时
→ 第 1 篇应该完成
→ 如果没有完成，立即跳到第 2 篇

检查点 2: 40 分钟时
→ 第 2 篇应该完成
→ 如果没有完成，立即跳到第 3 篇

检查点 3: 55 分钟时
→ 第 3 篇应该基本完成
→ 剩余 5 分钟检查不确定的题目
```

## 3. 不同题型的时间分配 | Time Per Question Type

### 各题型建议时间 | Recommended Time by Question Type

| 题型 | 每题建议时间 | 原因 |
|------|-------------|------|
| **T/F/NG** | 1.5-2 分钟 | 需要仔细对比 |
| **Y/N/NG** | 1.5-2 分钟 | 需要仔细对比 |
| **Matching Headings** | 1-1.5 分钟 | 可以批量处理 |
| **Matching Information** | 1.5-2 分钟 | 需要全文搜索 |
| **Matching Features** | 1-1.5 分钟 | 可以批量处理 |
| **Sentence Completion** | 1-1.5 分钟 | 有顺序原则 |
| **Summary Completion** | 1-1.5 分钟 | 有上下文线索 |
| **Note/Table/Flow** | 1 分钟 | 结构清晰 |
| **Diagram Label** | 1 分钟 | 定位简单 |
| **Short Answer** | 1 分钟 | 答案直接 |
| **Multiple Choice** | 1.5-2 分钟 | 需要对比选项 |

### 快速题型 vs 慢速题型 | Fast vs Slow Question Types

```
快速题型 (每题 < 1.5 分钟):
✅ Sentence Completion → 有顺序原则，定位快
✅ Summary Completion → 有上下文线索
✅ Note/Table/Flow/Diagram → 结构清晰
✅ Short Answer → 答案直接
✅ Matching Headings → 可以批量处理

慢速题型 (每题 > 1.5 分钟):
⚠️ T/F/NG → 需要仔细对比
⚠️ Y/N/NG → 需要仔细对比
⚠️ Matching Information → 可能乱序
⚠️ Multiple Choice → 需要对比选项
```

### 时间优化策略 | Time Optimization Strategies

#### 策略一：先做快题，后做慢题

```
如果一篇文章混合了多种题型:

1. 先做填空题 (Completion)
   → 答案直接来自原文，定位快

2. 再做选择题 (Multiple Choice)
   → 需要对比选项

3. 最后做判断题 (T/F/NG)
   → 需要最仔细的对比
```

#### 策略二：批量处理 Matching 题

```
Matching Headings 不要逐段做:
→ 先 Skim 全文，了解每段大意
→ 然后一次性匹配所有标题
→ 这样比逐段做快 30-50%
```

#### 策略三：利用顺序原则

```
顺序题型 (Sentence/Summary/Short Answer):
→ 按顺序做，不要跳题
→ 上一题的答案位置通常在下一题之前
→ 这样可以避免重复阅读
```

## 4. 时间陷阱与应对 | Time Traps and Solutions

### 陷阱一：纠结一道题 | Stuck on One Question

**问题 / Problem**:
```
花了 5 分钟在一道 T/F/NG 上，最后还是不确定
结果后面的题目时间不够
```

**解决方案 / Solution**:
```
规则: 任何题目不要超过 2 分钟
Rule: Never spend more than 2 minutes on any question

如果 2 分钟还没确定:
1. 先猜一个答案（优先猜 NOT GIVEN）
2. 在试卷上做个标记
3. 继续做下一题
4. 有时间再回来检查
```

### 陷阱二：过度阅读 | Over-Reading

**问题 / Problem**:
```
为了理解一道题，把整段文章都读了一遍
其实只需要读一个句子就够了
```

**解决方案 / Solution**:
```
规则: 只读答案句及前后句
Rule: Only read the answer sentence and surrounding sentences

找到关键词后:
→ 读答案句
→ 如果不够，读前一句或后一句
→ 不要读整段
```

### 陷阱三：反复回读 | Re-reading

**问题 / Problem**:
```
读了一遍没找到答案，又从头读一遍
结果还是没找到，又读一遍...
```

**解决方案 / Solution**:
```
规则: 同一段落最多读两次
Rule: Read any paragraph at most twice

第一次: 快速扫描关键词
第二次: 精读相关句子

如果两次都没找到:
→ 跳过这道题，先做后面的
→ 也许后面的题目会帮你定位
```

### 陷阱四：检查时改答案 | Changing Answers

**问题 / Problem**:
```
在检查时，把原来对的答案改成了错的
结果反而丢了分
```

**解决方案 / Solution**:
```
规则: 只在确定是错误时才改答案
Rule: Only change answers if you're certain they're wrong

统计表明:
→ 第一直觉正确率约 60-70%
→ 改答案后正确率反而下降

所以: 不确定就不要改
```

### 陷阱五：时间感知错误 | Poor Time Awareness

**问题 / Problem**:
```
以为才过了 10 分钟，其实已经过了 25 分钟
结果后面的时间严重不足
```

**解决方案 / Solution**:
```
规则: 每 10 分钟检查一次进度
Rule: Check progress every 10 minutes

建议: 在试卷上写下时间节点
→ 0:00 - 开始
→ 0:20 - 第 1 篇完成
→ 0:40 - 第 2 篇完成
→ 0:55 - 第 3 篇完成
→ 1:00 - 考试结束
```

## 5. 考前时间管理训练 | Pre-Exam Training

### 训练计划 | Training Schedule

#### 第 1 周: 单篇限时训练

```
目标: 每篇文章 20 分钟内完成
训练: 每天 2 篇，严格计时

步骤:
1. 设定 20 分钟倒计时
2. 独立完成一篇文章
3. 记录:
   - 完成时间
   - 正确率
   - 哪些题型花了最多时间
4. 分析并改进
```

#### 第 2 周: 题型专项训练

```
目标: 每种题型在建议时间内完成
训练: 按题型分类练习

快速题型 (每题 1 分钟):
- Sentence Completion × 10
- Summary Completion × 10
- Short Answer × 10

慢速题型 (每题 1.5-2 分钟):
- T/F/NG × 15
- Multiple Choice × 10
- Matching Information × 10
```

#### 第 3 周: 双篇连做训练

```
目标: 40 分钟内完成两篇文章
训练: 每天 1 次双篇连做

步骤:
1. 设定 40 分钟倒计时
2. 连续完成两篇文章
3. 记录:
   - 总用时
   - 每篇用时
   - 正确率
4. 分析时间分配是否合理
```

#### 第 4 周: 完整模拟考试

```
目标: 60 分钟内完成全部三篇文章
训练: 每周 2 次完整模拟

步骤:
1. 找一个安静的环境
2. 设定 60 分钟倒计时
3. 连续完成全部三篇文章
4. 记录:
   - 总用时
   - 每篇用时
   - 每种题型的用时
   - 总正确率
5. 分析并制定改进计划
```

### 训练记录表 | Training Record

| 日期 | 第 1 篇 | 第 2 篇 | 第 3 篇 | 总用时 | 正确率 | 备注 |
|------|---------|---------|---------|--------|--------|------|
| Day 1 | 22 min | 25 min | 28 min | 75 min | 28/40 | 超时 15 分钟 |
| Day 7 | 18 min | 20 min | 23 min | 61 min | 30/40 | 基本达标 |
| Day 14 | 16 min | 19 min | 21 min | 56 min | 32/40 | 有进步 |
| Day 21 | 15 min | 18 min | 20 min | 53 min | 34/40 | 稳定 7.0+ |

## 6. 考场应急策略 | Emergency Strategies

### 场景一：时间不够了 | Running Out of Time

**症状 / Symptoms**:
```
还剩 15 分钟，但第 3 篇还没开始
```

**应急方案 / Emergency Plan**:
```
1. 不要慌张 (Don't panic)
   → 慌张会让你更慢

2. 先做简单的题型 (Do easy types first)
   → 填空题 > 选择题 > 判断题

3. 快速 Skimming (Quick skim)
   → 只读每段首句
   → 1 分钟完成

4. 猜答案 (Guess remaining answers)
   → 不确定的题全部猜同一个选项
   → 不要留空！
```

### 场景二：文章太难 | Passage Too Difficult

**症状 / Symptoms**:
```
文章有很多生词，完全看不懂
```

**应急方案 / Emergency Plan**:
```
1. 跳过不懂的词 (Skip unknown words)
   → 不要查词典（考试没有词典）
   → 不要在心里翻译每个词

2. 关注你认识的词 (Focus on words you know)
   → 利用上下文猜测大意

3. 先做不需要完全理解的题型 (Do question types that don't require full understanding)
   → 填空题通常可以直接从原文找答案
   → 数字题通常不需要理解全文

4. 猜 (Guess)
   → 与其花时间纠结难题，不如猜完去做下一篇
```

### 场景三：找不到答案 | Can't Find the Answer

**症状 / Symptoms**:
```
在文章中找了 3 分钟，还是找不到答案
```

**应急方案 / Emergency Plan**:
```
1. 检查关键词 (Re-check keywords)
   → 你找的关键词可能被同义替换了

2. 跳过这道题 (Skip this question)
   → 先做后面的题
   → 后面的题可能会帮你定位

3. 利用顺序原则 (Use order principle)
   → 上一题和下一题的答案之间，就是这题的答案区域

4. 最后回来 (Come back later)
   → 如果还有时间，再找一次
   → 如果没时间，猜一个
```

### 场景四：答题卡填写问题 | Answer Sheet Issues

**症状 / Symptoms**:
```
最后 5 分钟发现有几道题答案还没写在答题卡上
```

**应急方案 / Emergency Plan**:
```
1. 立即填写答题卡 (Fill answer sheet immediately)
   → 不要再思考答案
   → 把所有答案先写上去

2. 不确定的题也要填 (Fill in uncertain answers too)
   → 猜一个答案
   → 不要留空

3. 检查拼写 (Check spelling)
   → 特别是填空题
   → 拼写错误不得分

4. 检查字数限制 (Check word limits)
   → 超过字数限制的答案不得分
```

```
Two minutes per question, never get stuck

```
