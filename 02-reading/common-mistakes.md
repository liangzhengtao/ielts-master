## 1. 理解类错误 | Comprehension Mistakes

### 错误 1: 过度推断 | Over-Inference

**错误表现 / How It Manifests**:
```
文章说: "Many students find the exam challenging."
你选: "The exam is impossible to pass." ❌

正确: "The exam is difficult for many students." ✓
```

**问题分析 / Analysis**:
- "challenging" ≠ "impossible"
- "many students" ≠ "all students"
- 你把自己的推测当成了文章的内容

**解决方法 / Solution**:
```
规则: 答案必须在文章中有直接依据
Rule: The answer must have direct support in the passage

技巧: 如果你需要"想"才能得出答案，那它可能是错的
Tip: If you need to "think" to reach the answer, it's probably wrong
```

### 错误 2: 忽略限定词 | Ignoring Qualifiers

**错误表现 / How It Manifests**:
```
文章说: "Some experts believe that..."
你选: "All experts agree that..." ❌

正确: "Certain experts think that..." ✓
```

**常见限定词 / Common Qualifiers**:

| 限定词 | 含义 | 如果被忽略 |
|--------|------|-----------|
| some | 部分 | → 变成 all |
| many | 许多 | → 变成 all |
| most | 大多数 | → 变成 all |
| often | 经常 | → 变成 always |
| sometimes | 有时 | → 变成 usually |
| can | 可能 | → 变成 will |
| may | 也许 | → 变成 must |
| likely | 可能 | → 变成 definitely |

**解决方法 / Solution**:
```
读题时圈出所有限定词
Circle all qualifiers when reading questions

对比时特别注意限定词是否一致
Pay special attention to whether qualifiers match
```

### 错误 3: 混淆因果关系 | Confusing Cause and Effect

**错误表现 / How It Manifests**:
```
文章说: "Air pollution increased because of industrial growth."
你选: "Industrial growth was caused by air pollution." ❌

正确: "Industrial growth led to more air pollution." ✓
```

**解决方法 / Solution**:
```
区分:
- A because of B → B 导致 A
- A led to B → A 导致 B
- A resulted in B → A 导致 B
- A was due to B → B 导致 A

画箭头帮助理解:
A ← because of B  (B → A)
A led to → B      (A → B)
```

### 错误 4: 错误理解同义替换 | Misunderstanding Paraphrasing

**错误表现 / How It Manifests**:
```
文章说: "The project was completed ahead of schedule."
题目说: "The project was finished early."
你选: FALSE ❌ (因为不认识 "ahead of schedule" = "early")

正确: TRUE ✓
```

**高频同义替换 / High-Frequency Paraphrases**:

| 原文 | 题目可能的替换 |
|------|--------------|
| increase | rise, grow, surge, escalate, climb |
| decrease | decline, fall, drop, diminish, reduce |
| important | significant, crucial, vital, essential, key |
| difficult | challenging, hard, tough, demanding |
| find | discover, identify, detect, locate |
| show | demonstrate, indicate, reveal, display |
| change | alter, modify, transform, shift |
| use | utilize, employ, apply, make use of |
| help | assist, aid, support, facilitate |
| problem | issue, challenge, difficulty, obstacle |

**解决方法 / Solution**:
```
每天积累同义替换词
Build paraphrase vocabulary daily

做题时主动预判可能的替换形式
Actively predict possible paraphrases when doing questions
```

### 错误 5: 混淆观点归属 | Confusing Who Holds Which View

**错误表现 / How It Manifests**:
```
文章说: "Dr. Smith argues that the theory is correct. However, 
Professor Johnson disagrees, claiming the evidence is insufficient."
题目说: "Dr. Smith thinks the evidence is not enough."
你选: TRUE ❌ (这是 Johnson 的观点，不是 Smith 的)

正确: FALSE ✓
```

**解决方法 / Solution**:
```
在文章中标记每个人的观点
Mark each person's view in the passage

使用符号:
Dr. Smith → ✓ (支持理论)
Prof. Johnson → ✗ (反对理论)

做题时仔细核对是哪个人的观点
Carefully check whose view it is when answering
```

## 2. 策略类错误 | Strategy Mistakes

### 错误 6: 逐字阅读 | Reading Word by Word

**错误表现 / How It Manifests**:
```
从文章第一字读到最后，每个词都读
→ 时间不够，后面的文章只能猜
```

**为什么是错误 / Why It's Wrong**:
```
IELTS 文章通常 800-900 词
逐字阅读速度: 100-150 wpm
3 篇文章需要: 15-20 分钟（纯阅读）
答题时间只剩: 40-45 分钟
→ 根本不够用！
```

**解决方法 / Solution**:
```
1. 先读题目，再读文章
   Read questions first, then the passage

2. 用 Skimming 了解大意
   Use skimming for the general idea

3. 用 Scanning 定位答案
   Use scanning to locate answers

4. 只精读答案句
   Only intensively read the answer sentence
```

### 错误 7: 不读题目要求 | Not Reading Instructions

**错误表现 / How It Manifests**:
```
题目要求: "NO MORE THAN TWO WORDS"
你写的答案: "industrial waste products" (3 词) ❌

正确: "industrial waste" (2 词) ✓
```

**常见题目要求 / Common Instructions**:

| 要求 | 含义 | 注意事项 |
|------|------|----------|
| ONE WORD ONLY | 只能一个词 | 不要写两个词 |
| NO MORE THAN TWO WORDS | 最多两个词 | a/the 算一个词 |
| NO MORE THAN THREE WORDS | 最多三个词 | |
| AND/OR A NUMBER | 和/或一个数字 | 数字算一个词 |

**解决方法 / Solution**:
```
做题前先读题目要求
Read instructions before answering

在试卷上圈出字数限制
Circle the word limit on the question paper

写完答案后数一数词数
Count words after writing the answer
```

### 错误 8: 不按顺序做题 | Not Following Question Order

**错误表现 / How It Manifests**:
```
第 1 题找不到答案，跳去做第 5 题
结果第 5 题的答案在第 1 题答案的后面
浪费了时间，还找不到答案
```

**解决方法 / Solution**:
```
大多数题型按顺序出题:
Most question types follow order:

✓ Sentence Completion → 按顺序
✓ Summary Completion → 按顺序
✓ Short Answer → 按顺序
✓ T/F/NG → 按顺序
✓ Y/N/NG → 按顺序
✓ Multiple Choice → 按顺序

✗ Matching Headings → 可能乱序
✗ Matching Information → 可能乱序
✗ Matching Features → 可能乱序

顺序题型: 按顺序做，利用上一题的位置找下一题
Order types: Follow order, use previous answer's location to find next
```

### 错误 9: 在一道题上花太多时间 | Spending Too Long on One Question

**错误表现 / How It Manifests**:
```
一道 T/F/NG 花了 5 分钟
最后还是不确定，随便选了一个
结果后面 3 道题没时间做了
→ 损失了 3 分
```

**解决方法 / Solution**:
```
规则: 每题最多 2 分钟
Rule: Maximum 2 minutes per question

超时处理:
1. 先猜一个答案
2. 在试卷上标记 "?"
3. 继续做下一题
4. 有时间再回来

记住: 一道难题猜对的概率是 33%（T/F/NG）
     放弃后面的 3 道题损失 3 分
     所以: 先做后面的题更划算
```

### 错误 10: 不利用顺序原则 | Not Using the Order Principle

**错误表现 / How It Manifests**:
```
第 3 题的答案在文章第 5 段
你从第 1 段重新开始找第 4 题的答案
结果第 4 题的答案在第 5 段后面
浪费了时间从头找起
```

**解决方法 / Solution**:
```
利用顺序原则:
第 3 题答案在第 5 段
→ 第 4 题答案在第 5 段或之后
→ 不需要从第 1 段重新找

记住上一题答案的位置
Remember the location of the previous answer
从那个位置继续往后找
Continue searching from that position
```

## 3. 答题规范错误 | Answer Format Mistakes

### 错误 11: 拼写错误 | Spelling Errors

**错误表现 / How It Manifests**:
```
正确答案: "environment"
你写的: "enviroment" ❌

正确答案: "government"  
你写的: "goverment" ❌

正确答案: "necessary"
你写的: "neccessary" ❌
```

**高频拼写错误词 / Common Misspelled Words**:

| 正确拼写 | 常见错误 |
|----------|----------|
| environment | enviroment |
| government | goverment |
| necessary | neccessary, necesary |
| occurrence | occurence |
| accommodation | accomodation |
| independent | independant |
| definitely | definately |
| separate | seperate |
| recommend | reccommend |
| beginning | begining |

**解决方法 / Solution**:
```
1. 平时练习时注意拼写
   Pay attention to spelling during practice

2. 建立个人拼写易错本
   Create a personal spelling error notebook

3. 写完答案后检查拼写
   Check spelling after writing answers

4. 特别注意常见的拼写规则
   Watch for common spelling rules
```

### 错误 12: 超过字数限制 | Exceeding Word Limit

**错误表现 / How It Manifests**:
```
题目要求: NO MORE THAN TWO WORDS
你写的: "the industrial waste" (3 词) ❌

正确: "industrial waste" (2 词) ✓
```

**解决方法 / Solution**:
```
规则: 字数限制包括冠词 (a, an, the)
Rule: Word limit includes articles (a, an, the)

技巧:
- 去掉不必要的冠词
- 去掉不必要的修饰词
- 只保留核心答案词

例:
"the big industrial waste" → "industrial waste" (去掉 the 和 big)
```

### 错误 13: 大小写错误 | Capitalization Errors

**错误表现 / How It Manifests**:
```
答案: "TRUE" 写成 "true" ❌
答案: "FALSE" 写成 "False" ❌
答案: "NOT GIVEN" 写成 "Not Given" ❌
```

**解决方法 / Solution**:
```
规则: T/F/NG 和 Y/N/NG 必须全大写
Rule: T/F/NG and Y/N/NG must be ALL CAPS

其他答案:
- 句首大写
- 专有名词大写
- 其他情况小写即可

但是: 大小写通常不影响得分
But: Capitalization usually doesn't affect scoring
为安全起见，建议全大写
For safety, recommend ALL CAPS for T/F/NG
```

### 错误 14: 答案不完整 | Incomplete Answers

**错误表现 / How It Manifests**:
```
题目: "What caused the increase in pollution?"
正确答案: "industrial waste"
你写的: "industrial" ❌ (只写了一半)
```

**解决方法 / Solution**:
```
规则: 答案必须是完整的语义单位
Rule: The answer must be a complete semantic unit

检查方法: 把答案放回题目中，看是否通顺
Check: Put the answer back in the question, see if it makes sense

"What caused the increase in pollution?" 
→ "industrial" ❌ (不通顺)
→ "industrial waste" ✓ (通顺)
```

## 4. 心理因素错误 | Psychological Mistakes

### 错误 15: 第一篇紧张 | First Passage Anxiety

**错误表现 / How It Manifests**:
```
考试开始后特别紧张
第一篇文章读不进去
花了 30 分钟还没做完
结果后面两篇时间严重不足
```

**解决方法 / Solution**:
```
考前准备:
1. 做 3-5 次完整模拟，适应考试节奏
2. 考试当天提前到考场，适应环境
3. 做几个深呼吸，放松心情

考试中:
1. 第一篇通常是最简单的，不要紧张
2. 如果 20 分钟没做完，先跳到第二篇
3. 最后有时间再回来补做
```

### 错误 16: 遇到难题就慌 | Panicking at Hard Questions

**错误表现 / How It Manifests**:
```
看到一道 T/F/NG 不确定
心里想"完了，这道题不会"
结果后面的题也受影响
→ 整体表现下降
```

**解决方法 / Solution**:
```
心态调整:
1. 每个人都有不会的题，这很正常
2. 一道题只值 1 分，不要因小失大
3. 猜一个答案，继续前进

技巧:
→ 告诉自己"先跳过，等会再回来"
→ 不要在心里给自己"判刑"
→ 专注于下一题，而不是上一题
```

### 错误 17: 过度自信 | Overconfidence

**错误表现 / How It Manifests**:
```
觉得"这道题太简单了"
不看文章就直接选答案
结果因为同义替换而选错
```

**解决方法 / Solution**:
```
规则: 每道题都要回文章验证
Rule: Verify every answer against the passage

即使你觉得很简单:
→ 还是要找到原文依据
→ 还是要检查同义替换
→ 还是要确认没有陷阱
```

### 错误 18: 时间感知错误 | Time Perception Error

**错误表现 / How It Manifests**:
```
以为才过了 10 分钟
实际上已经过了 25 分钟
结果后面时间不够
```

**解决方法 / Solution**:
```
1. 在试卷上写下时间节点
   Write time checkpoints on the paper

2. 每 10 分钟检查一次进度
   Check progress every 10 minutes

3. 用手表/考场时钟对照
   Check against the clock

时间节点:
→ 0:00 开始
→ 0:20 第一篇完成
→ 0:40 第二篇完成
→ 0:55 第三篇完成
→ 1:00 考试结束
```

## 5. 各题型常见错误 | Mistakes by Question Type

### True/False/Not Given 常见错误

| 错误 | 正确做法 |
|------|----------|
| 把 NOT GIVEN 当成 FALSE | NG = 文章没说；FALSE = 文章说相反 |
| 看到相似词就选 TRUE | 必须意思完全一致才选 TRUE |
| 过度推理 | 只看文章明确说了什么 |
| 忽略程度词 | some ≠ all, often ≠ always |

### Matching Headings 常见错误

| 错误 | 正确做法 |
|------|----------|
| 看到段落有标题中的词就选 | 词相同不代表意思相同 |
| 只看段落的某一句 | 看段落的整体大意 |
| 不排除已用选项 | 用过的标题划掉 |

### Sentence Completion 常见错误

| 错误 | 正确做法 |
|------|----------|
| 超过字数限制 | 严格遵守 NO MORE THAN X WORDS |
| 答案语法不对 | 检查词性、单复数、时态 |
| 自己编词 | 答案必须来自原文 |

### Multiple Choice 常见错误

| 错误 | 正确做法 |
|------|----------|
| 选原文完全复现的选项 | 正确答案通常是同义替换 |
| 不看所有选项就选 | 对比所有选项再决定 |
| 选"看似合理"的选项 | 必须有原文依据 |
