## 考试概览 | Exam Overview

### 基本信息 | Basic Information

| 项目 | 详情 |
|------|------|
| **考试时长 / Duration** | 60 分钟 / 60 minutes |
| **文章数量 / Passages** | 3 篇 (Academic) / 3 sections (General) |
| **题目数量 / Questions** | 40 道 / 40 questions |
| **答题方式 / Answer Format** | 答题卡 / Answer sheet (no extra transfer time) |
| **评分标准 / Scoring** | 每题 1 分 / 1 mark per question |

### Academic vs General Training 对比 | Comparison

| 对比项 | Academic 学术类 | General Training 培训类 |
|--------|----------------|------------------------|
| **文章来源** | 书籍、期刊、杂志、报纸 | 广告、通知、公司手册、书籍 |
| **难度** | 学术性强，词汇专业 | 日常实用，逐渐变难 |
| **Section 1** | 学术文章（最长） | 日常生活（2-3篇短文） |
| **Section 2** | 学术文章 | 工作相关（2-3篇短文） |
| **Section 3** | 学术文章（最难） | 学术文章（类似 Academic） |
| **适用场景** | 留学申请 | 移民、工作签证 |

## 核心策略总览 | Core Strategy Overview

### 1. 先读题，再读文章 | Questions First, Then Passage

```
❌ 错误做法：从头到尾读完文章 → 再看题 → 回头找答案（浪费时间）
✅ 正确做法：先看题目和关键词 → 带着目的扫读文章 → 定位答案

❌ Wrong: Read entire passage → Read questions → Go back and search (wastes time)
✅ Right: Read questions first for keywords → Scan passage with purpose → Locate answers
```

### 2. 顺序原则 | Order Principle

大多数题型遵循**顺序原则**——答案在文章中出现的顺序与题目顺序一致。

Most question types follow the **order principle** — answers appear in the passage in the same order as the questions.

**例外 / Exceptions**:
- Matching Headings（乱序）
- Matching Features（乱序）
- Matching Information（可能乱序）

### 3. 关键词定位法 | Keyword Location Method

```
步骤 / Steps:
1. 圈出题目中的关键词（名词 > 动词 > 形容词）
   Circle keywords in the question (nouns > verbs > adjectives)
2. 在文章中找到关键词或其同义替换
   Find the keyword or its synonym in the passage
3. 仔细阅读该段落，找到答案
   Read that section carefully to find the answer
```

### 4. 同义替换是核心 | Paraphrasing is Key

IELTS 阅读的**本质**就是考查同义替换能力：

The **essence** of IELTS Reading is testing your paraphrasing ability:

| 题目原文 | 文章中可能出现 | Possible in Passage |
|----------|--------------|---------------------|
| important | significant / crucial / vital | |
| increase | rise / grow / surge / escalate | |
| children | youngsters / juveniles / the young | |
| expensive | costly / high-priced / pricey | |
| solve | address / tackle / resolve | |
| damage | harm / impair / deteriorate | |

## 重要提示 | Important Notes

> **⚠️ 核心提醒 / Core Reminders**:
>
> 1. 阅读没有"回头检查"时间，做完直接收卷
>    No extra time to check answers — papers are collected immediately
>
> 2. 答案直接写在答题卡上，不要先写试卷再誊抄
>    Write answers directly on the answer sheet — no transfer time
>
> 3. 不确定的题先猜一个答案，不要留空
>    Guess if unsure — never leave blanks
>
> 4. 注意字数限制（如 "NO MORE THAN TWO WORDS"）
>    Watch word limits (e.g., "NO MORE THAN TWO WORDS")
