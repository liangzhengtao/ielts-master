# Contributing to IELTS Master

Thank you for your interest in contributing! 🎉

## How to Contribute

### 1. Add Sample Answers
- Write sample answers for speaking topics
- Write sample essays for writing tasks
- Include band scores and explanations

### 2. Fix Errors
- Correct typos or grammar mistakes
- Update outdated information
- Fix broken links

### 3. Add New Content
- Add new speaking topics
- Add new vocabulary lists
- Add new practice materials

### 4. Translate
- Translate content to other languages
- Improve existing translations

## Guidelines

### File Structure
- Use Markdown format
- Include both English and Chinese explanations
- Use clear headings and sections
- Add examples wherever possible

### Writing Style
- Be clear and concise
- Use simple language
- Include practical tips
- Add real examples

### Commit Messages
- Use clear commit messages
- Reference issue numbers if applicable
- Example: "Add speaking topic: Technology"

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

## Questions?

Open an issue if you have any questions!
