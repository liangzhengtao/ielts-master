# IELTS Computer-Based Test Simulator | 雅思机考仿真

A web-based simulator that mimics the real IELTS computer-based test interface.

一个基于网页的雅思机考仿真器，模拟真实的雅思机考界面。

## Features | 功能

- **Listening** - Audio player with controls, timed sections
- **Reading** - Passage display with question navigation
- **Writing** - Text editor with word count
- **Timer** - Realistic countdown timer
- **Scoring** - Instant score calculation
- **Review** - Answer review with correct answers

## How to Use | 使用方法

1. Open `index.html` in your browser
2. Choose a test section (Listening, Reading, Writing, or Full Test)
3. Answer questions within the time limit
4. Review your score at the end

## Screenshots | 界面截图

- Dark theme interface
- Split-screen layout (passage + questions)

- Word counter for writing

## Technical Details | 技术细节

- Pure HTML/CSS/JavaScript
- No external dependencies
- Works offline
- Mobile responsive
